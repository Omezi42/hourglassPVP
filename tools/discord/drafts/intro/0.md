砂時計アリーナのサーバーへようこそ。作者の Omezi です。

**砂時計アリーナ**は、砂時計をモチーフにしたターン制の対戦カードゲームです。
上の部屋に残った砂が体力、下に落ちた砂が攻撃力。時間が経つほど強くなり、
同時に脆くなります。ひっくり返せば体力と攻撃力が入れ替わる——この一点が核です。
ブラウザで遊べます → https://unityroom.com/games/sunadokei_arena

まだ作りかけで、ほぼ毎日更新しています。遊んで気づいたことは何でも教えてください。

**⌛ すなえるについて**
このサーバーで「すなえる」の名前で話しているのは、ぼくが動かしているbotです。
更新のお知らせ、新しい砂時計の紹介、対戦相手の募集通知はすなえるが投稿します。
中身は自動投稿なので、**すなえるに話しかけても返事はしません**。
ぼくに用があるときは、各チャンネルに普通に書いてください。全部読んでいます。

**📜 このサーバーのルール**
1. **人に親切に。** 誹謗中傷・差別的な発言・しつこい絡みはやめてください。
2. **勝ち負けは楽しく。** 対戦相手を煽らない。強い構築を責めない。
3. **宣伝・勧誘はしない。** 他のゲームやサーバーへの誘導、DMでの営業はご遠慮ください。
4. **チャンネルの用途に沿って書く。** 案内はこの下のメッセージにあります。
5. **不具合の報告は、何をしたときに起きたかまで書いてください。** 直せる確率が段違いです。
6. **チートや解析結果の共有はしないでください。** 対戦の不正対策はまだ入っていません。
7. **年齢制限のある話題・グロテスクな内容は投稿しないでください。**

守られない場合は、投稿の削除・タイムアウト・退出をお願いすることがあります。
判断はぼくがします。厳しくするつもりはないので、気楽に遊んでください。
