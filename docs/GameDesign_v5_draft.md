# 砂時計アリーナ v5.0 企画書(草案・未承認)

> **未承認の草案。** 一般的なDCGのパラメータ(コスト / 体力 / 攻撃力)を砂時計に持たせる案。
> v3(両面)・v4(自動位相)は破棄する。

---

## 1. 核となる発明:体力と攻撃力は、砂時計の上下の部屋である

> **上の部屋に残っている砂 = 体力**
> **下に落ちた砂 = 攻撃力**
> **砂の総量は、そのカードの規模(常に一定)**

毎ターン砂が1粒落ちる。つまり**時間が経つほど攻撃力が上がり、同時に脆くなる**。
そして上下がひっくり返るのだから——

> ## 反転すると、体力と攻撃力が入れ替わる。

物理的に正しく、ルールとしては1行。**落下速度というパラメータは要らない**。
総量だけで速度差が表現できる。

### 例:総量10の砂時計

| | 体力 | 攻撃力 | |
|---|---|---|---|
| 出したターン | 10 | 0 | 何もできない(召喚酔いが自然に発生) |
| 3ターン後 | 7 | 3 | |
| **ここで反転** | **3** | **7** | 待った時間を攻撃力へ換金する |
| 5ターン後に反転 | 5 | 5 | 均衡型 |
| 1ターン後に反転 | 1 | 9 | 極端なガラスの大砲 |

**いつ反転するかで、同じカードが別物になる。**パラメータは総量ひとつだけ。

## 2. ルール

- **コスト**:マナで場に出す。マナは毎ターン最大+1・全回復(上限10)
- 場は各プレイヤー **5枠**。プレイヤーの初期HPは **50〜60**
- 出したユニットは 体力=総量 / 攻撃力=0 で始まる
- **反転は1ターンに2体まで**(3章で後述。ここが盤面の性格を決める)
- 攻撃は**相手ユニットか相手プレイヤー本体を選べる**
- **被ダメージを受けると、その分の砂が落ちる**(体力-N / 攻撃力+N)。
  つまり**殴られると強くなるが、死に近づく**
- **砂が落ちきったら(体力0)即座に破壊される**

## 3. 検証で判明した設計制約(`BalanceReport_v3.md` 参照)

### 3.1 総量は二乗で効く ── 最も敏感なパラメータ

反転せず放置した場合、総量Nの砂時計が生涯に与えるダメージは **N(N-1)/2**。

| 総量 | 生涯ダメージ |
|---|---|
| 3 | 3 |
| 5 | 10 |
| 7 | 21 |
| **10** | **45** |
| 13 | 78 |

総量を1増やすと生涯火力が総量ぶん増える。**総量は3〜9の範囲に収める**。
初期に総量13までのカードを混ぜたところ、対局が12手で終わり先手勝率が66%に達した。

### 3.2 反転の最適解は「攻撃力 > 体力 のとき反転」

体力h・攻撃aの砂時計が、反転せず寿命を全うするまでに与える総ダメージは

```
生涯ダメージ = h × a + h(h-1)/2
```

反転すると (h, a) が (a, h) になるので、生涯ダメージの差は **a(a-1)/2 − h(h-1)/2**。
つまり **攻撃力が体力を上回ったときに反転するのが最適**であり、
「攻撃力の高い砂時計を、体力の高い状態へ戻す」ことで寿命を伸ばすほうが総火力が大きい。

**直感に反する点なので明記する。**「体力を攻撃力に換金する」ために反転したくなるが、
それは短視眼で、砂時計を使い捨てにしてしまう。検証用AIが当初この誤りを犯しており、
その結果ユニットが1対局あたり19体も老衰で消え、攻撃の94%が本体へ向かう
「盤面のないレース」になっていた。評価を生涯ダメージへ直した瞬間、
**攻撃の75%がユニットへ向かう盤面の取り合い**に変わった。

### 3.3 被ダメージは「落ちる」で問題ない ── むしろ逆転装置になる

| 被ダメージの扱い | 先手勝率 | 逆転率 | ユニットを攻撃 |
|---|---|---|---|
| **落ちる**(攻撃力+) | **58.6%** | **25.0%** | **75.4%** |
| 消える(総量が減る) | 65.8% | 25.2% | 73.9% |
| 落ちる・盤面上限なし | 61.5% | **19.2%** | 68.8% |
| 消える・盤面上限なし | 73.8% | **2.5%** | 63.6% |

**ユニット戦の量はほぼ変わらない**(75.4% / 73.9%)。当初「落ちるルールはユニット戦を
半減させる」と報告したが、これは検証用AIの評価の誤り(3.2)による見かけの結果だった。

そのうえで、**「落ちる」ほうが先手勝率も逆転率も明確に健全**である。
殴られた側の攻撃力が上がるため、劣勢のプレイヤーに反撃力が残るからで、
**被ダメージが落ちること自体が逆転装置として働いている**。
とくに盤面上限を外した場合、消えるルールでは逆転率が 2.5% まで落ちて完全なスノーボールになる。

### 3.4 反転の回数制限は撤廃してよい

**1体につき1ターン1回**(2回反転すれば元に戻るので、それ以上は無意味)とすれば、
何体反転しても破綻しない。

| 反転できる体数 | 先手勝率 | 決着手数 | 老衰で消えたユニット |
|---|---|---|---|
| 1体 | 57.7% | 33.5手 | 2.9体/対局 |
| 2体 | 59.4% | 33.1手 | 1.2体/対局 |
| **無制限** | **58.6%** | **34.0手** | **0.0体/対局** |

指標はほとんど変わらず、**老衰で消えるユニットが0になって盤面が完全に持続する**。
制限を設ける理由がない。

### 3.5 盤面の枠は、むしろ絞ったほうがよい

**枠の制限は撤廃できるが、撤廃すると明確に悪化する。**

| 盤面の枠 | 先手勝率 | 逆転率 | ユニットを攻撃 | 決着手数 |
|---|---|---|---|---|
| **3枠** | **48.8%** | **42.4%** | **81.9%** | 41.5手 |
| 4枠 | 56.2% | 30.5% | 78.4% | 37.3手 |
| 5枠 | 58.6% | 25.0% | 75.4% | 34.0手 |
| 6枠 | 59.7% | 24.1% | 73.1% | 31.8手 |
| **上限なし** | **61.5%** | **19.2%** | 68.8% | 28.0手 |

枠が狭いほど先手有利が減り、逆転が増え、ユニット戦が濃くなる。きれいな単調関係である。
理由は、**枠が狭いと1枠の価値が上がって交換(除去)が必然になる**のに対し、
並べ放題だと先に展開した側がそのまま押し切れてしまうため。

### 3.6 プレイヤーHPは50〜70

| プレイヤーHP(3枠) | 先手勝率 | 決着手数 | 逆転率 |
|---|---|---|---|
| 50 | 48.8% | 41.5手 | 42.4% |
| 70 | 52.1% | 44.3手 | 43.9% |
| 90 | 51.7% | 46.9手 | 45.6% |

## 5. カードの語彙(効果)

### 5.1 トリガー

| トリガー | 発動条件 |
|---|---|
| **出したとき** | 場に出た瞬間に1回 |
| **反転したとき** | 反転するたび(この作品固有。毎ターン発動しうるため累積が強い) |
| **常在** | 場にある間ずっと |

### 5.2 エフェクト

砂時計は「体力=上の砂 / 攻撃力=下の砂」なので、**砂を動かす効果がそのままバフ・デバフになる**。

| エフェクト | 内容 |
|---|---|
| **一撃** | 相手プレイヤーにNダメージ |
| **砂を落とす** | 対象の砂をN粒落とす(体力-N / 攻撃力+N)。相手に使えば死に近づけるが強化してしまう |
| **砂を戻す** | 対象の砂をN粒戻す(体力+N / 攻撃力-N)。自分の砂時計の延命 |
| **砂を足す** | 対象の総量を+N(体力+N)。恒久的な強化 |
| **破壊** | 相手の砂時計1体を破壊する |
| **強制反転** | 相手の砂時計1体の体力と攻撃力を入れ替える |
| **貫通** | 常在。ユニットを攻撃したとき、超過分が相手プレイヤーへ抜ける |
| **ドロー** | N枚引く |

**効果の価値は生涯ダメージの式で見積もれる。**砂を操作する効果はすべて
`体力×攻撃力 + 体力(体力-1)/2` の差分として計算できるため、値付けに勘を要しない。

### 5.3 検証で判明した値付けの原則

#### 原則1:効果は「総量」ではなく「コスト」で買う

総量Nを1減らすと生涯ダメージが**N近く**減る(二乗の効果)。総量5を4にするだけで
生涯ダメージが10から6へ落ちる。**効果を付けるために総量を削るのは、ほぼ常に損**である。

実測でも、総量を削って効果を付けたカード群は、同コスト帯のバニラ群に **30.9%** しか勝てなかった。
効果はコストを上げて買うこと。

#### 原則2:プレイヤーへの直接ダメージは極端に強い

「出したとき相手に3ダメージ」を持つ総量5のカードは、単色デッキ総当たりで **94.4%** を記録した。
盤面を一切経由せずに勝利条件へ直結するためで、生涯ダメージ(除去されれば失われる)とは
価値の質が違う。**直接ダメージは控えめに値付けする**。

#### 原則3:一時的な妨害は弱い

**強制反転は最弱(22.4%)だった。**相手は次の自分の手番で反転し直せるため、効果が1ターンしか続かない。
盤面へ干渉する効果は、**相手が元に戻せない形**(破壊・総量の減少・反転の封じ)にする必要がある。

#### 原則4:確定除去は思ったより弱い

破壊は 38.9〜55.6% に留まった。盤面が3枠しかなく再展開が速いこと、
放っておいても砂時計は戦闘と老衰で消えることが理由。**除去は万能札ではない**。

#### 原則5:反転トリガーは累積するので強くなりやすい

「反転するたび総量+1」は 77.8〜83.3% と最上位に来た。反転は毎ターン行えるため、
反転トリガーの効果は**毎ターン発動する常在効果に近い**。値付けは常在効果として行う。

## 7. 重大な訂正:これまでの検証には2つのバグがあった

### 7.1 勝敗判定が反転していた

シミュレータの終局処理が、**自分の疲労で死んだ側を勝者として数えていた**。

```python
if p.hp<=0 and o.hp<=0: return None
return (p is a)      # ← p が死んだ場合でも「p の勝ち」を返していた
```

v5 検証全体(3章・4章・5.5節)の先手勝率・逆転率はこの誤りを含む。

### 7.2 決着の 100% がデッキ切れだった

修正後に決着の原因を測ったところ、**1200戦すべてが疲労(デッキ切れ)で終わっていた**。
本体へのダメージが一度も勝敗を決めていない。3章・4章の数値は
**カードゲームではなく疲労レースを測っていた**ことになる。

## 8. 判明した構造的欠陥:除去の価値が本体攻撃を常に上回る

思考AIの評価を「勝利にどれだけ近づくか」で正規化して測り直しても、結果は変わらなかった。
理由は計算で示せる。

体力h・攻撃aの相手を除去する価値は生涯ダメージ `LT = a·h + h(h-1)/2`、
本体を殴る価値は自分の攻撃力 `atk`(相手の攻撃力aと同程度)。両者の比は

```
除去 ÷ 本体 = LT / atk ≒ h + h(h-1)/(2a)
```

**この比はプレイヤーHPにも総量のスケールにも依存しない。**
体力4・攻撃2の相手なら常に約7倍、除去のほうが価値が高い。

したがって **「盤面を処理しきれる限り、攻撃はすべて交換に消えて本体に届かない」**。
盤面が狭いほどこの傾向が強くなる。

### 修正後の実測

| 盤面 | 本体ダメージで決着 | 先手勝率 |
|---|---|---|
| 3枠 | **0.0〜0.1%** | 49.3〜51.3% |
| 4枠 | 0.0〜1.6% | 54.4〜56.0% |
| 5枠 | 0.0〜14.7% | 56.4〜57.6% |
| 6枠 | 9.7〜52.9% | 62.7% |
| 上限なし | 73.9〜84.4% | 67.6〜67.9% |

**「本体ダメージで決着する」と「先手勝率が50%前後」を両立する設定が存在しない。**

3章で「3枠が最良(先手48.8%)」と結論したのは誤りだった。3枠では対局が
疲労レースになり、**手番の有利不利がそもそも結果に影響しないため先手50%に見えていた**だけである。

### 「超過ダメージが本体へ抜ける」を標準ルールにする案(部分的に有効)

| 盤面・HP | 貫通なし | 常時貫通 |
|---|---|---|
| 5枠 / HP30 | 14.7% | **30.7%** |
| 6枠 / HP30 | 52.9% | **63.7%** |
| 5枠 / HP50 | 0.0% | 0.4% |

改善はするが、プレイヤーHPが高い設定では効かない。単独では解決にならない。

## 9. 次に検討すべき対策

1. **総量を小さくする**(2〜4)。除去/本体の比は `h + h(h-1)/(2a)` なので、
   体力2・攻撃1なら約3倍まで下がる。ただし1を下回らないため根本解決ではない
2. **1ターンに除去できる数を制限する**(例:ユニットを攻撃できるのは1体まで、
   残りは本体へ)。盤面を処理しきれなくする直接的な方法
3. **破壊された砂時計は手札に戻す**。除去を一時的なものにして価値を下げる
4. **疲労(デッキ切れ)による決着を廃止し、別の終局条件を置く**
5. ミラー戦・同一思考という測定条件そのものを見直す。実際のカードゲームでも
   同型対決は長引くため、**異なるデッキ同士での測定**が必要

## 10. 根本原因の特定と解決

8章の「除去が本体攻撃より常に7倍価値が高い」は、**ルールの2つの欠落**が原因だった。
どちらも小手先の制限ではなく、ルールそのものの誤りである。

### 原因1:攻撃しても反撃を受けなかった

砂時計が相手の砂時計を攻撃したとき、一方的にダメージを与えるだけで自分は何も失わない
実装になっていた。**除去がノーリスクの完全な得**であれば、本体を殴る理由は原理的に存在しない。

ハースストーンでもMTGでも、ユニット同士がぶつかれば互いにダメージを受ける。
これが「本体を殴る=安全な確定ダメージ」と「ユニットを殴る=自分も傷つくが盤面を取る」を
釣り合わせている。

**修正:砂時計同士がぶつかれば、両方の砂が落ちる。**
互いに相手の攻撃力ぶんのダメージを同時に受ける。物理的にも自然で、
殴り合うほど双方が鋭く脆くなる。

### 原因2:被ダメージで「砂が落ちる」と、戦闘が価値中立になる

原因1だけを直すと、今度は**ユニット戦が消滅した**(ユニットへの攻撃が 9〜11% へ低下、
先手勝率 76%)。理由は計算で示せる。

被ダメージで砂が落ちるルールは、**総量が保存される**ことを意味する。
体力5・攻撃1の砂時計同士がぶつかると、双方が体力4・攻撃2になる。
生涯ダメージは `LT(5,1)=15` から `LT(4,2)=14` へ、**わずか1しか減らない**。

> **戦闘で価値がほとんど失われないなら、殴り合う意味がない。**

これは「被ダメージは落ちる」という規則が持つ**保存則**の直接の帰結であり、
数値調整では絶対に解消できない。

**修正:被ダメージを受けた砂は落ちるのではなく、消える(総量が減る)。**
`LT(5,1)=15` → `LT(4,1)=10` となり、戦闘が双方の資源を確実に削る。

## 12. 確定した構成

**盤面6枠 / プレイヤーHP30 / マナ上限10 / 総量3〜9 /
反転は1体につきターン1回・体数無制限 / 攻撃は相互ダメージ / 被ダメージで砂は消える /
初期手札は先手3枚・後手6枚**

| 指標 | 実測 | 評価 |
|---|---|---|
| 先手勝率 | **50.3%** | 目標圏 |
| 決着手数 | 24.5手 | 良好 |
| 本体ダメージで決着 | 81.8% | 良好(残りはデッキ切れ) |
| ユニットへの攻撃 | 41.0% | 盤面と本体の配分が健全 |
| 逆転率 | 14.3% | やや低い(リードが決定的) |

### 後手補正について

**後手の手札枚数が、先手勝率を細かく調整できる唯一のレバーだった。**

| 後手の初期手札 | 先手勝率 |
|---|---|
| 4枚 | 67.6% |
| 5枚 | 56.5% |
| **6枚** | **50.3%** |

マナによる補正は粒度が粗すぎて使えない(恒久+1で 64% → 26% へ飛ぶ)。
1回だけ+1マナの「コイン」方式も効果がなかった(むしろ悪化)。

## 13. 残る課題

- **先手3枚・後手6枚という差は大きい**。ハースストーンの3枚 vs 4枚+コインと比べて極端で、
  見た目の納得感に欠ける。別の細かい補正手段を探す余地がある
- **逆転率14.3%はやや低い**。リードが決定的になりやすい。プレイヤーHPを上げると
  逆転率は上がるが、本体ダメージでの決着率が下がる(HP40 で 47.2%、HP50 で 15.8%)
- **デッキ切れによる決着が18%残っている**
- カードの効果・キーワードの値付けは、この土台の上で改めて測り直す必要がある
  (これまでの値付けは疲労レースの上で測ったものであり無効)
