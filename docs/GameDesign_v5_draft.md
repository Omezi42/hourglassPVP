# 砂時計アリーナ v5.0 企画書(草案・未承認)

> **未承認の草案。** 一般的なDCGのパラメータ(コスト / 体力 / 攻撃力)を砂時計に持たせる案。
> v3(両面)・v4(自動位相)は破棄する。

---

## 1. 核となる発明:体力と攻撃力は、砂時計の上下の部屋である

> **上の部屋に残っている砂 = 体力**
> **下に落ちた砂 = 攻撃力**
> **砂の総量は、そのカードの規模(常に一定)**

毎ターン砂が1粒落ちる。つまり**時間が経つほど攻撃力が上がり、同時に脆くなる**。
そして上下がひっくり返るのだから——

> ## 反転すると、体力と攻撃力が入れ替わる。

物理的に正しく、ルールとしては1行。**落下速度というパラメータは要らない**。
総量だけで速度差が表現できる。

### 例:総量10の砂時計

| | 体力 | 攻撃力 | |
|---|---|---|---|
| 出したターン | 10 | 0 | 何もできない(召喚酔いが自然に発生) |
| 3ターン後 | 7 | 3 | |
| **ここで反転** | **3** | **7** | 待った時間を攻撃力へ換金する |
| 5ターン後に反転 | 5 | 5 | 均衡型 |
| 1ターン後に反転 | 1 | 9 | 極端なガラスの大砲 |

**いつ反転するかで、同じカードが別物になる。**パラメータは総量ひとつだけ。

## 2. ルール

- **コスト**:マナで場に出す。マナは毎ターン最大+1・全回復(上限10)
- 場は各プレイヤー **5枠**。プレイヤーの初期HPは **50〜60**
- 出したユニットは 体力=総量 / 攻撃力=0 で始まる
- **反転は1ターンに2体まで**(3章で後述。ここが盤面の性格を決める)
- 攻撃は**相手ユニットか相手プレイヤー本体を選べる**
- **被ダメージを受けると、その分の砂が落ちる**(体力-N / 攻撃力+N)。
  つまり**殴られると強くなるが、死に近づく**
- **砂が落ちきったら(体力0)即座に破壊される**

## 3. 検証で判明した設計制約(`BalanceReport_v3.md` 参照)

### 3.1 総量は二乗で効く ── 最も敏感なパラメータ

反転せず放置した場合、総量Nの砂時計が生涯に与えるダメージは **N(N-1)/2**。

| 総量 | 生涯ダメージ |
|---|---|
| 3 | 3 |
| 5 | 10 |
| 7 | 21 |
| **10** | **45** |
| 13 | 78 |

総量を1増やすと生涯火力が総量ぶん増える。**総量は3〜9の範囲に収める**。
初期に総量13までのカードを混ぜたところ、対局が12手で終わり先手勝率が66%に達した。

### 3.2 「被ダメージで砂が落ちる」は成立するが、ユニット戦を半減させる

| 被ダメージの扱い | ユニットを攻撃 | 本体を攻撃 |
|---|---|---|
| **落ちる**(攻撃力+) | **39.2%** | 60.8% |
| 消える(総量が減る) | 66.9% | 33.1% |

**倒しきれない相手を殴ると強化してしまう**ため、攻撃が本体へ流れる。
ただし**ユニット戦が消滅するわけではない**(39%は残る)。倒しきれる時は普通に倒すため。

この規則は「**中途半端に殴るな。倒しきれる時だけ手を出せ**」という原則を生む。
複数体で確実に落としにいく、という組み立てが必要になり、判断としては面白い。
採用する場合、**確実に倒しきるための手段**(除去・貫通)をカード側に用意する必要がある。

### 3.3 盤面の性格を決める最大の変数は「1ターンの反転回数」

| 反転回数 | 老衰で消えたユニット | ユニットを攻撃 | 決着手数 | 性格 |
|---|---|---|---|---|
| **1体** | 19.1体/対局 | 22.1% | 26.5手 | 使い捨ての消耗レース |
| **2体** | **4.5体/対局** | **39.2%** | 34.7手 | **盤面が持続する読み合い** |

反転が1回だと盤面を維持できず、ユニットはほぼ全て老衰で消える。
そうなると**放っておいても死ぬ相手を除去する意味が薄れ**、攻撃が本体へ流れる。
反転2回にすると盤面が持続し、ユニットが本物の脅威になるため戦闘が発生する。

### 3.4 プレイヤーHPは50〜60が必要

| プレイヤーHP | 先手勝率 |
|---|---|
| 30 | 65.8% |
| 50 | 43.5% |
| 60 | 43.9% |

HP30では先手が圧倒的。50以上で釣り合う。

## 4. 推奨する構成(検証済み)

**5枠 / プレイヤーHP50 / マナ上限10 / 総量3〜9 / 反転2体まで / 被ダメージは落ちる**

| 指標 | 実測 |
|---|---|
| 先手勝率 | 43.5% |
| 決着手数 | 31.0手 |
| 引き分け | 0.0% |
| ユニットへの攻撃 | 39.4% |
| 老衰で消えるユニット | 3.6体/対局 |

## 5. 未解決の課題

- **先手勝率43.5%はやや後手有利**。プレイヤーHPを45前後に下げると50%へ寄る見込み
- **中盤のリードが結果に結びつかない**(20手目に劣勢だった側の勝率が56.8%)。
  盤面が入れ替わり続けるため、HPのリードが意味を持ちにくい。
  プレイングが報われる形になっているか、追加の検証が必要
- カードはすべてバニラ(効果なし)で検証している。効果を持たせた場合の挙動は未検証
- 3.2の規則を採る場合、「倒しきる手段」をカードの語彙として設計する必要がある
