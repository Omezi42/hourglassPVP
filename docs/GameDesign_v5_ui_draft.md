## B. 追加する記述(v5.0の対局画面)

### B-1 画面構成

- 対局画面は上から順に **相手の情報帯 / 相手の場(6枠)/ 自分の場(6枠)/ 自分の情報帯 /
  自分の手札** で構成する。盤面を挟んで対面させる点は v1.0 と同じだが、
  **手札は情報帯より外側(画面最下部)に置く**。手札は最も頻繁に触る領域であり、
  盤面と混ざらない位置に固定する
- **情報帯には HP・マナ・山札の残り枚数・墓地の枚数を並べる**。相手側は手札の枚数も出す
  (中身は伏せる)。相手の手札を扇形に並べて枚数を示すことはせず、数字1つで示す。
  6枠の盤面と20枚のデッキを同時に置くと画面が狭いため、裏向きカードの列に幅を割かない
- **マナは数字とピップ(粒)の併記とする**。「3/7」のような数字だけだと、支払える枚数を
  手札と見比べる操作が読みにくいため。上限10まで横に並べても情報帯の幅に収まる
- 山札・墓地は枚数のバッジだけを持つ小さな山として置き、押すと墓地の中身を一覧できる。
  山札の中身は見られない

### B-2 場のカードの表示

- **体力と攻撃力は、砂時計の物理そのものに合わせて上下へ置く。体力は上の部屋の位置
  (カードの左上)、攻撃力は下の部屋の位置(カードの左下)に表示する。**
  これは v5.0 の核となる発明(上の砂=体力/下の砂=攻撃力)を、数字の置き場所だけで
  説明するための決定であり、一般的なDCGのように攻撃力を左下・体力を右下へ置く配置は採らない
- **イラストは体力と攻撃力の比で3枚を切り替える**。攻撃力が体力より少ないうちは
  上向き、拮抗しているときは落下中、攻撃力が体力を上回ったら落ちきりの絵にする。
  既存の3状態の絵をそのまま使い、v5.0の連続値を3段階へ量子化して見せる
- **キーワードはカードの下端に短いラベルとして並べる**(「守護」「硝子」など)。
  紋章にはしない。7種あり、複数持つカードもあるため、絵柄で覚えさせるより語で読ませる
- **守護を持つカードは枠を太くする**。攻撃の対象選択に直接効くため、ラベルだけでなく
  形でも分かるようにする
- **硝子が残っているカードには薄い光の膜を重ねる**。1度使うと消える
- 出したターンのカード(反転も攻撃もできない)は僅かに沈んで見せ、
  **このターンに攻撃済みのカードは彩度を落とす**

### B-3 操作

- **出す**:手札のカードを押す → 出せる枠(空き枠と、上書きできる自分の枠)が光る →
  枠を押すと出る。マナが足りないカードは手札の時点で暗く表示し、押しても光らせない。
  **上書きになる枠は空き枠と別の色で光らせる**(元のカードを失うため)
- **設置効果が相手1体を対象に取る場合**(アイ・ハンマー)、出した直後に相手の場が
  対象選択の状態になる。対象がいない場合は選択を挟まず、そのまま出る
- **反転**:自分のカードを押す → その場に「反転」ボタンが出る → 押すと入れ替わる。
  1体につき1ターン1回・出したターンは不可であり、できない場合はボタンを出さない
- **攻撃**:自分のカードを押した状態で相手のカードか**相手のHP帯**を押す。
  ドラッグでも同じ操作ができるようにする。攻撃できる対象だけを光らせ、
  **守護がいる間は守護のカードと、相手のHP帯以外が光らない**
- **ターン終了**は画面右下の大きなボタンとする。**まだ攻撃できるカードや、
  払えるマナが残っている状態で押そうとしたときは、ボタンの色を変えて知らせる**
  (押せなくはしない。あえて残す選択もあるため)
- 「ログ」「投了」は v1.0 どおり画面下部中央にまとめる

### B-4 演出

- **相打ちは、双方のカードが中央でぶつかって互いに砂を散らす**。v5.0では攻撃した側も
  必ずダメージを受けるため、一方的に見える演出にしない
- **ダメージを受けた砂は消える**(総量が減る)。ターン終了時に落ちる砂(体力→攻撃力)とは
  見た目を明確に分ける。**消える砂は砕けて散り、落ちる砂は下の部屋へ流れる**。
  この2つを取り違えるとルールを誤解するため、演出上もっとも重要な区別として扱う
- 反転の演出は v1.0 のもの(光の筋・持ち上げ・回転・着地)をそのまま使う。
  v5.0でも反転はゲームの中心となる行動であり、作り込みの方針は変わらない
- ターン終了時、自分の全ユニットの砂が同時に1粒落ちる。1体ずつ順に見せるのではなく
  **同時に落として、破壊されたものだけを続けて見せる**(6枠あるため順送りだと長い)

### B-5 デッキ編集

- **デッキは20枚・同名2枚まで**。編成中の欄は「カード名 × 枚数」の縦リストとし、
  20枚をカードの絵で並べることはしない(画面に入らないため)
- **マナカーブ(コスト別の枚数)をグラフとして常時表示する**。20枚のデッキでは
  コストの配分が構築の中心であり、数えなくても分かる状態にする
- 全カードの一覧は v1.0 どおり横1行の横スクロールとし、押すと編成へ1枚加わる。
  2枚入っているカードは一覧側で「2/2」と示して押せなくする
