# 砂時計 カード一覧(Hourglasses)

このファイルは砂時計(カード)の個別データを管理する。
ルール・キーワード・値段表など設計の前提は `docs/GameDesign.md` を参照すること。
測り方と生データは `docs/BalanceReport_v5.md` にある。

各砂時計は **コスト / 総量(体力+攻撃力)/ キーワードまたは効果** の3つを持つ。
場に出た時点で体力=総量・攻撃力0で始まり、毎ターン砂が1粒落ちて
体力-1・攻撃力+1 になる。反転すると体力と攻撃力が入れ替わる。

実データは `data/cards/{id}.tres`。

### ダスト(コスト2)を足した理由

**余砂(破壊されたとき)を持つカードが1枚も無く**、語彙として定義済み(GameDesign.md 6章)
なのにキーワード辞書に「まだこの能力を持つ砂時計はありません」と出ていた。既存の
`ON_DEATH × DAMAGE_PLAYER` の組み合わせだけで作れるため、エンジンには手を入れていない。

総量4で46.8%・総量5で55.7%(いずれも800戦×シード42/43の平均)と、**均衡は4と5のあいだ**
(およそ4.4)にある。整数ではこれ以上詰められないため、より50%に近い4を採った
(`docs/BalanceReport_v5.md` 5.3節の分解能の限界。グレインと同じ形)。

値段に直すと **+0.1** で、ほぼ無料にあたる。同じ「本体へ2ダメージ」でも
設置は +1.1 なので、**発動が破壊時まで遅れるぶんが1粒ぶん安い**ことになる。

**勝率の幅は 44.7〜55.0%(レンジ10.3pt)。**800戦での測定誤差が±3.5pt程度あるため、
この幅はほぼ誤差の範囲であり、**これ以上の調整は誤差を追いかけるだけになる**。
調整前(引き直し前)は 38.2〜59.5%(21.3pt)だった。

### グレイン(コスト1)を足した理由

**最小コストが2だったため、マナ1しか無い1ターン目は構造上どちらのプレイヤーも
何も出せなかった。**盤面へ触れないまま1手が過ぎるうえ、初見のプレイヤーには
手札が全て暗いことがバグと見分けられない。バニラの基準総量
`1.9 + 1.33 × コスト` はコスト1で3.2を指すため、総量3のバニラとして足した。

総量3で44.7%、総量4で54.5%(いずれも800戦×2シードの平均)と、**均衡は3と4の
あいだにある**。整数の総量ではこれ以上詰められないため、基準線の式に近い3を採った
(`docs/BalanceReport_v5.md` 5.3節の分解能の限界)。

### スプラウト(コスト3)を足した理由

**余砂の2枚目**。1枚では語の使い回しが効かず、トリガーとして定義した意味が半分しか出ない
(GameDesign.md 6章)。ダストが「余砂で本体を殴る」側なので、こちらは
**エコー(設置:カードを1枚引く)の余砂版**にして、同じ効果が設置と余砂でどう変わるかを
プール内で読み比べられるようにした。

総量4で42.1%・5で47.7%・6で51.5%・7で59.5%(いずれも800戦×シード42/43の平均)。
均衡は5.7付近で、より50%に近い6を採った。

値段に直すと **+0.2**。**設置:1枚引く(+2.7)より2.5も安い**。ダストでも設置(+1.1)→
余砂(+0.1)で1.0下がっており、**余砂は「遅れるぶん安い」どころか、ドローのように
盤面へ直接効かない効果ではほとんど値段が消える**。破壊されるまで手札が増えないため、
引いたカードを使うマナが残っていないことが多いのが理由と見られる。

### 同じキーワードをコスト違いで持つ組

**語(キーワード)にしているのは、2枚以上のカードに載っている4種だけ**
(GameDesign.md 6章)。1枚しか無い毒砂・吸命・連撃は語を使わず効果の文で書く。

| キーワード | 軽い方 | 重い方 |
|---|---|---|
| **守護** | シールド(2/4) | ガード(5/7) |
| **硝子** | グラス(3/6) | ミラー(5/7) |
| **速落** | ダッシュ(2/4) | ランス(4/6・貫通も持つ) |
| **貫通** | ドリル(3/7) | ランス(4/6・速落も持つ) |

トリガーの**余砂**は ダスト(2/4・本体へ2ダメージ)と スプラウト(3/6・1枚引く)の2枚が持つ。
トリガーは分類なので載っている枚数に関わらず語のまま使う(GameDesign.md 6章)が、
1枚しか無いと辞書で引いても比べる相手がいないため、2枚目までは早めに埋める。

### ハンマーとスイープを弱めた経緯(承認済み)

当初の「1体を破壊」「全体の砂を2粒削る」は、**総量を下限(2)まで削り、
コストを上げても勝率が下がらなかった**(スイープはコスト7で63.5%、9でも60.4%)。
除去の価値は周囲のカードの大きさに比例するため、コストという一律の値上げでは追いつかない。
効果そのものを弱めることで釣り合った。
