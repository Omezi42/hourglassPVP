# 砂時計 駒一覧(Hourglasses)

このファイルは砂時計(カード)の個別データを管理する。
ルール・語彙・数値方針など駒デザインの前提は `docs/GameDesign.md` を参照すること(このファイルはその前提の上での「実データ台帳」)。

新しい砂時計を追加する際は、GameDesign.md 7章の語彙(トリガー×ターゲット×エフェクト)の組み合わせで表現し、この表に1行追加する。
既存の語彙で表現できない効果が必要になった場合は、先に GameDesign.md 7章への追記を提案すること。

---

## 現行10種類の砂時計(サンプル実装)

| 名前 | 落下ダメージ | 追加効果 |
|---|---|---|
| **サンド** | 4 | なし(バニラ、基準駒) |
| **ソード** | 3 | 反転時:相手プレイヤーに1ダメージ |
| **キング** | 1 | 落下中の間:被ダメージ-1 / 落ちきり時追加:自分に2ダメージ |
| **ジャッジ** | 1 | 落ちきり状態の間、毎ターン相手に1ダメージ(継続) |
| **シールド** | 2 | 落下中の間:被ダメージ-1 |
| **ウォール** | 2 | 相手に反転させられた時:相手に1ダメージ(カウンター) |
| **ダッシュ** | 2 | 反転時:自分をもう1段階進める(即座に次状態へ) |
| **エコー** | 2 | 落ちきり時:味方ランダム1個を上向きに戻す |
| **ミラー(→)** | 2 | 反転時:右隣の砂時計の状態を自分に揃える |
| **アイ** | 0 | 落下中の間:正面の相手の砂時計をロック(反転不可) |
