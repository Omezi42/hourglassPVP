# 砂時計 カード一覧(Hourglasses)

このファイルは砂時計(カード)の個別データを管理する。
ルール・キーワード・値段表など設計の前提は `docs/GameDesign.md` を参照すること。

各砂時計は **コスト / 総量(体力+攻撃力)/ キーワードまたは効果** の3つを持つ。
場に出た時点で体力=総量・攻撃力0で始まり、毎ターン砂が1粒落ちて
体力-1・攻撃力+1 になる。反転すると体力と攻撃力が入れ替わる。

---

### 同じキーワードをコスト違いで持つ組

キーワード制の狙いどおり、同じ能力を軽重で作り分けられている。

| キーワード | 軽い方 | 重い方 |
|---|---|---|
| **守護** | シールド(2/4) | ガード(5/5) |
| **硝子** | グラス(3/5) | ミラー(5/5) |
| **速落** | ダッシュ(2/4) | ランス(4/6・貫通も持つ) |

### 調整が必要な2枚

**ハンマー(確定破壊)とスイープ(全体除去)は、総量を下限の2まで削っても勝率が
57.4% / 60.1% と下がりきらなかった。**効果が強すぎるため、総量ではなく
**コストを上げて釣り合わせる**必要がある(ハンマー 4→5、スイープ 6→7 へ暫定的に引き上げ済み。
再測定は未実施)。

これは GameDesign.md 6章の設計指針4「毒砂は常に高い」と同じ現象で、
**確定除去は総量では買えない**ことを示している。

## 未検証・今後の課題

- **コストがあまり効いていない。**グラス(コスト3・総量5)とミラー(コスト5・総量5)が
  ともに約50%で並ぶなど、コスト2と5の差が結果にあまり現れない。盤面6枠に対して
  マナ上限10が過剰で、中盤以降マナが余っているのが原因と考えられる。
  マナ上限を下げるか、盤面を広げるかの検討が必要
- 余砂(破壊されたとき)を持つカードが1枚もない。語彙として定義済みなので追加する
- カードのモチーフ・イラストは未着手。既存10種のイラストは流用できるが、
  新規10種は生成が必要
