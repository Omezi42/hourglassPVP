# 砂時計 駒一覧(Hourglasses)

このファイルは砂時計(カード)の個別データを管理する。
ルール・語彙・数値方針など駒デザインの前提は `docs/GameDesign.md` を参照すること(このファイルはその前提の上での「実データ台帳」)。

新しい砂時計を追加する際は、GameDesign.md 7章の語彙(トリガー×ターゲット×エフェクト)の組み合わせで表現し、この表に1行追加する。
既存の語彙で表現できない効果が必要になった場合は、先に GameDesign.md 7章への追記を提案すること。

## 現行10種類の砂時計

スキルは手番の行動として発動し、**反転の代わりに行う**(GameDesign.md 4.3)。スキルを使った
マスもその手番に進行するため、落下ダメージが高い駒ほどスキルを撃ちにくい。
**スキルを持たないのは基準駒のサンドだけ**で、**受動効果は10種のうち4種だけが持つ**。

| 名前 | 落下ダメージ | スキル | 受動効果 |
|---|---|---|---|
| **サンド** | 4 | なし(バニラ、基準駒) | なし |
| **ソード** | 3 | **一撃**:相手プレイヤーに2ダメージ | なし |
| **ダッシュ** | 3 | **加速**:自分自身を1段階進める | なし |
| **シールド** | 2 | **治癒**:自分のHPを1回復 | なし |
| **ミラー(→)** | 2 | **位置交換**:右隣の自分の駒と位置を入れ替える | なし |
| **ジャッジ** | 2 | **同調**:右隣の駒の状態を自分に揃える | 落ちきり中の間、毎ターン相手に1ダメージ |
| **ウォール** | 2 | **一撃**:相手プレイヤーに1ダメージ | 相手に反転させられた時:相手に1ダメージ |
| **キング** | 1 | **号令**:落ちきっている味方を1個、上向きに戻す | 落ちきり中の間:被ダメージ-1 |
| **エコー** | 1 | **交代**:自分自身を控えの1個と入れ替える | なし |
| **アイ** | 0 | **目覚め**:落ちきっている味方を2個まで上向きに戻す | 落下中の間:正面の相手をロック(反転不可) |

落下ダメージの合計は20。

## スキル制への移行と、駒を作り替えた経緯

移動・交代は当初すべての駒が使える基本行動だったが、自己対戦での選択率がそれぞれ1.8%と、
1手番を費やす価値がなかった。そこで基本行動を「反転」だけに絞り、両者を駒のスキルへ移した
(GameDesign.md 4.3)。

当初はスキルを4種の駒にだけ持たせていたが、自己対戦でスキルの選択率が2.6%にとどまり、
CPU同士の総当たりでも「スキル持ちを場へ出さない方が強い」という結果が出た。そこで
**基準駒のサンドを除く9種すべてにスキルを持たせ**、あわせて**受動効果を4種だけに絞った**。
受動を全ての駒が持っていると駒の違いが読み取りにくく、スキルという主軸もぼやけるため。
この変更でスキルの選択率は2.6%から63%台へ跳ね上がり、毎手番「起こすか、能力を使うか」を
選ぶゲームになった。

主な変更点は次のとおり。

| 駒 | 変更前 | 変更後 |
|---|---|---|
| ソード | 落下3 / 反転時:相手に1ダメージ | 落下3 / スキル「一撃」(2ダメージ)・受動なし |
| シールド | 落下2 / 落下中:被ダメージ-1 | 落下2 / スキル「治癒」(1回復)・受動なし |
| ジャッジ | 落下2 / 受動のみ | 落下2 / スキル「同調」を追加 |
| ウォール | 落下2 / 受動のみ | 落下2 / スキル「一撃」(1ダメージ)を追加 |
| キング | 落下1 / 受動2つ(軽減・自傷2) | 落下1 / スキル「号令」+ 受動は軽減の1つだけ |
| ダッシュ | 落下2 / 反転時:自分を1段階進める | 落下3 / スキル「加速」・受動なし |
| ミラー | 落下2 / 反転時:右隣と状態同期 | 落下2 / スキル「位置交換」・受動なし |
| エコー | 落下2 / 落ちきり時:味方ランダム1個を上向き | 落下1 / スキル「交代」・受動なし |
| アイ | 落下0 / 落下中:正面ロック | 落下0 / スキル「目覚め」+ 受動はそのまま |

**治癒の回復量は1に抑えている**。自己対戦で回復2にすると膠着が8.8%・P90が112手、
回復3では膠着12.0%・P90が上限の200手に達した(回復1では膠着3.0%・P90が37手)。
1手番あたりの平均ダメージを回復が上回ると、双方が回復し合って対局が終わらなくなるため。

### 控えの扱いについて

交代がスキルになったことで、**交代スキルを持つ駒を入れないデッキでは控えの2枚が場に出ない**。
これは構築上の選択として意図したものであり、「デッキ5枚のうち何枚を実際に回すか」を編成の
判断に含める。控えを活かしたいプレイヤーは交代スキル持ちを採用する。

---

### キングの効果を変更した経緯

キングは当初「落下ダメージ1 / 落下中の間:被ダメージ-1 / 落ちきり時追加:自分に2ダメージ」
だった。しかし自己対戦の検証で、3つの要素がすべて「落ちきらせず落下中に留めろ」という同じ方向を
向いているため、**毎ターン反転して落下中を維持し続ける**以外の使い道がないことが判明した
(1試合あたり7.7回、自分の手番の約7割をキングの維持に費やしていた)。これは GameDesign.md 7章の
設計指針3(反転させられ続けると無限に得をする効果は避ける)の裏返しにあたる。

そこで軽減を「落下中の間」から「落ちきり中の間」へ移し、効果の向きをばらした。維持ループは
1試合7.7回から0.25回へほぼ消滅した。その後、全駒へスキルを持たせる際に受動を1つへ絞る方針と
なったため、**自傷2は削除**して「落ちきり中の間:被ダメージ-1」だけを残している。
