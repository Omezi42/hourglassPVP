# 砂時計 カード一覧(Hourglasses)

このファイルは砂時計(カード)の個別データを管理する。
ルール・キーワード・値段表など設計の前提は `docs/GameDesign.md` を参照すること。
測り方と生データは `docs/BalanceReport_v5.md` にある。

各砂時計は **コスト / 総量(体力+攻撃力)/ キーワードまたは効果** の3つを持つ。
場に出た時点で体力=総量・攻撃力0で始まり、毎ターン砂が1粒落ちて
体力-1・攻撃力+1 になる。反転すると体力と攻撃力が入れ替わる。

実データは `data/cards/{id}.tres`。

### 同じキーワードをコスト違いで持つ組

キーワード制の狙いどおり、同じ能力を軽重で作り分けられている。

| キーワード | 軽い方 | 重い方 |
|---|---|---|
| **守護** | シールド(2/4) | ガード(5/8) |
| **硝子** | グラス(3/5) | ミラー(5/7) |
| **速落** | ダッシュ(2/4) | ランス(4/5・貫通も持つ) |
| **貫通** | ドリル(3/6) | ランス(4/5・速落も持つ) |

## 調整が必要な2枚(**要承認**)

**ハンマー(確定破壊)とスイープ(全体除去)は、総量が下限(2)に達しており、
コストを上げても勝率がほとんど下がらない**(ハンマー コスト5→59.5% / 6→56.4%、
スイープ コスト7→63.5% / 8→59.5% / 9→60.4%)。

効果そのものを弱める以外に釣り合わせる手段がない。次の案は実測で確認済み。

| カード | 提案 | 実測 |
|---|---|---|
| **ハンマー** | 「1体を破壊」→**「1体に4ダメージ」**、コスト4・総量3 | 48.9% |
| **スイープ** | 「全体の砂を2粒削る」→**「全体の砂を1粒削る」**、コスト6・総量4 | 51.1% |

承認を得るまでは現行の効果文のままとする。**この2枚が勝率を吸っているため、
残り18種の勝率も一律に50%を下回っている。**2枚を確定させてから全体を測り直す。

## 未検証・今後の課題

- **余砂(破壊されたとき)を持つカードが1枚もない。**語彙として定義済みなので追加する(AL-3)
- ハンマー・スイープの確定後に、18種の総量を1度だけ測り直す
- **イラストが未設定のカードが10種ある**:グラス・ドリル・ヴァンプ・ロック・ツイン・
  ランス・スウォーム・ポイズン・ハンマー・スイープ。既存10種のイラストは
  サンド・シールド・ダッシュ・ソード・エコー・アイ・ミラー・ウォールへ割り当て、
  ガードは king、グロウは judge の絵を流用している(AM-6)
