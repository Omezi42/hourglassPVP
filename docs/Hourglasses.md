# カード一覧(Hourglasses)

このファイルはカードの個別データを管理する。**カードには盤面へ出る「砂時計」と、
出ずに効果だけを起こす「砂術」の2種類がある**(GameDesign.md 6章)。
砂時計58種 + 砂術12種 = **70枚が基本セット**であり、ここで出そろっている
(GameDesign.md 8章)。
ルール・キーワード・値段表など設計の前提は `docs/GameDesign.md` を参照すること。
測り方と生データは `docs/BalanceReport_v5.md` にある。

各砂時計は **コスト / 総量(体力+攻撃力)/ キーワードまたは効果** の3つを持つ。
場に出た時点で体力=総量・攻撃力0で始まり、毎ターン砂が1粒落ちて
体力-1・攻撃力+1 になる。反転すると体力と攻撃力が入れ替わる。

実データは `data/cards/{id}.tres`。

各 `.tres` は **`pool_index`(追加順の通し番号)**を持つ。砂時計一覧の「追加順」の並び
(GameDesign.md 9章)がこれを読む。初期20種は同時に追加されたため順序が存在せず、
下の表からグレイン・ダスト・スプラウトを除いた並びを1〜20として与えた。以後は21(グレイン)・22(ダスト)・23(スプラウト)と続き、50種化で24〜50、
マナカーブ調整の8枚で51〜58を与えた。
**カードを1枚足すたびに次の番号を入れる**。

### 27種を一度に足した回(50種化)

**キーワードを付けかえただけのカードばかりで個性が無い**というユーザーの指摘を受けた回。
23種の時点でバニラ4枚とキーワードだけの10枚が全体の6割を占め、残りも
「設置で1回だけダメージかドロー」に寄っていた。**盤面に居続けて毎ターン働く駒も、
他の駒へ干渉する駒も1枚も無かった**。

手本は初期のハースストーン・シャドウバース・ドラゴンクエストライバルズにある、
**1行で読めるのに他と重ならない**効果(GameDesign.md 6章)。あわせて語彙を8つ足した。

**この回で分かったこと**

- **繰り返し働くトリガー(落砂・被弾)は、想像よりずっと高い。**クラックは
  「被弾:カードを1枚引く」だけでコスト3の均衡総量が6になった。バニラの基準線
  (5.9)とほぼ同じで、**効果が実質無料に見えるが、これは総量6が「引ける回数」を
  買っているため**である。総量を2まで下げると36%まで落ちる
- **繰り返しトリガーと「攻撃できない」を重ねると、総量では釣り合わない。**
  タワーとアンカーはコスト5のままだと最小の総量でも56〜61%あり、コストを7へ上げて
  初めて釣り合った(タワー 7/8で53.0%、アンカー 7/9で49.0%)。**効果が盤面の
  大きさに比例しないぶん、除去(ハンマー・スイープ)と違ってコストで買える**
- **攻撃できない駒は、総量をかなり大きく取れる。**ワッチャーはコスト2で総量7、
  ゲートはコスト4で守護つき総量9。バニラの基準線のほぼ2倍にあたる
- **トークンを出す効果は安い。**ペブルはコスト2・総量3でモート(総量2)を連れてきて
  51.7%。盤面の枠を1つ使うため、総量をそのまま足した場合ほど強くならない

### マナカーブ調整の8枚(58種化)

**プールのコストの分布が3〜4に偏っており、コスト1がグレイン1枚しか無かった。**
1ターン目に触れる選択肢が「グレインを2枚積むかどうか」しかなく、
「最小コストは1とする」(GameDesign.md 6章)の狙いが枚数の面で成立していなかった。

| コスト | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| 50種のとき | 1 | 7 | 16 | 15 | 7 | 2 | 2 |
| **58種(現行)** | **5** | **10** | 16 | 15 | 7 | **3** | 2 |

**この回で分かったこと**

- **先手勝率が60.4%から54.9%へ戻り、目標圏(45〜55%)へ収まった。**手番の補正は
  何も足していない。**軽い受けがプールに無かったことが、後手の1手の遅れを取り返せなく
  していた**と見られる。50種化の時点では「繰り返しトリガーがテンポの価値を上げたため」と
  読んでいたが、**先に手を入れるべきだったのはコストの分布のほうだった**
- **同じ効果でも、繰り返すトリガーに載せると高い。**「味方1体の攻撃力+1」は
  設置(ワンド)で +1.2、落砂(ソルト)で +1.6。トリガーだけを差し替えたカードは
  値付けも別物として測り直すこと
- **「自分の砂時計すべての砂を1粒落とす」は値段がマイナス(-0.4)。**攻撃力は増えるが
  体力が減るため、利点だけの効果ではない。ラトルはコスト2で総量5(基準線4.5より上)
- **「落砂:相手全体へ1ダメージ」はプールで最も高い(+6.9)。**毎ターン続く全体除去に
  等しく、コスト6でも総量3(基準線9.9)まで削ってようやく釣り合った。
  除去がコストで買えない(下記)のと同じ性質が、繰り返しトリガーにも出る
- **「攻撃できない」はコスト1でも安い。**ハスクはコスト1・総量6で48.0%(基準線3.2の
  ほぼ2倍)。ワッチャー(2/7)・ゲート(4/9)と同じ傾向

### ダスト(コスト2)を足した理由

**余砂(破壊されたとき)を持つカードが1枚も無く**、語彙として定義済み(GameDesign.md 6章)
なのにキーワード辞書に「まだこの能力を持つ砂時計はありません」と出ていた。既存の
`ON_DEATH × DAMAGE_PLAYER` の組み合わせだけで作れるため、エンジンには手を入れていない。

総量4で46.8%・総量5で55.7%(いずれも800戦×シード42/43の平均)と、**均衡は4と5のあいだ**
(およそ4.4)にある。整数ではこれ以上詰められないため、より50%に近い4を採った
(`docs/BalanceReport_v5.md` 5.3節の分解能の限界。グレインと同じ形)。

値段に直すと **+0.1** で、ほぼ無料にあたる。同じ「本体へ2ダメージ」でも
設置は +1.1 なので、**発動が破壊時まで遅れるぶんが1粒ぶん安い**ことになる。

**勝率の幅は 44.7〜55.0%(レンジ10.3pt)。**800戦での測定誤差が±3.5pt程度あるため、
この幅はほぼ誤差の範囲であり、**これ以上の調整は誤差を追いかけるだけになる**。
調整前(引き直し前)は 38.2〜59.5%(21.3pt)だった。

### グレイン(コスト1)を足した理由

**最小コストが2だったため、マナ1しか無い1ターン目は構造上どちらのプレイヤーも
何も出せなかった。**盤面へ触れないまま1手が過ぎるうえ、初見のプレイヤーには
手札が全て暗いことがバグと見分けられない。バニラの基準総量
`1.9 + 1.33 × コスト` はコスト1で3.2を指すため、総量3のバニラとして足した。

総量3で44.7%、総量4で54.5%(いずれも800戦×2シードの平均)と、**均衡は3と4の
あいだにある**。整数の総量ではこれ以上詰められないため、基準線の式に近い3を採った
(`docs/BalanceReport_v5.md` 5.3節の分解能の限界)。

### スプラウト(コスト3)を足した理由

**余砂の2枚目**。1枚では語の使い回しが効かず、トリガーとして定義した意味が半分しか出ない
(GameDesign.md 6章)。ダストが「余砂で本体を殴る」側なので、こちらは
**エコー(設置:カードを1枚引く)の余砂版**にして、同じ効果が設置と余砂でどう変わるかを
プール内で読み比べられるようにした。

総量4で42.1%・5で47.7%・6で51.5%・7で59.5%(いずれも800戦×シード42/43の平均)。
均衡は5.7付近で、より50%に近い6を採った。

値段に直すと **+0.2**。**設置:1枚引く(+2.7)より2.5も安い**。ダストでも設置(+1.1)→
余砂(+0.1)で1.0下がっており、**余砂は「遅れるぶん安い」どころか、ドローのように
盤面へ直接効かない効果ではほとんど値段が消える**。破壊されるまで手札が増えないため、
引いたカードを使うマナが残っていないことが多いのが理由と見られる。

### 同じキーワードをコスト違いで持つ組

**語(キーワード)にしているのは、2枚以上のカードに載っている4種だけ**
(GameDesign.md 6章)。1枚しか無い毒砂・吸命・連撃は語を使わず効果の文で書く。

| キーワード | 軽い方 | 重い方 |
|---|---|---|
| **守護** | シールド(2/4) | ガード(5/7) |
| **硝子** | グラス(3/6) | ミラー(5/7) |
| **速落** | ダッシュ(2/4) | ランス(4/6・貫通も持つ) |
| **貫通** | ドリル(3/7) | ランス(4/6・速落も持つ) |

**毒砂・吸命・連撃は50種になってもまだ1枚ずつ**であり、語へ昇格していない。
語彙の載せ替えでカードを作らない方針(GameDesign.md 6章)を採ったため、
2枚目を出すためだけのカードは足していない。

トリガーは分類なので載っている枚数に関わらず語のまま使う(GameDesign.md 6章)。
58種での内訳は次のとおり。

| トリガー | 持つ砂時計 |
|---|---|
| **設置** | ソード / エコー / アイ / ハンマー / スウォーム / スイープ / ペブル / フォージ / クラウン / パイク / ハロー / ブランク / ピボット / ワンド / ラトル |
| **反転** | グロウ / ホイール / ページ / ティック |
| **余砂** | ダスト / スプラウト / シェル / ブルーム / バースト / レガシー / フラスコ / シード / ハスク |
| **落砂** | アワー / メモリー / ドリップ / ウェル / タワー / アンカー / ソルト / オベリスク |
| **被弾** | クラック / テンパー / スパイク / バーム / バーブ / グリム |

### ハンマーとスイープを弱めた経緯(承認済み)

当初の「1体を破壊」「全体の砂を2粒削る」は、**総量を下限(2)まで削り、
コストを上げても勝率が下がらなかった**(スイープはコスト7で63.5%、9でも60.4%)。
除去の価値は周囲のカードの大きさに比例するため、コストという一律の値上げでは追いつかない。
効果そのものを弱めることで釣り合った。

## 砂術12種(基本セット)

砂術は**総量を持たず、コストと効果だけ**を持つ(GameDesign.md 6章)。
勝率は砂時計と同じ方式(そのカード2枚を含むデッキ vs 含まないデッキ)で
**各400戦×シード42/43の平均**を採った。**誤差は±5pt**であり、暫定値である。

`pool_index` は 59〜70 を与えた。

| 名前 | id | コスト | 効果 | 勝率 |
|---|---|---|---|---|
| **サンドショット** | shot | 1 | 相手プレイヤーに2ダメージ | 40.6% |
| **ひとつまみ** | pinch | 1 | 自分の砂時計1体の砂が2粒落ちる | 38.4% |
| **逆さ砂** | turn | 1 | 自分の砂時計1体を反転する | 37.1% |
| **砂嵐** | gust | 2 | 相手の砂時計すべての砂が1粒落ちる | 41.5% |
| **封砂** | seal | 2 | 相手の砂時計1体の効果とキーワードを消す | 37.4% |
| **砂の壁** | bulwark | 2 | 自分の砂時計1体に守護を与え、総量+2 | 47.6% |
| **砂へ還す** | recall | 2 | 相手の砂時計1体を持ち主の手札へ戻す | 47.2% |
| **砕砂** | shatter | 3 | 相手の砂時計1体に4ダメージ | 46.3% |
| **砂の補給** | refill | 3 | カードを2枚引く | 53.0% |
| **砂王の呼び声** | call | 3 | モートを2体出す | 42.4% |
| **砂塵嵐** | tempest | 4 | 相手の砂時計すべてに2ダメージ | 58.0% |
| **時の逆流** | reverse | 5 | 自分のHPを反転する(残りHPと失ったHPが入れ替わる) | 45.9% |

**勝率の幅は 37.4〜58.0%。**同じ回に測り直した砂時計(グレイン45.0% / シールド45.0% /
サンド47.3% / ソード50.5%)と比べると、**下に7〜8ポイント、上に7ポイントはみ出している**。
値付けはまだ収束していない(下記)。

**砂塵嵐(58.0%)は、はみ出したまま出すことを選んでいる**(ユーザー判断)。
全体2ダメージを1ダメージにすれば48.6%まで下がることは測定済みだが、
**プールに1枚くらい明確に強いカードがあったほうが面白い**という判断による。
弱い側の6枚とは扱いが違い、**これは調整漏れではなく意図した1枚**として記録しておく。

### 砂術ならではの4枚

GameDesign.md 6章は「少なくとも3分の1は、盤面へ駒を置かないからこそ成立する効果」を
求めている。それに当たるのは次の4枚で、**いずれも砂時計には持たせられない**。

- **時の逆流**:**残りHPと失ったHPを入れ替える。**砂時計の反転(上の部屋と下の部屋の
  入れ替え)をプレイヤー自身へ持ち込んだもので、このゲームの中心にある操作を
  そのまま体力へ写している。**HPが12を下回っているときだけ得になり(初期HP24化により
  15から変更)、満タンで撃つとその場で負ける**——効果の説明を読まなくても、
  砂時計の絵から挙動が推測できる唯一の砂術。勝率(45.9%)はHP24化後に測り直す
- **逆さ砂**:反転の「1体1ターン1回」「出したターンは不可」を無視する。
  駒の効果としてこれを書くと、その駒自身の制限と食い違う
- **砂へ還す**:盤面から駒を取り除いて手札へ戻す。**盤面を減らす唯一の非破壊の手段**で、
  設置効果を持つ駒を戻せば撃ち直せる
- **砂嵐**:相手全体の砂を1粒落とす。**体力を削ると同時に攻撃力を上げる諸刃**であり、
  相手の駒を寿命へ近づける代わりに一時的に殴られやすくなる

### この回で分かったこと

- **砂術はコストで釣り合わせられない。**確定破壊・全体除去と同じ形の壁で
  (`docs/BalanceReport_v5.md` 4.2節)、**弱い側でも同じことが起きる**。最小コストが1である
  以上、弱すぎる砂術を安くして釣り合わせる余地が無い。実測でも、コストを1から3へ動かした
  ときの勝率の差は測定誤差(±5pt)より小さかった。**釣り合わせる手段は効果の側にしかない**
- **「自分の砂時計の砂を2粒落とす」(ひとつまみ)は、思ったほど得ではない。**
  同じコスト1で「攻撃力+2」にすると52.2%だったものが、砂落としにすると38.4%まで下がる。
  **総量が変わらないため、攻撃力を得たぶんちょうど寿命が縮む**からで、
  砂を落とすことは強化ではなく**前借り**にあたる。速落(GameDesign.md 6章)の値段が
  +0.6と安いのと同じ理由がここに出ている
- **CPUは砂術を持て余す**(同10.5節)。1手ごとの貪欲法で1手番のマナ配分を見ないため、
  駒を出した残りのマナでしか撃てない。**実測値は砂術を過小評価している可能性が高い**

## 未検証・今後の課題

- **固有のイラストを持つ砂時計は1種も無い。**58種すべてがサンドの絵1枚の色違いであり、
  輪郭(アルファ)は58種で完全に一致する。かつてこの欄には「10種は固有」と書いてあったが、
  実測した結果それらもサンドからの色相回転・彩度・明度の調整で作られていた(いわゆる
  「剣モチーフ」に見えたソードは、サンドの彩度を0.18倍にしただけである)。
  **したがって見分けているのは紋章だけである**(GameDesign.md 9章)
- **50種になった時点で、色相だけでは見分けられない。**色相環へ均等に置いても隣との差が
  0.02しかなく、彩度を2段に分けても100種までは保たない。**種類をさらに増やすときは、
  色ではなく枠の形か装飾を変える手段が要る**
- **表の勝率はすべてデッキ20枚のときの測定であり、現行の30枚では測り直していない。**
  枚数はマリガンの事故率・疲労・引きの分散に効くため、値付けの前提そのものが動いている
  (`docs/BalanceReport_v5.md` 9章)。次にプールを触る回に30枚で測り直す
- **35種(50種化の27種 + マナカーブ調整の8種)は各400戦(誤差±5pt)でしか測っていない。**
  次にプールを触る回に800戦で測り直す
- **逆転率が37.3%になった**(目標25〜35%)。マナカーブ調整で先手勝率が60.4%から54.9%へ
  戻った裏返しにあたる(両者は連動する。GameDesign.md 7章)。2ポイントの超過は測定誤差に
  近いため、次にプールを触る回に測り直して判断する
