# 砂時計 駒一覧(Hourglasses)

このファイルは砂時計(カード)の個別データを管理する。
ルール・語彙・数値方針など駒デザインの前提は `docs/GameDesign.md` を参照すること(このファイルはその前提の上での「実データ台帳」)。

新しい砂時計を追加する際は、GameDesign.md 7章の語彙(トリガー×ターゲット×エフェクト)の組み合わせで表現し、この表に1行追加する。
既存の語彙で表現できない効果が必要になった場合は、先に GameDesign.md 7章への追記を提案すること。

## 現行10種類の砂時計

スキルは手番の行動として発動し、**反転の代わりに行う**(GameDesign.md 4.3)。スキルを使った
マスもその手番に進行するため、落下ダメージが高い駒ほどスキルを撃ちにくい。

| 名前 | 落下ダメージ | スキル | 受動効果 |
|---|---|---|---|
| **サンド** | 4 | なし | なし(バニラ、基準駒) |
| **ソード** | 3 | なし | 反転時:相手プレイヤーに1ダメージ |
| **シールド** | 2 | なし | 落下中の間:被ダメージ-1 |
| **ウォール** | 2 | なし | 相手に反転させられた時:相手に1ダメージ(カウンター) |
| **ジャッジ** | 2 | なし | 落ちきり中の間、毎ターン相手に1ダメージ |
| **ダッシュ** | 3 | **加速**:自分自身を1段階進める | なし |
| **ミラー(→)** | 2 | **位置交換**:右隣の自分の駒と位置を入れ替える | なし |
| **キング** | 1 | なし | 落ちきり中の間:被ダメージ-1 / 落ちきり時追加:自分に2ダメージ |
| **エコー** | 1 | **交代**:自分自身を控えの1個と入れ替える | なし |
| **アイ** | 0 | **目覚め**:落ちきっている自分以外の味方を2個まで上向きに戻す | 落下中の間:正面の相手をロック(反転不可) |

落下ダメージの合計は20。スキル制へ移行した直後は19(移行前と同じ)だったが、自己対戦で
スキル持ちを場へ出すこと自体が損だと分かったため、ダッシュを2→3へ上げている。

## スキル制への移行と、駒を作り替えた経緯

移動・交代は当初すべての駒が使える基本行動だったが、自己対戦での選択率がそれぞれ1.8%と、
1手番を費やす価値がなかった。そこで基本行動を「反転」だけに絞り、両者を駒のスキルへ移した
(GameDesign.md 4.3)。あわせて、勝率が下位に固まっていた5枚を作り替えた。

| 駒 | 変更前 | 変更後 | 意図 |
|---|---|---|---|
| ダッシュ | 落下2 / 反転時:自分を1段階進める | 落下2 / スキル「加速」 | 受動だった効果を能動化。反転と加速の選択が生まれる |
| ミラー | 落下2 / 反転時:右隣と状態同期 | 落下2 / スキル「位置交換」 | 隣接参照という持ち味を残しつつ、位置を動かす唯一の駒にした |
| エコー | 落下2 / 落ちきり時:味方ランダム1個を上向き | 落下1 / スキル「交代」 | 盤面を作り直す役割と交代が噛み合う。控えへ触れる唯一の駒のため打点を下げた |
| アイ | 落下0 / 落下中:正面ロック | 落下0 / スキル「目覚め」+ 受動はそのまま | 落下ダメージ0で機会費用が無く、毎手番スキルを撃てる0ダメージ枠の見本にした |
| ジャッジ | 落下1 / 落ちきり中:毎ターン1ダメージ | 落下2 / 同左 | 受動特化の駒として残し、打点だけ底上げした |

キングは落下ダメージを2から1へ戻した。「落ちきり中の間:被ダメージ-1」へ変更した際に打点も
上げた結果、勝率が51.3%から60.2%へ上がりすぎたため。

### 控えの扱いについて

交代がスキルになったことで、**交代スキルを持つ駒を入れないデッキでは控えの2枚が場に出ない**。
これは構築上の選択として意図したものであり、「デッキ5枚のうち何枚を実際に回すか」を編成の
判断に含める。控えを活かしたいプレイヤーは交代スキル持ちを採用する。

### キングの効果を変更した経緯

### キングの効果を変更した経緯

キングは当初「落下ダメージ1 / 落下中の間:被ダメージ-1 / 落ちきり時追加:自分に2ダメージ」
だった。しかし自己対戦の検証で、3つの要素がすべて「落ちきらせず落下中に留めろ」という同じ方向を
向いているため、**毎ターン反転して落下中を維持し続ける**以外の使い道がないことが判明した
(1試合あたり7.7回、自分の手番の約7割をキングの維持に費やしていた)。これは GameDesign.md 7章の
設計指針3(反転させられ続けると無限に得をする効果は避ける)の裏返しにあたる。

そこで軽減を「落下中の間」から「落ちきり中の間」へ移し、落下ダメージを1→2へ上げた。
「自傷2を1回払って落ちきらせ、以後は守りが続く」というリスク・リターンの明確な駒になり、
維持ループは1試合7.7回から0.25回へほぼ消滅した。

なお、軽減が「落ちきり中の間」になったことで、**落ちきった瞬間の自傷2にはキング自身の軽減
(-1)が適用され、実質1ダメージになる**。落ちきり時のダメージ適用より先にキングの状態が
落ちきりへ変わるためで、意図した挙動として扱う(自己対戦での測定もこの挙動を含んでいる)。
