## カードセット(仕様確定・実装一部着手)

仕様は GameDesign.md 8章・15章・21章(2026-09-09追記)、実装設計は Architecture.md 10.8.1節。
**基本セット以後のカードを、コンセプトごとの3〜15枚セットとしてショップで買い切り販売する**
方式に変更した。ガチャ・錬金は廃止(ロードマップのフェーズ44から外した)。

**所有の土台(`CardData.set_id` / `CardSetLibrary` / `players/{uid}.owned_card_sets` /
`AccountService.unlock_card_set()`)は、下のソロモードの実装と合わせて1本化して作る**
(Architecture.md 10.8.1節・10.15節で確認済み)。ソロモードの「ソロモードセット」
(`price = 0`。ショップには並べずステージクリアで解放)は、この土台の最初の利用例になる。
別々の所有データを2つ持つ案は採らなかった。

      関わらず含める。**「相手が使ってきた知らないカードが欲しくなる」ことを狙いとする
