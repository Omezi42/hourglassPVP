軽い受けをプールが持っていなかった。

### 値付けの宿題(ユーザー判断で当初案の数値のまま出している)

砂術12種のうち**6枚が測定で40%前後**にあり、同じプールで測り直した砂時計(45〜50.5%)より

- [x] **砂塵嵐(58.0%)は、はみ出したまま出す**(ユーザー判断)。全体2ダメージを
      1ダメージにすると48.6%まで下がることは測定済みだが、**プールに1枚くらい
