## 0. v2 系の3案がなぜ失敗したか

本編(スロット制)・付録A(コスト制)・付録B(注水制)は、いずれも砂時計を
**「効果が出るまでの待ち時間」**として扱っていた。

待ち時間はコストである。そしてコストは、それ自体では判断を生まない。
3案は結局いずれも**帽子をかぶったマナシステム**であり、砂時計は判断を増やしておらず、
摩擦を足していただけだった。根が同じなので、どう捏ねても同じ味になる。

v3 は、砂時計の**まだ使っていない性質**から出発する。

---

## 1. 出発点:砂時計は「二室ある対称な物体」である

砂時計はタイマーである前に、**上下2つの部屋を持ち、ひっくり返すと上下が入れ替わる**
対称な物体である。v1.0 を含め、この対称性をルールに使ったことは一度もなかった。

### 核となる3つのルール

> **1. カード1枚が、表と裏で別々の効果を持つ。砂の量も面ごとに異なる。**
>
> **2. 砂が落ちきると、そのとき「下」にある面の効果が発動する。**
>
> **3. 反転は遅延ではなく、どちらの顔を使うかの切り替えである。**

v1.0 の反転が退屈だったのは、反転しても同じ効果がまた出てくるだけだったため。
両面になった瞬間、反転は「カードを別のカードに作り替える」行為になる。

### 例

| ソード | 砂 | 効果 |
|---|---|---|
| **表** | 1 | 相手に **2** ダメージ |
| **裏** | 3 | 相手に **6** ダメージ |

反転が「**軽い連打モード ⇄ 重い一撃モード**」の切り替えになる。
付録A-1が4枚のカードに分けて表現していた「急ぐか待つか」の逆相関が、
**1枚のカードの表裏**に収まり、しかもリソースを一切必要としない。

## 2. 砂時計は使い捨てない

**落ちきったカードを墓地へ送らない。**

> 落ちきる → 効果が発動 → **停止した砂時計として場に残る** → 反転すれば裏の顔で再稼働

砂時計は本来、繰り返し使える道具である。盤面は「使って捨てる」ものではなく
**「回し続ける」**ものになり、次の判断が毎ターン生まれる。

- 停止した砂時計を**反転して再稼働**させるか(既知の効果をもう一度、逆の顔で)
- 手札の新しいカードに**入れ替える**か(枠は有限)
- どちらもせず、別の砂時計を**反転**するか

副産物として、**既存の3状態イラスト(満タン / 落下中 / 停止)がそのまま完璧に機能する**。

---

## 3. 対局の構成

- デッキ **15枚**(同名2枚まで)。HP **25**
- 場は各プレイヤー **4スロット**
- 初期手札は先手3枚・後手4枚。マリガン1回
- リソース(マナ・時)は**存在しない**

## 4. ターンの流れ

1. **ドロー** — 1枚引く
2. **メインフェイズ** — 次の2つを、**それぞれ1回まで**、好きな順で行える
   - **セット**:手札から1枚、面を選んで空きスロットへ置く
     (停止した砂時計の上へ**上書き**して置くこともできる。上書きされたカードは墓地へ)
   - **反転**:自分の場の砂時計1つを裏返す。面が入れ替わり、砂が満タンに戻って落ち始める
3. **ターン終了** — 自分の場の砂時計が**すべて1段階落ちる**。
   落ちきったものは左から順に、**下にある面**の効果を発動し、**停止**する
4. 手番を相手へ

**セットしたターンは落ちない**(次の自分のターン終了から落ち始める)。
**停止した砂時計は落ちない**(反転するまで動かない)。

---

## 5. なぜこれで局面が増えるのか

v1.0 の敗因は「毎ターン同じメニューが並ぶ」ことだった。v3 では、1手の選択肢が
盤面と手札の状態によって毎回作り替えられる。

| | v1.0 | v3.0 |
|---|---|---|
| カードの顔 | 1つ | **2つ(表裏)** |
| 反転の意味 | 状態のリセット(結果は同じ) | **効果の切り替え(結果が変わる)** |
| 盤面の構成 | 対局中ほぼ不変 | 上書き・入れ替えで変化し続ける |
| 非公開情報 | なし | 手札 |
| 1枚のカードが持つ局面 | 3状態 | 2面 × 砂段階 × 停止/稼働 |

**同じカードが盤面に居続けても、向きと砂の残量で毎ターン違う意味を持つ。**
これが「同じことの繰り返し」への直接の答えになる。

## 6. 両面カードの設計指針

- **表と裏は「強い/弱い」ではなく、性質の違う効果にする。**
  強弱だけだと、常に強い面を選ぶ単純な最適解が生まれる
- **砂の量で「速い顔/遅い顔」を作る。**軽い面は砂1〜2、重い面は砂3〜4
- **どちらの面も、単体で使う価値があること。**片面が完全な死に札なら、それは1面カードと同じ
- 一方の面に**常設効果**(場にある間ずっと効く)を置いてもよい。
  ただし停止中は効果を失うため、常設面は「落ちきって停止した状態で効く」ものとして書く

## 7. カード案(既存10種の翻案)

砂の量と効果量は仮。承認後にシミュレーションで詰める。

| カード | 表(軽い顔) | 裏(重い顔) |
|---|---|---|
| **サンド** | 砂2 / 相手に4ダメージ | 砂4 / 相手に9ダメージ |
| **ソード** | 砂1 / 相手に2ダメージ | 砂3 / 相手に6ダメージ |
| **キング** | 砂1 / 自分の他の砂時計をすべて1段階進める | 砂4 / 相手に8ダメージ |
| **シールド** | 砂2 / 自分のHPを3回復 | 砂2 / 停止中の間、自分の受けるダメージ-1 |
| **ジャッジ** | 砂3 / 相手に4ダメージ | 砂3 / 停止中の間、自分のターン終了ごとに相手へ1ダメージ |
| **エコー** | 砂1 / 1枚引く | 砂3 / 3枚引く |
| **ミラー** | 砂2 / 相手の場をすべて1段階戻す | 砂4 / 相手の砂時計を1つ破壊する |
| **アイ** | 砂2 / 相手の場の砂時計1つを**強制的に反転**させる | 砂4 / 相手の手札を1枚捨てさせる |
| **ダッシュ** | 砂1 / 自分の砂時計1つを1段階進める | 砂2 / このターン、もう一度反転できる |
| **ウォール** | 砂2 / 自分のHPを4回復 | 砂3 / 相手に3ダメージ、自分のHPを3回復 |

### 反転を軸にしたコンボの例

- **ダッシュ(裏)** で反転回数を増やし、1ターンに2枚の顔を切り替える
- **アイ(表)** で相手の砂時計を**強制反転**させる。相手が狙っていた面を裏返し、
  砂を満タンに戻して妨害する ── 相手の「切り替え」を逆手に取る妨害
- **キング(表)** で自分の場を一斉に進め、複数の砂時計を**同じターンに落ちきらせる**
