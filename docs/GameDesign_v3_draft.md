## 0. v2 系の3案がなぜ失敗したか

本編(スロット制)・付録A(コスト制)・付録B(注水制)は、いずれも砂時計を
**「効果が出るまでの待ち時間」**として扱っていた。待ち時間はコストであり、コストは
それ自体では判断を生まない。3案とも**帽子をかぶったマナシステム**であり、砂時計は
判断を増やしておらず、摩擦を足していただけだった。

v3 は、砂時計の**まだ使っていない性質**から出発する。

---

## 1. 核となる発明:砂時計は「二室ある対称な物体」である

砂時計はタイマーである前に、**上下2つの部屋を持ち、ひっくり返すと上下が入れ替わる**
対称な物体である。v1.0 を含め、この対称性をルールに使ったことは一度もなかった。

> **1. カード1枚が、表と裏で別々の効果を持つ。砂の量も面ごとに異なる**
>
> **2. 砂が落ちきると、そのとき「下」にある面の効果が発動し、その場で停止する**
>
> **3. 反転は遅延ではなく、どちらの顔を使うかの切り替えである**

v1.0 の反転が退屈だったのは、反転しても同じ効果がまた出てくるだけだったため。
両面になった瞬間、反転は「カードを別のカードに作り替える」行為になる。

## 2. 砂時計は使い捨てない ── カードは「装置」である

**落ちきったカードを墓地へ送らない。**停止した砂時計として場に残り、反転すれば
裏の顔で再稼働する。

これにより、砂時計は**「遅れて発動する呪文」ではなく、マナで設置して反転で回し続ける
装置**になる。この一点が、マナ制との相性を決定づけている(次章)。

副産物として、**既存の3状態イラスト(満タン / 落下中 / 停止)がそのまま完璧に機能する**。
新しいイラストは1枚も要らない(裏面は同じ絵を180°回すだけ)。

---

## 3. マナと砂は、役割が完全に分かれる

v2 の付録Aでは「マナを払う」と「落ちきるまで待つ」が二重のコストになり破綻していた。
v3 ではカードが場に残り続けるため、両者の意味が重ならない。

| | 意味 | 支払い |
|---|---|---|
| **マナコスト** | その装置を盤面に設置する権利の値段 | **一度きり** |
| **砂の量** | その面がどれくらいの間隔で発動するか | **繰り返す時間** |

- **砂が少ない面**(1〜2)= 小さい効果を**高頻度**で出す。反転して回し続けるエンジン
- **砂が多い面**(3〜4)= 大きい効果を**低頻度**で出す。数ターン仕込む大砲
- **停止中に効く面**(常設)= **動かさない**ことが利益になる置物

**同じ1枚のカードに、この3つの使い方が同居する。**

## 4. リソース:マナ

- 自分のターン開始時、**最大マナが +1 され、全回復する**(上限7)
- 先手の1ターン目はマナ1。持ち越しはしない
- **マナが許す限り、1ターンに何枚でもセットできる**
- **反転にマナは要らない**

マナは「盤面を広げる」ためだけの資源であり、「盤面を回す」のは反転が担う。
序盤はマナが装置の設置を制限し、盤面が埋まった中盤以降は反転の判断が主戦場になる。

---

## 5. ターンの流れ

1. **ドロー** — 1枚引く
2. **メインフェイズ** — 以下を好きな順で、何度でも
   - **セット**:手札から1枚、**面を選んで**空きスロットへ置く。マナコストを払う
   - **反転**:自分の場の砂時計を裏返す。面が入れ替わり、砂が満タンに戻って落ち始める
     - **1枚につき1ターンに1回まで**
     - **セットしたターンは、そのカードを反転できない**
3. **ターン終了** — 自分の場の**稼働中の**砂時計がすべて1段階落ちる。
   落ちきったものは左のスロットから順に、**下にある面**の効果を発動し、**停止**する
4. 手番を相手へ

- **停止中の砂時計は落ちない**(反転するまで動かない)
- セットしたカードは、そのターンの終了時から落ち始める。
  砂1の面でセットすれば、**そのターンのうちに発動する**(呪文的な使い方)

## 6. 盤面

- スロットは各プレイヤー **6枠**
- 停止中の砂時計も枠を占有する
- 空き枠が無いとき、**停止中の砂時計に上書きしてセットできる**(上書きされたカードは墓地へ)。
  稼働中の砂時計には上書きできない

6枠としたのは、**盤面の広さがそのまま局面の多様性になる**ため。4枠では、砂4の大砲を
2つ仕込んだ時点で残り2枠しかなく、エンジン(軽い装置)・大砲(重い装置)・置物(常設面)の
3つの役割を同時に成立させられない。6枠あれば、この3種を並べたうえで、なお1〜2枠を
状況に応じた入れ替えに使える。マナ上限7と噛み合い、盤面が完成するまでに
おおよそ6〜8ターンかかる計算になる。

---

## 7. この設計が生む判断

毎ターン、盤面の各装置について次を判断することになる。

| 装置の状態 | 判断 |
|---|---|
| **停止中** | 反転して再稼働させるか(逆の顔になる)/ 置いたままにするか(常設面なら効果継続) |
| **稼働中(落下の途中)** | 触らず落としきるか / **反転して進行を捨て**、別の顔へ切り替えるか |
| **落ちきる直前** | このまま発動させるか / 相手の妨害が届く前に別の手を打つか |

**反転すると砂が満タンに戻る**ため、稼働中の装置を反転するのは常に損である。
したがって基本形は「稼働中は触らない、停止したら反転して再起動」になり、
**相手にとっては「強制的に反転させる」ことが最も痛い妨害になる**(アイの表面)。

## 8. カード案(既存10種の翻案)

数値はすべて仮。承認後にシミュレーションで詰める。

| カード | マナ | 表(軽い顔) | 裏(重い顔) |
|---|---|---|---|
| **ダッシュ** | 1 | 砂1 / 自分の砂時計1つを1段階進める | 砂2 / 山札から1枚引く |
| **ソード** | 2 | 砂1 / 相手に2ダメージ | 砂3 / 相手に6ダメージ |
| **シールド** | 2 | 砂2 / 自分のHPを3回復 | 砂2 / **停止中の間**、自分の受けるダメージ -1 |
| **ウォール** | 2 | 砂2 / 自分のHPを4回復 | 砂3 / 相手に3ダメージ、自分のHPを3回復 |
| **サンド** | 3 | 砂2 / 相手に4ダメージ | 砂4 / 相手に9ダメージ |
| **エコー** | 3 | 砂1 / 山札から1枚引く | 砂3 / 山札から3枚引く |
| **アイ** | 3 | 砂2 / 相手の砂時計1つを**強制的に反転**させる | 砂4 / 相手の手札を1枚捨てさせる |
| **ジャッジ** | 4 | 砂3 / 相手に4ダメージ | 砂3 / **停止中の間**、自分のターン終了ごとに相手へ1ダメージ |
| **ミラー** | 4 | 砂2 / 相手の場をすべて1段階戻す | 砂4 / 相手の砂時計を1つ破壊する |
| **キング** | 5 | 砂1 / 自分の他の砂時計をすべて1段階進める | 砂4 / 相手に10ダメージ |

### コンボの例

- **キング(表)× 重い顔の装置** ── 砂4の大砲を並べておき、キングで一斉に1段階進めて
  **同じターンに複数を落ちきらせる**。落ちる順は左からなので、並べ方まで意味を持つ
- **ジャッジ(裏)× 反転しない選択** ── 停止させたまま置いておくと毎ターン1ダメージ。
  枠を1つ差し出す代わりの、遅いが確実な勝ち筋
- **アイ(表)× 相手の大砲** ── 砂4があと1で落ちきる瞬間に強制反転。
  **3ターン分の仕込みを丸ごと巻き戻す**、このゲームで最も痛い妨害
- **ダッシュ(表)× 自分の大砲** ── 1マナの軽い装置を、大砲の着弾を早めるための
  加速装置として盤面に常駐させる

## 9. 対局の構成

- デッキ **20枚**(同名2枚まで)。HP **30**
- 初期手札は先手3枚・後手4枚。マリガン1回。毎ターン1ドロー
- 山札が尽きたら、以降は自分のターン終了ごとに1ダメージ(疲労)

## 10. なぜ「同じことの繰り返し」が解けるのか

| | v1.0 | v3.0 |
|---|---|---|
| 反転の意味 | 状態のリセット(**結果は同じ**) | 効果の切り替え(**結果が変わる**) |
| カードの顔 | 1つ | 2つ |
| 1ターンの行動 | 1回 | マナの許す限りのセット + 装置ごとに1回の反転 |
| 盤面の構成 | 対局中ほぼ不変 | マナで拡張、上書きで更新 |
| 非公開情報 | なし | 手札 |

**同じカードが盤面に居続けても、向き・砂の残量・稼働/停止で毎ターン違う意味を持つ。**

## 11. 未決事項

- **1ターンが長くなりすぎないか。** 6枠すべてが反転可能だと、判断が多すぎて
  持ち時間3分では足りない恐れがある。反転を「1ターンに2回まで」等で絞る案もある
- **CPU の思考の組み合わせ爆発。** 反転の組み合わせ(最大2^6)× セットの組み合わせとなり、
  現在の `SmartCpuStrategy` の全探索は破綻する。貪欲法かビームサーチへの作り替えが必要
- 停止中に効く常設面が直感的か(「止まっている間だけ効く」という言い回し)
- スロット6枠・マナ上限7・HP30・デッキ20枚の妥当性(要シミュレーション)
- 相手への干渉(強制反転・破壊・手札破壊)の適正量
