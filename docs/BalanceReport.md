## 0. フェーズ21適用後の再検証(行動が進行を止めないルール)

### 0.1 何を変えたか

本レポート4章が指摘した「反転の83.6%が相手陣へ集中し、盤面が枯れて12.8%が膠着する」問題の
原因は、駒の数値ではなく**ルールの非対称**にあると判断した。旧ルールでは自分の駒を反転すると
自陣1マスの進行を失うのに対し、相手の駒を反転するコストはゼロだったため、妨害が一方的に得だった。

そこで「行動を設定したマスは進行しない」という条項を削除し、**行動の解決に続けてそのマスは必ず
進行する**方式へ変更した(GameDesign.md 2章・4.3・4.4)。反転・移動・交代のすべてがコスト
ゼロになり、行動の選択は効果の損得だけで決まる。

### 0.2 測定条件

`smart_vs_smart` 2000戦をシード42/43/44の3本、メタ進化(pop=24・15世代)をシード100/101/102の
3本。旧ルールの数値は本レポート2章(シード42・2000戦)およびベースラインのメタ進化(シード100)。
CPU(`SmartCpuStrategy`)は変更していないため、差分はルール変更のみに由来する。

### 0.3 全体指標

| 指標 | 旧ルール(s42) | 新ルール s42 | s43 | s44 |
|---|---|---|---|---|
| 引き分け(膠着)率 | **12.80%** | **3.00%** | 2.80% | 2.50% |
| 平均決着手数 | 48.8 | **22.2** | 21.8 | 21.4 |
| 中央値 / P90 | 28 / 200(上限) | 15 / 33 | 15 / 33 | 15 / 33 |
| 先手勝率(有効試合) | 57.45% | **60.7%** | 59.7% | 60.9% |
| 反転の比率 | 72.55% | 96.3% | 96.2% | 96.2% |
| **反転の内訳(自陣)** | **16.4%** | **64.4%** | 62.8% | 61.8% |
| 移動の比率 | 26.02% | **1.6%** | 1.7% | 1.7% |
| 交代の比率 | 0.67% | 1.6% | 1.6% | 1.6% |

3シードでほぼ同値のため、これらの差はノイズではない。

- **狙いは達成された。** 反転の対象が相手陣83.6%から自陣約63%へ逆転し、膠着は12.8%→2.8%へ、
  P90手数は上限200手から33手へ縮んだ。「双方が妨害しかせず盤面が枯れる」構造は解消された
- **決着が速くなりすぎている可能性がある。** 平均21.8手・中央値15手は1人あたり7〜11手で、
  コンセプトの「5分程度で1戦」に対して短い。初期HP20の見直しが次の論点になる
- **先手有利は悪化した**(57.5%→60.4%)。対局が速くなるほど先制の価値が上がるため
- **移動が死に要素化した**(26.0%→1.7%)。事前に想定したとおり、移動の価値の大半は
  「そのマスの進行を止めること」だった。交代は0.67%→1.6%と倍増したが依然として少ない

### 0.4 CPUの強さ(先手固定の交絡を解消)

本レポート2章の `smart_vs_random` はSmartがSide A固定で、先手有利と交絡していた。先後を
入れ替えて測り直した結果、**Smartは先手で99.4%、後手で99.1%**勝つ。思考の差が勝敗に直結する
という結論自体は正しかったことが確認できた(いずれも1000戦、シード42)。

### 0.5 駒別勝率の入れ替わり(3シード合算)

| 駒 | 旧ルール | 新ルール | 変化 |
|---|---|---|---|
| シールド | 43.2% | **58.2%** | +15.0 |
| サンド | 51.5% | 57.7% | +6.2 |
| ソード | 48.5% | 53.7% | +5.2 |
| キング | 39.8% | 51.3% | +11.5 |
| ウォール | 38.0% | 45.7% | +7.7 |
| エコー | 37.3% | 45.7% | +8.4 |
| アイ | 39.4% | 45.3% | +5.9 |
| ミラー | 40.5% | 45.2% | +4.7 |
| ダッシュ | 42.8% | 44.0% | +1.2 |
| **ジャッジ** | **54.8%** | **39.3%** | **-15.5** |

- **ジャッジ(落ちきり中に毎ターン1ダメージ)が最強から最弱へ転落した。** 盤面が枯れなく
  なったため、「全員が落ちきった盤面で唯一ダメージを出し続ける」という旧環境での優位が消えた
- **シールドとキングが大きく伸びた。** 落下中の駒を反転すると上向きへ戻ってから進行するので
  また落下中になる。つまり**毎ターン反転すれば「落下中」を永続できる**。被反転回数はキングが
  8.55回/戦・シールドが4.55回/戦と突出しており、「落下中の間」効果(被ダメージ-1)を維持し
  続ける戦術が確立している。キングは落ちきり時の自傷2も踏まずに済む
- この「毎ターン同じ駒を反転して落下中を維持するループ」は、GameDesign.md 7章の設計指針3
  (反転させられ続けると無限に得をする効果は避ける)の裏返しにあたる。次の調整の論点になる

### 0.6 メタの推移(pop=24・15世代・3シード)

| | 旧ルール(s100) | 新 s100 | 新 s101 | 新 s102 |
|---|---|---|---|---|
| エントロピー(初期3.29) | 2.93 | 2.83 | 2.72 | 2.86 |
| ユニークデッキ数 | 15 | 13 | 9 | 12 |
| ほぼ絶滅(<2%) | dash, mirror, wall | eye, judge, wall | dash, eye, judge, mirror | dash, judge |

- **多様性は改善していない**(エントロピー・ユニークデッキ数とも横ばい〜微減)。ルール変更は
  膠着と行動の偏りを直したが、駒同士のバランスには効いていない
- **サンド・シールド・ソード・キングの4枚は3シードすべてで15〜20%の高シェア**を占め、
  実質的な必須枠になっている
- **ジャッジは3シードすべてで1〜2%**まで沈み、明確な死に枠になった
- アイ・ダッシュ・ミラー・エコー・ウォールはシードによって0%〜18%と大きく振れており、
  pop=24・15世代ではまだ遺伝的浮動が支配的。これらの優劣を語るには規模を上げる必要がある

### 0.7 初期HP30とキングの効果変更(実施済み)

0.6までの結果を受けて、**初期HPを20→30**、**キングを「落下ダメージ2 / 落ちきり中の間:
被ダメージ-1 / 落ちきり時追加:自分に2ダメージ」**へ変更した(いずれもユーザー承認済み)。

キングの変更理由は、反転の内訳を状態別に測り直したことで判明した。**自分の駒を「落下中」で
反転した3857回のうち3852回がキング**であり、「落下中を維持し続けるループ」は
ルール全体の問題ではなくキング1枚に固有の現象だった(シールドは自分では一度も落下中を
反転しておらず、被反転は相手が軽減を剥がしに来ているもの)。キングは
「落ちきり時に自分に2ダメージ(=落ちきらせたくない)」「落下中の間 被ダメージ-1
(=落下中でいてほしい)」「落下ダメージ1(=落ちきらせる価値がない)」の3つがすべて
同じ方向を向いていたため、毎ターン反転する以外の使い道がなかった。軽減を「落ちきり中」へ
移すことで効果の向きをばらした。

#### 結果(2000戦×3シード / メタ進化 pop=24・15世代×3シード)

| 指標 | HP20・キング現行 | **HP30・キング案E** |
|---|---|---|
| 先手勝率(有効試合) | 60.4% | **53.7%**(53.0 / 54.3 / 53.7) |
| 引き分け(膠着)率 | 2.8% | **1.0%**(1.1 / 0.8 / 1.1) |
| 平均決着手数 | 21.8 | **26.2**(26.7 / 25.8 / 26.2) |
| 中央値 / P90 | 15 / 33 | **22 / 36〜38** |
| 反転の内訳(自陣) | 62.8% | 57.6% |
| 移動 / 交代 | 1.7% / 1.6% | 1.8% / 1.8% |
| キングの落下中自己反転 | 7.70回/戦 | **0.25回/戦** |

- **先手有利がほぼ解消した**(60.4%→53.7%)。手数が伸びて先制の価値が相対的に下がったため、
  後手補正ルールを別途設ける必要は当面なさそう
- **維持ループは消滅した**(7.70→0.25回/戦)
- 膠着率は1.0%まで下がり、平均26.2手・中央値22手と目標レンジに収まった
- **移動・交代は依然として死に要素**(いずれも1.8%)。この2つはHPやキングの調整では動かない

#### 想定外だった点

**キングの勝率が51.3%→60.2%へ上がりすぎた。** 落下ダメージを1→2にしたことに加え、
軽減が「落ちきり中」になったため**落ちきった瞬間の自傷2に自身の軽減が乗って実質1になる**
(docs/Hourglasses.md に明記済み)。ループは潰れたが、駒としては強化しすぎている。
落下ダメージを1へ戻すか、自傷を3にして実質2へ戻すのが次の調整候補。

**メタの多様性は悪化した。**

| | HP20・現行(s100/101/102) | HP30・案E(s100/101/102) |
|---|---|---|
| エントロピー | 2.83 / 2.72 / 2.86 | **2.64 / 2.46 / 2.82** |
| ユニークデッキ数 | 13 / 9 / 12 | **6 / 4 / 12** |

対局が長くなったぶん運の要素が減り、強いデッキがより確実に勝つようになったため選択圧が
強まったと考えられる。s100/s101では サンド・シールド・ソード・キング・ウォール の5枚へ
ほぼ完全収束した(各16〜20%)。**駒の数値格差がそのまま表面化しており、駒ごとのバランス調整が
次の主題であることがはっきりした。**

### 0.9 スキル制への移行(フェーズ22、実施済み)

移動(1.8%)・交代(1.8%)が1手番を費やす価値を持たないことが確定したため、基本行動を
「反転」だけに絞り、両者を駒のスキルへ移した(GameDesign.md 4.3)。あわせて下位5枚を作り替え、
キングの落下ダメージを2→1へ戻した(0.7の宿題)。測定条件は0.2と同じ。

| 指標 | フェーズ21(移動・交代あり) | **フェーズ22(スキル制)** |
|---|---|---|
| 先手勝率(有効試合) | 53.7% | **49.8%**(50.7 / 49.7 / 48.9) |
| 引き分け(膠着)率 | 1.0% | 3.0% |
| 平均決着手数 / 中央値 | 26.2 / 22 | **32.7 / 24** |
| P90手数 | 37 | 48 |
| 反転の比率(自陣) | 95.8%(57.6%) | 94.6%(55.0%) |
| 能動的な選択肢の比率 | 移動1.8% + 交代1.8% = 3.6% | **スキル4.9%** |
| メタのエントロピー | 2.64 / 2.46 / 2.82 | **2.80 / 2.62 / 2.79** |
| ユニークデッキ数 | 6 / 4 / 12 | **10 / 7 / 11** |

- **先手有利がほぼ解消した**(53.7%→49.8%)。3シードとも50%前後で、後手補正は不要
- **メタの多様性が改善に転じた**。フェーズ21で悪化した分を取り戻し、初期HP20の頃と同水準に戻った
- 移動・交代を4枚の駒へ集約したことで、能動的な選択肢の選択率は3.6%→4.9%へ上がった。
  ただし依然として反転が94.6%を占めており、**スキルが1手番を使う価値を持つとまでは言えない**
- 決着手数が26.2→32.7手へ伸びた。中央値24手は目標レンジ内だがP90が48手と長い

#### 駒別勝率(3シード合算)

| 駒 | 勝率 | 場に出た率 |
|---|---|---|
| サンド | 60.2% | 100% |
| ジャッジ | 59.6% | 78% |
| シールド | 51.2% | 28% |
| ソード | 50.1% | 34% |
| エコー(交代) | 47.8% | 16% |
| ウォール | 47.3% | 20% |
| キング | 46.9% | 79% |
| ダッシュ(加速) | 43.2% | 83% |
| ミラー(位置交換) | 43.0% | 83% |
| **アイ(目覚め)** | **35.3%** | 78% |

- **駒間の格差は広がった**(レンジ18.5pt→24.9pt)。アイ(35.3%)が明確に弱く、
  サンド(60.2%)とジャッジ(59.6%)が強い。ジャッジは落下ダメージ1→2の底上げが効きすぎた
- **この数値は配置ヒューリスティクスに汚染されている**。`SmartCpuStrategy` にスキル持ちを場へ
  置く固定ボーナス(`SKILL_ON_BOARD_BONUS = 25`)を入れたため、スキル持ち4枚の「場に出た率」が

  勝率を鵜呑みにしないこと**
- エコー(交代)の「場に出た率」は16%と最も低い。交代スキルは「自分自身を控えと入れ替える」
  ため、場に出す価値と交代する価値が噛み合っていない可能性がある

### 0.11 配置ボーナスの決定と、スキルの価値の検定

0.9で「駒別勝率が配置ヒューリスティクスに汚染されている」と書いた `SKILL_ON_BOARD_BONUS` を、
**CPU同士の総当たり**(0 / 10 / 25 / 45 / 70 の5値、各ペア120戦×先後、計960戦/値)で決めた。

| bonus | 0 | 10 | 25 | 45 | 70 |
|---|---|---|---|---|---|
| 勝率 | **72.2%** | 61.9% | 41.5% | 35.6% | 33.5% |

**0が圧倒的に強い。** つまり「スキル持ちを場へ置く」こと自体が、現在の駒設計では損だという
ことになる。これは配置ヒューリスティクスの調整ではなく、**スキルが1手番と場の1マスに
見合う価値を持っていない**という設計上の結論である。

そこで次の2点を変え、同じ総当たりを回し直した。

- **ダッシュの落下ダメージを2→3**(スキル持ちの打点が低すぎて場に出す価値がなかった)
- **「目覚め」を「落ちきっている味方を2個まで上向きに戻す」へ**。従来は落下中の味方も対象に
  していたため、**起こすことで自分の駒が落ちきるのを自分で遅らせる**という逆効果があった
  (GameDesign.md 7章の設計指針7として明文化した)

結果は 0=69.5% / 10=60.0% / 25=44.8% / 45=38.4% / 70=36.6% とほぼ変わらず、**0のまま**とした。
スキル2種を強化した程度では、場に出す価値は生まれない。

#### 汚染を取り除いた測定(2000戦×3シード)

|---|---|---|

| 引き分け率 | 3.0% | **0.2%** |
| 平均手数 / 中央値 | 32.7 / 24 | 25.0 / 22 |
| スキルの選択率 | 4.9% | **2.6%** |
| メタのエントロピー(s100/s101) | 2.80 / 2.62 | **2.83 / 3.08** |
| ユニークデッキ数(s100/s101) | 10 / 7 | **11 / 15** |

| 駒 | 勝率 | 場に出た率 |
|---|---|---|
| シールド | 62.7% | 100% |
| キング | 59.1% | 86% |
| サンド | 55.5% | 100% |
| ソード | 50.5% | 77% |
| ダッシュ(加速) | 47.0% | 80% |
| ジャッジ | 46.3% | 83% |

| ウォール | 44.8% | 36% |

- 勝率レンジは24.9pt→**18.9pt**へ縮み、メタの多様性も過去最良になった(ユニークデッキ15)
- 一方で対局が短くなり(32.7→25.0手)、**先手勝率が55.4%へ戻った**。手数と先手有利は
  連動しており、片方だけを見て調整すると取り違える
- **エコー(交代)の場に出た率は1%**。交代スキルは事実上使われていない

#### 交代スキルが機能しない理由(設計上の指摘)

交代は「自分自身を控えと入れ替える」。しかし**初期配置は自分で自由に選べる**ため、
控えの駒を場に出したいなら最初からそう置けばよく、わざわざ1手番と場の1マスを使って
入れ替える理由がない。交代に価値が出るのは「配置時には読めなかった形で盤面が悪化したとき」
に限られ、それだけでは1手番に見合わない。

交代を機能させるなら、**入れ替えそのものに付加価値を持たせる**(出てきた駒が落下中から
始まる、入れ替えた駒が控えで回復する、など)か、**控えを配置時に選べなくする**(ランダム化・
非公開化)といった、交代の前提そのものを変える必要がある。

### 0.12 次に検討すべきこと(いずれも未承認)




1. **スキルが「1手番+場の1マス」に見合う価値を持つよう作り直す**(最重要)。総当たりが
   示すとおり、現在はスキル持ちを場へ出さない方が強い。効果量を上げるだけでは足りず、
   スキルの設計そのもの(何ができるか)を見直す必要がある
2. **交代スキルの前提を変える**(0.11の指摘)。初期配置を自由に選べる限り、単なる入れ替えに
   価値は生まれない
3. **シールドの抑制**(62.7%)。落下中の間 被ダメージ-1 が、反転で落下中を維持しやすい
   現在のルールと噛み合いすぎている
4. **決着手数と先手勝率はトレードオフ**(25.0手で55.4% / 32.7手で49.8%)。どちらを優先するか
   決めてから駒を触ること
5. ~~`SKILL_ON_BOARD_BONUS` の値決め~~ → 総当たりで0に確定(0.11)
6. 判断材料を得るため、メタ進化の**母集団と世代数を増やし、シードも5本以上**にする

## 1. 検証方法と前提

### 1.1 検証の目的
従来のランダム行動CPUでは「放置しても勝手に働く駒」しか測れず、妨害・ロック・カウンターなど相手の行動に依存する駒（アイ、ウォール等）の価値が不当に低く評価されていた。
本検証では、盤面評価と合法手探索を行う強いCPU（`SmartCpuStrategy`）を構築し、これを用いた自己対戦およびデッキ進化ループを回すことで、人間同士の対戦に近いハイレベルなゲームバランスを定量検証する。

### 1.2 思考ロジックと探索アーキテクチャ
- **スナップショット探索**: `GameState` に軽量な内部スナップショット保存・復元（`save_snapshot()` / `restore_snapshot()`）を実装し、独立した探索用インスタンス上でシグナル副作用なく高速に局面展開。
- **評価関数**:
  - プレイヤーHP差（\( (my\_hp - opp\_hp) \times 100 \)、危険域での重み補正）
  - 決着判定（即座に \(\pm 100,000\)）
  - 自陣の期待値: 落下中（`FALLING`）駒の前進期待値（打点 \(\times 30\)）、落ちきり時効果、継続ダメージ（ジャッジ等 \(\times 45\)）、軽減効果
  - 相手陣の脅威度: 次手番で落ちきる相手の高打点駒（\(- \text{打点} \times 32\)）、相手の継続ダメージ駒
  - ロック状態のペナルティ / アドバンテージ
- **初期配置思考（`choose_placement`）**:
  - デッキ5枚から全順列（60通り）を評価し、左（上向き/交代口）、中央（落下中/即効）、右（落ちきり/反転前提）に最適な駒を配分。

### 1.3 シミュレーション・進化ループの設定
- **固定デッキ検証**: 1000〜2000試合（シード固定 `seed=42`、手数上限200手）
  1. `random_vs_random` (1000試合)
  2. `smart_vs_random` (1000試合)
  3. `smart_vs_smart` (2000試合)
- **メタ進化ループ**:
  - 集団サイズ: 24〜32デッキ
  - 世代数: 15世代
  - 対戦方式: 集団内総当たり（先後両方を対戦し先後バイアスを排除）
  - 世代交代: エリート保存（上位25%） + トーナメント選択 + 交叉（デッキ5枚の配合） + 変異（駒差し替え・配置再決定）
- **反実仮想テスト**:
  - メモリ上の一時上書き設定（`tools/balance/overrides/*.json`）を経由し、本体の `.tres` やソースコードを変更せずに調整案A / Bの挙動・メタ推移を検証。

## 4. 発見された問題点

### 1. 【一強構成の固定化と多様性の欠如】
- 「左: シールド(被ダメ軽減) / 中央: サンド(即落ち4点) / 右: ソード(初手反転1点)」の初動テンポがあまりに強力で、他のシナジー（ミラー同期、ダッシュ加速、ウォール反撃）を完全に駆逐している。

### 2. 【ウォール（カウンター）の構造的欠陥】
- ウォールは相手から反転された時に1ダメージを与えるが、賢い相手は**ウォールを完全に無視して他の高打点駒（サンド等）のみを反転妨害する**。
- 結果としてウォールは被反転回数が 0.22回/試合 と全く触られず、単なる2点バニラ以下として死に駒化した。

### 3. 【ミラー・ダッシュのバリュー不足】
- ミラー（右隣同期）やダッシュ（1段階加速）はギミックとしては面白いが、基礎打点が2と低く、サンド（4点）やソード（3点+1点）の基礎火力差に押し負けてメタから淘汰された。

### 4. 【交代（swap_in）アクションの死に要素化】
- 全手数の **0.67%** しか選ばれていない。
- 原因: 交代は左マスでしか行えず、交代したマスはそのターン砂が進行しないため、2ターン分のテンポロスが発生する。場に強力な3枚を維持して反転・移動を回す方が圧倒的に得であるため。

### 5. 【先手有利の存在】
- 有効試合における先手勝率は **57.45%**。
- 中央マスが `FALLING` で始まるため、先手が初手で中央のサンド（4点）を妨害されずに通しやすい構造が先手優位を生んでいる。

## 6. 人間によるプレイテストで確認すべき項目

統計シミュレーションでは捉えきれない、以下の体験的要素については実機での人間同士の対戦で確認することを推奨する：

1. **相手の初期配置読み（ブラフと心理戦）**:
   - 相手のデッキ5枚を見て「中央にサンドを置いてくるか、右にウォールを置いてくるか」の読み合いの楽しさ。
2. **演出テンポと納得感**:
   - 行動解決ズームや反転演出のテンポが、30手前後の決着に対して心地よいか。
3. **アイ（0点枠）のストレス度**:
   - 正面ロックされた側のプレイヤーのストレスが過大でないか（移動で正面をずらす対策が直感的に行えるか）。
4. **交代（swap_in）の操作頻度**:
   - 人間プレイヤーが控えの駒をどの程度活用するか（UIの分かりやすさ、控え選択時のハイライト誘導の有効性）。
