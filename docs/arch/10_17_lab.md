# 10.17 掲示板(ラボ)(GameDesign.md 29章)

**募集回・案・票の3つのコレクションで持つ。**プレイヤー側クライアントは既存の
`FirestoreClient`で「回の取得・案の一覧・投稿・投票」を行い、**お題の作成・非表示・
採用の確定は開発側だけが開くHTML管理ツールから行う。**1回1件・1人3票・自分へ入れない・
募集中だけ、の上限は**Firestoreのセキュリティルールで縛る**(投票数で決める掲示板は
票の水増しを許すと成り立たないため。11章の「クライアントを信頼する」方針の例外)。

## データ構造

| コレクション/ドキュメント | フィールド |
|---|---|
| `lab_rounds/{round_id}` | `title` / `detail` / `starts_at` / `ends_at`(unix秒) / `results_fixed`(bool) / `created_at` |
| `lab_proposals/{round_id}_{uid}` | `author_uid` / `round_id` / `card_name` / `description` / `card_kind`(`"hourglass"` / `"spell"`) / `hidden`(bool) / `good_count`(int) / `result`(`""` / `"adopted"`) / `source`(`"vote"` / `"tournament"`) / `created_at` |
| `lab_ballots/{round_id}_{uid}` | `voter_uid` / `round_id` / `proposal_ids`(Array[String]、3件まで) / `last_id`(直前に足したid) |

- **`round_id` は `r` + 開始日の `YYYYMMDD`(英数字のみ)。**案と票のドキュメントIDを
  `{round_id}_{uid}` にすることで「1回1人1件」「1回1人1枚の投票用紙」をIDの一意性で担保する
  (uidも英数字のみのため `_` で分けられる)
- 募集中かどうかは `starts_at <= 現在 < ends_at` で決まり、状態のフィールドを持たない。
  締切後、開発側が採用の印を付け終えたら `results_fixed` を立てる
- 大会の実装権(10.18節)の案は `round_id = ""` / `source = "tournament"` の自動IDで作る

## セキュリティルール(`firestore.rules`)

| 対象 | 許可 |
|---|---|
| `lab_rounds` | 読み取りのみ(書き込みは管理ツール=Admin SDKだけ) |
| `lab_proposals` 作成 | 本人・登録済み(`players/{uid}.login_id` が空でない)・IDが `{round_id}_{自分のuid}`・回が募集中・`good_count == 0` / `hidden == false` / `result == ""` / `source == "vote"`・文字数の上限 |
| `lab_proposals` 更新 | `good_count` だけが+1、自分の案でない、非表示でない、回が募集中、**同じ書き込みで自分の投票用紙の `last_id` がこの案になり、件数が1つ増えている** |
| `lab_ballots` 作成・更新 | 本人・登録済み・IDが `{round_id}_{自分のuid}`・`proposal_ids` が「前の内容 + `[last_id]`」で3件以下・`last_id` の案の `good_count` が同じ書き込みで+1されている |

票の書き込みは「投票用紙の更新」と「案の`good_count`+1」を1回の`commit()`へ入れ、
ルールが `getAfter()` で互いを確かめる。どちらか片方だけの書き込みは通らない。

## `LabRules`(`scripts/logic/lab_rules.gd`, static)

通信を持たない判定だけを集め、テストから直接叩く。

- `VOTES_PER_ROUND = 3`
- `is_open(round, now)` / `is_closed(round, now)` / `current_round(rounds, now)`(開いている回。無ければ空)
- `proposal_id(round_id, uid)` / `ballot_id(round_id, uid)`
- `votes_left(ballot)`、`can_vote(proposal, ballot, uid, round, now)`
- `viewer_order(rows, uid)`:募集中の並び。`hash(uid + id)` で並べ、人ごとに違い開き直しても同じ順
- `ranked(rows)`:締切後の並び。`good_count` 降順
- `status_of(proposal, round, now)`:自分の投稿の状態(掲載中/非表示/検討中/採用/得票)

## `LabProposalService`(`scripts/net/lab_proposal_service.gd`, static)

`AccountService` と同じ「`FirestoreClient`を受け取るstaticのみ」の流儀。

- `fetch_rounds(client)`:`lab_rounds` を `starts_at` 降順で直近 `ROUND_LIMIT` 件
  (単一フィールドの `orderBy` のみ。複合インデックスを要求しない)
- `list_round(client, round_id)`:`round_id` の等価フィルタ1本。非表示はクライアント側で除く
- `list_mine(client, uid)`:`author_uid` の等価フィルタ1本。`created_at` 降順はクライアント側
- `fetch_ballot(client, round_id, uid)`
- `submit(client, uid, round, name, description, kind)`:`LabModeration.quick_check()` を通してから
  `{"exists": false}` 前提で案を作る。既にあれば「この回には投稿済み」を返す
- `vote(client, uid, round_id, proposal_id)`:投票用紙と案を `updateTime` 前提で読み、
  `LabRules.can_vote()` を通してから2件の書き込みを1回の `commit()` で行う。競合したら読み直す

## `LabModeration`(`scripts/logic/lab_moderation.gd`, static)

`quick_check(name, description)`:空欄・文字数・禁止語の部分一致を投稿前に弾く。
ここで弾けないもの(商標・既存カードとの酷似・趣旨のズレ)は、掲載後に管理ツールで非表示にする。

## 管理ツール(`tools/lab_admin/`)

**バニラのHTML+JavaScript1枚**(ビルド不要)。Firestoreへは直接触れず、
Cloud Functions の `labAdmin`(`functions/lab_admin.js`)を経由する。認証は
`LAB_ADMIN_SECRET`(`firebase functions:secrets:set`)の共有シークレット1本で、
ツールは初回に入力を求めて`localStorage`へ保存し、以後`X-Admin-Secret`ヘッダーへ乗せる。

| action | 内容 |
|---|---|
| `list_rounds` | 回を新しい順に返す |
| `create_round(title, detail, starts_at, ends_at)` | 回を作る。期間が他の回と重なれば断る |
| `list_round(round_id)` | その回の案を非表示も含めて `good_count` 降順で返す |
| `set_hidden(id, hidden)` | 非表示の切り替え |
| `set_result(id, result)` | `result` を書く。`"adopted"` のときは**同じトランザクションで** `players/{author_uid}.owned_titles` へ `"proposer"` を足す |
| `fix_results(round_id)` | `results_fixed` を立てる(過去の回に採用の印が出る) |
| `grant_tournament_prize(...)` | 10.18節 |

## UI(プレイヤー側)

| クラス | 責務 |
|---|---|
| `LabTab`(`scripts/ui/lab_tab.gd`) | ホーム「つくる」タブ。タイルの副題に開いている回のお題を出す |
| `CardLabScreen`(`scripts/ui/card_lab_screen.gd`) | ヘッダー・3タブ(募集中/自分の投稿/過去の回)・一覧・取得。表示の切り替えだけを持つ |
| `LabThemeBand`(`scripts/ui/lab_theme_band.gd`) | 募集中の上部の帯。お題・補足・締切までの残り・残り票数・「案を出す」 |
| `LabProposalCard`(`scripts/ui/lab_proposal_card.gd`) | 一覧の1件。押すと `opened` を出す。得票数・採用・非表示・投票済みの印は渡された表示モードで描き分ける |
| `LabProposalDetail`(`scripts/ui/lab_proposal_detail.gd`) | 詳細パネル。全文と「この案に投票する」 |
| `LabSubmitPanel`(`scripts/ui/lab_submit_panel.gd`) | 投稿フォーム(説明は複数行の `TextEdit`・文字数の残りを表示)と、送信前の確認 |

## 採用時の称号付与

称号の所有は `players/{uid}.owned_titles`(10.8節の `owned_icons` と同じ形)。
`set_result(id, "adopted")` が `"proposer"`(「発案者」)を足す。
