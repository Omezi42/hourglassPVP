# v3.0(両面砂時計案)の検証レポート

`docs/GameDesign_v3_draft.md` のルールについて、**特殊効果を一切持たない
「マナコスト・砂の量・ダメージ」だけのカード**でシミュレーションを行った。
狙いは「両面という発明が本当に判断を生んでいるか」を、主張ではなく数値で確かめること。

## 検証方法

- v3 のルール(6枠・マナ上限7・自由設置・カードごとにターン1回の反転・出したターンは反転不可)を
  そのまま実装した対局シミュレータ
- カードは10種×2枚=20枚。コスト1〜5に対して発動レート(ダメージ÷砂)を 1.0〜3.0 で割り当て、
  軽い顔(砂1〜2)と重い顔(砂3〜4)を持たせた
- 思考は両者同一の貪欲AI。「残り想定ターン数のあいだに出せる総ダメージ」で面と設置を選ぶ
- 各条件 1200〜1500 戦

---

## 結論1:両面制は、ダメージだけでは何も生んでいない

**アブレーション(対照実験)の結果が決定的だった。**

| 条件 | 先手勝率 | 決着手数 |
|---|---|---|
| 両面が異なる(本来のv3) | 76.5% | 16.4手 |
| **両面を完全に同一にする**(反転しても何も変わらない) | **72.5%** | **16.3手** |

**反転で顔が変わっても、ゲームはほとんど変化しなかった。**
さらに、セット時にどちらの面を選んだかを数えると:

| | 片面が85%以上を占めるカード |
|---|---|
| ダメージのみ(両面とも dmg) | **10種中7種** |
| 一方の面を防御パラメータにした場合 | **10種中10種**(全カードで固定) |

### なぜこうなるのか

ダメージ量と砂の量は、**発動レート(ダメージ ÷ 砂)という単一の物差しに還元できてしまう**。
比較可能な 1本の尺度に乗った瞬間、常にどちらかの面が勝ち、選択は消滅する。

> **両面が判断になるのは、2つの面が「同じ物差しで比較できない」ときだけ。**

表と裏は、量の大小ではなく**種類の違う資源**(ダメージ / 防御 / 干渉 / ドロー)にしなければ
ならない。しかも「どちらが正しいか」が**相手の盤面に依存して変わる**必要がある。
純パラメータでは最適解が事前に計算できてしまうため、局面によらず一定になる。

## 結論2:先手勝率が壊滅的で、しかも調整の刻みが存在しない

| 条件 | 先手勝率 |
|---|---|
| HP30 / HP60 / HP100 | 71.6% / 76.5% / 64.7% |
| マナ上限 4 / 5 / 7 / 10 | 62.6% / 73.3% / 73.4% / 73.4% |
| 後手の初期手札 +1 / +2 / +3枚 | 76.4% / 75.4% / 75.9% |
| **後手の初期マナ +1** | **21.0%** |
| **後手の初期マナ +2** | **6.4%** |

- HP・マナ上限・後手の手札枚数を動かしても**先手有利はまったく改善しない**
- 一方、**後手にマナを1与えただけで先手勝率が 76.5% → 21.0% へ暴落する**

**1マナが勝率55ポイントを動かす。**つまりこのゲームはテンポに対して過敏すぎ、
先手76% と 後手79% の間に**適正な設定が存在しない**。手札を増やしても効かないのは、
律速がカード枚数ではなく**マナ**だからである。

---

## 結論3:逆転が起きない

装置は場に残り続け、破壊されないため、**両者のダメージ量は単調増加する**。
一度開いた差を縮める仕組みがルール上どこにも無く、勝敗は「どちらが先に盤面を
立ち上げたか」でほぼ確定する。先手有利が消えないのはこの構造の帰結である。

干渉要素(相手の砂時計を強制反転させる面)を10種中6種まで増やしても、
先手勝率は 68.7% までしか下がらなかった。**進行を巻き戻すだけでは、
積み上がった盤面の差は埋まらない。**

---

## 結論4:対局が短く、盤面が完成する前に終わる

HP60 で平均16.4手(各プレイヤー8ターン)。6枠が埋まりきる前に決着する。
盤面の広さを局面の多様性の源泉にする設計(v3 6章)が、実際には機能していない。

---

## 処方箋

| 問題 | 対策 |
|---|---|
| 両面が判断にならない | 表と裏を**種類の違う資源**にする。かつ**正解が相手の盤面に依存**するようにする |
| テンポ過敏(1マナで55pt) | マナ以外の律速を入れる(1ターンのセット枚数上限など)。マナだけを唯一の資源にしない |
| 逆転が起きない | 装置が**消耗する / 破壊される / 効果が盤面状況で変わる**仕組みを入れる。永続かつ単調増加の盤面は必ずテンポゲーになる |
| 決着が速い | 序盤のダメージレートを抑え、HPを上げる。盤面が完成してから勝負が始まるようにする |

**最重要は1つめ。**「カードが2つの顔を持つ」という発明そのものは、ダメージという
1本の物差しの上では成立しない。この発明を生かすなら、**面ごとに異なる種類の効果を
持たせることが必須要件**であり、「特殊効果なしのパラメータ調整だけで面白くする」ことは
このルールでは不可能である、というのが本検証の結論である。
