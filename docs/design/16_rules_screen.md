# 16. ルール画面(遊び方)

ルールを知らないまま対局へ入って離脱されることを防ぐための画面。ホーム画面の
「ルール」タブから入る。

- **テキストと、実際にレンダリングされた盤面を並べた「紙芝居」形式とする**。1ページは
  見出し1行・本文2〜4行・その内容を実演する盤面の3つで構成する。読み物だけでも、
  動く絵だけでも足りないため、必ず両方を対にする
- **盤面は挿絵ではなく、対局画面と同じ描画コンポーネントを同じデータで描いたものとする**。
  ルール画面専用の簡易イラストを別に用意すると、実際の対局画面と見た目がずれた時点で
  誤った予習になるため
- **ページに入った瞬間に、そのページの演出が1度だけ自動再生される**(砂が1粒落ちる /
  反転する / 相打ちで砂が砕ける)。「もう一度見る」で再生し直せる。**演出も対局画面と
  同じものを使う**。消える砂と落ちる砂の違い(4章)は文章より演出のほうが伝わるため、
  ここが本画面の中心になる
- **章を選んで飛べる目次を左に置く**。順に読ませる導線(次へ)と、あとから1点だけ調べに
  戻る導線(目次)の両方を持たせる。チュートリアルではなくリファレンスとしても使える
  ようにするため
- 操作はページ送り(前へ / 次へ)と目次のみ。**盤面はクリックを受け付けない**。
  対局と同じ見た目である以上、押せそうに見えるものが押せないことを避けるため、
  ホバーの反応も出さない
- 進捗は保存しない。次に開いたときは常に先頭のページから始める

## 章立て

| 章 | 見せること | 盤面 |
|---|---|---|
| 1 | 上の砂=体力 / 下の砂=攻撃力、合計が総量 | 砂時計1体を大きく |
| 2 | 毎ターン終了時に砂が1粒落ちる。体力0で破壊 | 1体が落ちきるまで |
| 3 | 反転。攻撃力が体力を上回ったら返す。**反転権は敵味方どちらの駒も反転でき、
  「1体1ターン1回・出したターンは不可」の制限を受けない。弱めてから同じ手番で
  仕留めるのが定石** | 1体が反転する |
| 4 | 場に出す。マナ・コスト・6枠・出したターンは動けない | 手札から台座へ |
| 5 | 攻撃は相打ち。**受けた砂は消え、落ちた砂は消えない** | 2体がぶつかる |
| 6 | キーワード(守護 / 硝子 / 貫通 / 速落) | 該当カードを並べる |
| 7 | 対局の流れ・勝利条件・**マリガン**・コイン | 6枠の盤面と情報帯 |

**3章と7章はそれぞれ2ページ・3ページ構成とする**(反転権・マリガンのぶんが1ページずつ
増える)。反転権の「弱めてから同じ手番で仕留める」という使い方は、この使い方を
教えないと宝の持ち腐れになる(2章)ため、ここで初めて案内する。
