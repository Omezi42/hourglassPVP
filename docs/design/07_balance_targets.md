# 7. バランスの目標値

自己対戦シミュレーション(CPUは中級)で次のレンジに収まることを確認する。
測り方・生データ・調整の経緯はすべて `docs/BalanceReport_v5.md` にある。

| 指標 | 目標 | 現状(70枚・デッキ30枚・HP24・反転権2/3) |
|---|---|---|
| 先手勝率 | 45〜55% | 51.0〜51.5% |
| 決着手数 | 20〜30手 | 20.1〜20.2手 |
| 本体ダメージで決着した割合 | 90%以上 | 100% |
| ユニットへの攻撃の割合 | 30〜60% | 47.5〜47.9% |
| 逆転率(中盤劣勢からの勝率) | 25〜35% | 32.1〜33.3% |

(800戦×シード42/43。BalanceReport_v5.md 12.4節)

**測るときの原則**

- **「本体ダメージで決着した割合」を必ず測る。**低いと対局がデッキ切れで決まっており、
  カードゲームとして成立していない
- **先手勝率と逆転率は連動する。**盤面の広がりを参照する逆転カード(スイープ・スウォーム)は
  構造的に後手を利する。片方だけ見て調整しない
- **手番の補正は1つだけ選び、重ねない。**コイン・1ターン目ドローなしは各約22pt、
  後手の手札1枚は約7pt動く。先手勝率が上振れしたらまずコストの分布を疑う
  (58種化ではコスト1〜2を足しただけで5.5pt戻った)
- **カード1枚の強さは混成デッキの平均勝率では測れない。**「そのカード2枚を含むデッキ」と
  「含まないデッキ」を直接ぶつける
- **デッキ枚数・初期HPを動かしたら、それ以前の実測値はすべて無効。**必ず測り直す
- **初期HP24(2026-09-05)**は時計の文字盤にちなむ数。HPを下げることは、クラス制の無いこの
  ゲームでは「対局の短縮 = 先行者有利の強化」にしか効かない(逆転率↓・先手勝率↑)。
  単独でこれ以上のHP調整は行わない。時の逆流の損益分岐点はHP12
