# 32. 攻略サイト

ゲームの外に置く閲覧専用のWebサイト。カードの一覧・人の対局から集めた統計・自分の対局の分析とリプレイを、
ゲームを起動せずに見られるようにする。**プレイヤーが記事を書く編集型のwikiにはしない**(荒らし対策と記事の管理を抱えないため)。

## ページ

| ページ | ログイン | 中身 |
|---|---|---|
| カード辞典 | 不要 | 最新版の全カード。名前・コスト・総量・効果と、図鑑と同じ詳細の絵。名前・効果の文で絞り込める |
| みんなの統計 | 不要 | カードごとの採用率と「そのカードを入れたデッキの勝率」、先手の勝率、平均手数、決着の要因の内訳 |
| ランキング | 不要 | ランクマッチの今シーズンの上位(ゲーム内のランキングと同じ並び・同じ範囲) |
| マイページ | 要 | 自分のオンライン対戦の全件と、その分析 |
| リプレイ | 要 | 自分の対局を選んで再生する |

## みんなの統計

- **人が指したオンライン対戦(22章の対局の記録)だけを数える。**CPU戦は数えない(22章と同じ理由)
- **版で絞り込める。**既定は「最新の版」、選択肢に「全期間」と過去の版を並べる。版の横にその版の対局数を出す
  (カードが変われば数字を混ぜられないため。22章)
- **ランクマッチだけ / ルームマッチを含める**を切り替えられる。既定はランクマッチだけ(友達対戦は真剣勝負とは限らないため)
- カード別の勝率には**「そのカードを入れたデッキで戦った勝率であり、カードの強さそのものではない」**という但し書きを
  表の上に出す(19章と同じ)。**対局数が少ないカードの勝率は薄く表示し**、20局未満は数字の代わりに「—」とする
- **1日1回まとめて更新する。**ページには最終更新の時刻を出す(終局のたびに書き換えると、サイトの読み手のぶんまで
  対局者の通信が増えるため)

## ログイン

- **ゲームで登録したIDとパスワードでログインする**(14章)。ゲーム内と同じアカウントであり、サイト用の登録は無い
- **ゲスト(IDを登録していないアカウント)はログインできない。**パスワードを持たないため。ログイン画面に
  「ゲームのアカウント画面でIDを登録すると、ここに入れます」と1行で添える
- サイトにパスワードは保存しない。ログインの状態はそのブラウザにだけ残り、ログアウトできる

## マイページ

- **オンライン対戦は全件を見られる**(リプレイの30件とは別の、消えない対局の記録を読むため。22章)。
  CPU戦は戦績の通算(19章)だけを出す
- 出す分析: 通算の勝率、先手・後手別の勝率、自分のデッキ別の勝率、相手が入れていたカード別の勝率、
  決着の要因、期間ごとの勝率の推移、対局の一覧(日時・相手の表示名・勝敗・手数)
- **他のプレイヤーの詳しい戦績は見せない。**他人について出すのはランキングの行と、自分の対局の相手としての表示名だけ

## リプレイ

- **再生できるのは自分が指した対局だけ**(12章)。マイページの対局の一覧から開く
- 再生はゲーム本体をページの中で起動し、ゲームのリプレイ再生画面(12章)をそのまま使う。
  サイトで再生の仕組みを作り直さない(ルールを2か所に持つと食い違うため)
- **対局と同じ版のゲームで再生する**(今のカードで昔の対局を再生すると手順がずれるため)。
  Godot本体を更新する前の版の対局は再生できず、その旨を出す
