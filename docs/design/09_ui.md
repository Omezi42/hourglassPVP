# 9. UI設計メモ

## 対局画面

見た目の現行仕様は下の「対局画面の見た目」が持つ。ここは構成・操作・演出の約束。

### 構成

- 上から順に「相手の情報帯 / 相手の場(6枠)/ 自分の場(6枠)/ 自分の情報帯 / 自分の手札」。
  手札は最も頻繁に触るため、情報帯より外側(画面最下部)に固定する
- **12枠の盤面は1枚の卓上として描く**(木の額 / プレイマット / 中央の真鍮のレール)。卓の外は暗く落とし、
  卓の後ろにだけ淡い光を置いて浮かせる。卓の面は濃紺のフェルトで四隅に金の唐草(木地のままだと駒の砂の琥珀色と近く駒が沈む)
- **台座は空き枠にも必ず描く**(どこへ置けるかを盤面から読めるように)。6枠はカード型のスロットではなく丸い台座
- **プレイマットは自分と相手で別々に敷く**。ショップ(21章)で買う見た目の品で、**既定は「なし」**(額・フェルト・レールだけ)。
  相手のマットは相手の設定を表示名等と同じ経路で受け取る。CPU戦はCPU専用、リプレイと観戦は既定(棋譜はマットを記録しない)。
  地は暗く模様は薄く、駒・台座・バッジのコントラストを落とさないことを見た目より優先する。**画像ではなくコード描画**で、
  持つのは地の色・模様の種類・縁の色だけ
- **情報帯**: HP・マナ・山札の残り・墓地の枚数。相手側は手札の枚数も(裏向きカードの列にはせず数字1つ)。
  名前プレートにはアイコン・称号・表示名(CPU戦はCPU専用アイコンと「AI思考体」等の称号)。
  **マナは数字とピップの併記**で、粒はいまの最大マナのぶんだけ並べる。**HPは真鍮の器に入った琥珀の砂**として見せ、数字は必ず読める色で置く
- **手札は革の「手元の面」の上に置く**。札が宙に浮いている状態にしない
- **画面左の余白(卓の左)は「直前の手」の列**。直近4件を上から新しい順に積む。積むのは設置 / 砂術 / 攻撃(→対象)/ 反転 / 反転権で、
  自分・相手どちらの手も積む(ターン終了・コイン・マリガンは積まない。盤面を変えた手だけを追えるようにするため)
- 山札・墓地は枚数バッジを持つ小さな山。押すと墓地の中身を一覧できる。山札の中身は見られない
- **画面右の行動の列**: 性格で3つの群にまとめる。手番の外の資源(反転権 / コイン)/ 手番(持ち時間の時計 / ターン終了。大きなボタン・列の中ほど)/
  対局の外(ログ / エモート / 投了)。投了はターン終了から最も遠い下端に置く(押し間違えを防ぐため)。
  列を画面中央へ移すことはしない(盤面の幅が削れる)。「反転」はこの列に置かない(下記)
- **対局画面にバージョンを出す**(不具合の報告と突き合わせるため。11章)

### 手札と場の見た目

- **手札のカードと場の砂時計は別の見た目にする**。手札はカードの枠を持つが、**場に出た瞬間に枠を捨て、台座の上に立つ
  砂時計そのものになる**。砂時計はそれ自体が状態を表示する器(上の砂=体力 / 下の砂=攻撃力)であり、枠へ閉じ込めると
  最重要の情報チャネルが潰れ、反転の演出も嘘になる。手札=カード / 場=ミニオンは既存DCGの標準でもある
- **数値の配置は既存DCGの慣習に合わせる**。手札は**コスト=左上 / 総量=右下**、場は**攻撃力=左下 / 体力=右下**、
  **場ではコストを出さない**。砂時計の上下の部屋へ数字を対応させる案は採らない(慣習から外れた配置は覚え直しを全員へ課す)
- 手札の名前とキーワードの行は、下の隅のバッジと封蝋が占める帯より上へ置く。**名前の高さはキーワードの有無に関わらず揃える**
- **イラストは体力と攻撃力の比で3枚を切り替える**(攻撃力<体力=上向き / 拮抗=落下中 / 攻撃力>体力=落ちきり)。
  場ではこの絵を大きく出し、砂の量を数値と並ぶ主要な情報として扱う。モチーフを生かすのは絵と演出の側で、数値の読み取りには持ち込まない
- **砂時計の絵は1組(3状態)だけを持ち、カードごとの色は数値(元の絵のid + 色相の回転量・彩度・明度)として持つ**。
  起動時に1組から作るため、カードを何種増やしても配布物は増えない。固有の絵を置けばそちらが優先される
  (基本の絵を品として売るのがカードスキン。31章)。色の数値は現行の絵から逆算した近似で、輪郭のコントラストがごくわずかに緩む
- **カード1枚ごとに固有の紋章(モチーフのアイコン)を添える**。全種が同じ絵の色違いである以上、
  **実際に見分けているのは紋章であり、色は「同じ絵に見えないための下地」に過ぎない**(50種で色相環の隣との差は0.02しか無い。
  彩度を2段に分けても100種までは保たない。さらに増やすときは色ではなく枠の形か装飾を変える)。
  紋章はカードのモチーフ(サンド=砂時計 / アイ=目 …)であって能力の分類ではない。能力系統の共通紋章を使い回す案は採らない
  - **カードを並べるすべての画面へ必ず添える**。図鑑・工房の在庫棚・編成中の棚はいずれも「絵の隅へ押した真鍮の印」で形を1つに揃える
  - **置き場は砂時計そのものではなく「載せている側」**: 場=台座正面の真鍮のメダル / 手札=左下の封蝋 / 詳細パネル=名前の左。
    駒の背後へ大きな透かしを敷く案は採らない(駒が128x168pxしかなく、はみ出した縁だけが見えて散らかる)
  - 素材は商用利用可・クレジット表記不要の外部アイコンから取り、出所を `assets/CREDITS.md` へ記録する
- **キーワードは短いラベルとして並べる**(紋章にしない。7種あり複数持つカードもあるため語で読ませる)
- **守護は対局画面の場でだけ形でも示す**(台座の輪を太い真鍮に)。攻撃の対象選択に直接効くため。手札・一覧・デッキ編集では
  ラベルだけ(枠を太くする強調はしない。選択中の枠と紛れる)。
  **硝子が残っているものはガラスに薄い光の膜**を重ね、1度使うと消える
- 出したターンのもの(動けない)は僅かに沈め、**攻撃済みは彩度を落とし**、**まだ攻撃できる自分の駒には控えめな印**を出す
- **砂術は砂時計の絵を持たず、紋章を中央へ大きく置き、総量のバッジを出さず、枠の色を変える**。場での見た目は存在しない

### 操作

- **出す**: 手札を押す → 空き枠が光る → 枠を押す。ドラッグでも出せる。マナが足りない札・**空き枠が無い間はどの札も暗くして出せなくする**
  (上書き設置は行わない)。設置効果が相手1体を対象に取る場合は出した直後に対象選択へ入る(対象がいなければそのまま出る)
- **反転**: 自分の駒を押す → **その駒のすぐ下に「反転」ボタン**が出る → 押す。できない場合はボタンを出さない。
  右の列へ置くと視線とカーソルの往復が遠く、上へ出すと相手の駒へ重なる。駒の下端と自分の情報帯のあいだへ収まる高さにする
- **反転権**(2章): 行動の列のボタン。残り0または自分の手番でないときは押せない。**残り回数は数字ではなく粒で示し、自分と相手の
  両方を並べる**(相手の残りが見えないと、相手の駒を弱めるか守るかの判断が立たない)。押すと**敵味方どちらの場も光り**、
  選んだ駒を反転させて残りが1減る
- **攻撃**: 自分の駒を押した状態で相手の駒か**相手のHP帯**を押す。ドラッグでも同じ。攻撃できる対象だけを光らせ、
  **守護がいる間は守護以外が光らない**
- **砂術**: 押すと空き枠ではなく対象が光る。対象を取らないものはその場で発動。ドラッグの落とし先は対象(取らないものは盤面のどこでも)。
  **空き枠が無くても暗くならない**(6章の例外)
- **攻撃の対象を選んでいる間、双方の予測後の数値を出す**(体力の減り方・破壊されるか)。戦闘は相打ちである以上
  「この攻撃で自分も死ぬのか」が毎回の判断の中心で、暗算させない。狙う相手にカーソルがある間はその1組の結果に置き換え、
  離れたら**最も自分が削られる組**(最悪の場合)へ戻す。HP帯を指しているときは本体を殴る場合の予測
- **選択は右クリックまたはEscでも取り消せる**
- **手札はホバーで手前へ大きく浮かせる**(押す操作は変わらない)
- **コイン**(後手のみ・1対局1度): 行動の列から押してマナ+1
- **マリガン画面**を対局前に挟む(2章)。暗幕の上に初期手札を大きく並べ、押すたびに選択が切り替わり、選ばれたものは沈んで
  引き直しの印(やり直しの矢印)を重ねる。確定ボタンは0枚なら「このままで開始」、n枚なら「n枚を引き直す」。相手が何枚交換したかは出さない。
  **見出しの上に自分が先手か後手かを出し、後手ならコインを持つことも添える**(残す札の重さの判断が手番で変わるため)
- **クリックできる要素は共通の挙動**: ホバーで明るく浮きカーソルが指に、押し込むと縮み、**要素の上で離した時のみ確定**。
  操作できない状態(相手の手番・観戦・再生中)ではホバー表現もカーソル変更もしない
- タッチ: タップ判定に許容マージンを持たせる。頻繁に押すボタン(反転等)は指でも押せる寸法を確保する

### 詳細パネル(ホバー)

- **対局中のカード・駒の効果詳細は、カーソルを乗せている間だけ表示する**。クリックで開く形は、自分の駒を読むだけで攻撃・反転の
  選択に入ってしまうため採らない
- **その代わりパネルに操作を要する要素を置かない**(語のボタンも実演も出さず、語と説明を文として並べる)。
  パネルへカーソルを動かす理由が無い状態にして初めて、外れたら消える形が成立する。語の意味と実演は砂時計図鑑に集約する
- 手札・自分の駒・相手の駒のいずれもホバーで出す。空き枠では出さない
- **中身の高さぴったりまで縮め、カーソルのすぐ近く(右下を既定、はみ出す側だけ折り返す)へ出す**。置き場の規則は1箇所で決め、画面ごとに持たない
- **上下の情報帯には掛けない**(HP・マナ・山札は読みながら判断するもの)。パネルは卓の範囲へ収める
- **出さない間**: 攻撃・設置効果・砂術の対象選択中 / マリガン中 / 演出の再生中
- カードから外れたら短い間を置いて消す(隣へ移る途中で点滅させない)。手札のホバー拡大(`hover_zoom`)は別に維持する

### エモート

- 行動の列の「エモート」ボタンは「ログ」「投了」と**まったく同じ寸法・作り**(クールダウン中も文言の頭は「エモート」のまま、残り秒数を後ろへ)。
  押すと4つの選択肢が真鍮枠のパネルに1行ずつ並ぶ(行頭に菱形)。選ぶと即送信、発言者の名札付近に吹き出しとして約3.8秒(完全不透明3.0秒)表示後フェード。送信後9秒のクールダウン
- **対局中に使えるのは4つまで**で、所有分からアカウント画面でセットする。ショップで増えても選択肢は常に4行(盤面を覆う面積のほうが損)
- 既定の4つ: 「よろしくお願いします」「見事な一手です」「なんだと…」「こちらに傾いているようですね」
- **マリガン中は送信できず、ボタン自体を出さない**(無効の見た目が隣の真鍮のボタンと並ぶと色が違って見える)
- 相手のエモートをミュートできる(ポップアップ内で切り替え)。CPU戦でも送れ、CPUも低確率で返す

### 演出

**原則**: ロジックは演出を待たず即座に解決し、演出は結果を後から見せる。演出中は盤面の操作を受け付けない。
**消える砂(被ダメージ・砕けて散る)と落ちる砂(ターン終了・下の部屋へ流れる)を演出で明確に分ける**——取り違えると4章のルールを誤解するため、
演出上もっとも重要な区別として扱う。

- **攻撃は、駒が対象の斜め上まで渡っていき、反動をつけて当てる**(線を引くのではなく「渡っていく」)。4段構成:

| 段 | 動き | 尺 |
|---|---|---|
| 寄る | 台座を離れ対象の斜め上へ。出だしを速く終わりを緩め、**上端をつままれてぶら下がった駒**として下端が遅れて振れる | 0.28秒 |
| 溜める | 上端を支点に振り子のように後ろへ傾く。砂も傾きに合わせて寄る | 0.14秒 |
| 当てる | 振り下ろしてコツンと当てる(叩き潰さない)。接触点で閃光と砂の破片 | 0.10秒 |
| 戻る | 小さく揺れながら台座へ戻る | 0.30秒 |

  - **相打ち**: 当たった瞬間に防御側も同じだけ砂を散らし、押し返されて揺れる。加えて**防御側の攻撃力が1以上なら、台座正面の
    紋章を攻撃側へ短く突き出してすぐ戻す**(砂が散るだけでは反撃に見えない)。攻撃力0の駒は突き出さない。
    誰が仕掛けたかは攻撃側の動きだけで示す
  - 相手プレイヤーを殴る場合も同じ動きで対象がHPバーになるだけ。**貫通は砕けた対象を通り抜けてHPバーまで届く**
  - **連撃は1回目が台座へ戻ってから2回目**(重ねる案は採らない。0.3秒の短縮にしかならず演出の進行を作り替える必要がある)
  - **同じターンで2回目以降の攻撃は尺を6割へ詰める**
  - **当たった瞬間、卓と駒だけをごく短く揺らす**(情報帯と行動の列は動かさない)。ダメージが大きいほど強く、上限あり。
    揺れている最中に次が当たったら足さずに大きいほうで上書きする
- **ターン終了の砂落ちは全ユニット同時**に1粒落とし、破壊されたものだけ続けて見せる
- **破壊は砕けて台座へ崩れ落ちる**。割れた瞬間にガラスの破片を砂より速く散らし(器が壊れたことを伝える)、砂は放物線を描いて台座へ溜まってから消える。
  同時に複数壊れた場合も同時に見せる
- **場に出した砂時計は台座の少し上から落ちて着地し、足元に砂が舞う**。着地と通常の反転では台座の銘板を短く光らせる(ドローの合図と同じ光の輪)
- **設置効果・トリガーは「そのカード自身の紋章が対象へ飛んで働きかける」**。光の筋だけでは何かが光っただけにしか見えない。
  単体・全体・敵味方を問わずすべて紋章で見せ、**光の筋が残るのは通常の反転だけ**。全体を狙う効果は対象の数だけ同時に飛ばす
  - **型**(効果の性質で動き方を変える): **打撃**(ダメージ・破壊・本体への直接ダメージ)=弧を描いて飛び当たると膨らみ盤面を揺らす /
    **恵与**(味方の強化・キーワード付与・回復)=低い山なりで舞い降り金色の輪が広がる、揺らさない / **払拭**(効果を消す)=直進して
    くすんだ輪へ収縮 / **反転**(体力と攻撃力の入れ替え)=回転しながら飛び、届くと対象が通常の反転と同じ演出で裏返る
  - **出どころ**: 駒=駒の中心から即座に / **砂術**=自分の情報帯の上で紋章が大きく浮き上がってから飛ぶ(対象を取らないものはその場で弾けて光の輪だけ)/
    **余砂**=砕けた台座に銘板だけが残り、それが飛ぶ(飛ぶ先が無い効果は銘板がその場で光って消える)
  - **砂へ還す**は紋章が対象を包み、駒が縮んで持ち主の手札の方向へ吸い込まれる(壊れたのではなく戻ったと読めるように)。
    **時の逆流**は自分のHPバーの上で紋章が一回転し、届いた瞬間に数値が入れ替わる
  - **ドローを起こす効果**は山札の脈打ちに加えて、その駒の紋章の周りへ短い光の輪(どのカードが引かせたかを示す)
- **砂術は撃った瞬間に墓地へ置く**。上の浮上が「手札から消えただけ」に見えないための代わりを務める
- **反転は誰が手を出したかが分かる演出にする**: 反転した側の陣地から対象へ光の筋が伸び、届いた瞬間に駒が持ち上がって回転し着地する。
  **中心となる行動のため他より作り込む**——筋の後ろに金の砂粒が尾を引き、着弾で放射状の光条、回転はわずかに行き過ぎてから戻す(手でひっくり返した手応え)
- **硝子が無効化したとき、膜が割れる閃光を出す**(次の攻撃が通るかを判断できるように)
- **ドローは山札から手札へ札が流れる動き、疲労は山札を赤く脈打たせてからHPバーへ数字を飛ばす**
- **ダメージはフローティング数字**。発生源の駒が特定できればその駒からHPバーへ飛ばし原因の駒を光らせる。
  **大きいダメージほど文字を大きく強い色にし、高く浮かせる**。回復は緑で大きさを変えない
- **手番の切り替わり**: 自分の手番になった瞬間、盤面中央に「あなたの番」を一瞬大きく出す(誘導対局では出さない。手番の流れはすなえるの帯が案内するため。18章)。相手の手番の間は相手の情報帯を光らせ自分を落とす
- **相手の1手は1手ずつ見せる**: 対象の駒へスポットライトを当て、**対局ログと同じ文言**をその駒の近くへ浮かせ、間を置いてから次へ
- **効果音**: 出す / 反転 / 攻撃(相打ち)/ 被弾 / 決着 / ボタン押下 の6種。**CC0素材に限る**(クレジット管理のコストを負わないため。CC BY等は不採用)。
  **同じ音源を高さで鳴き分ける**(破壊は被弾より低く、硝子の膜割れは高く。同じ出来事は必ず同じ高さ)。砂時計が壊れた音は被弾と別に鳴らす
- **BGM**: タイトル(厳かで壮大)/ ホーム系 / 対局 の3曲をクロスフェードで繋ぐ。**パブリックドメインのクラシック(ピアノソロ)**。
  オーケストラは強弱の幅が大きくBGMに向かない。楽曲として完結するためループせず、終端の数秒前からフェードして間を置いて頭から鳴らす「アルバム再生」。
  結果画面ではBGMを止め勝敗別の短いジングル(CC0・ピチカート等)。ブラウザの自動再生制限のため最初のクリックを検知してから再生する
- **音量は「効果音」「BGM」の2系統**をホーム右上のハンバーガーメニューのスライダーで独立に調整し `user://` へ永続化。
  メニューには音量の下に**公式Discordサーバーへの導線**(公式マークだけの正方形ボタン、真鍮へ塗り替えない。別タブで招待リンク)

### 結果とログ

- **対局ログ**: 各手番で誰が何をしたか、砂の進行で何が起きたかを記録して表示する。**決着そのものも1手として記録**(「先手の勝利(後手のHPが0)」等)
- **結果パネル**: 勝敗・両者の最終HP・総手数・決着の要因・獲得した砂金(15章)・「もう一度」「ログ」「ホームへ」。背景を暗くして盤面を塞ぐ。
  対局・観戦で共通。**「もう一度」は同じデッキでもう1局で、当面CPU戦にだけ置く**(オンラインの再戦は同意の仕組みが要る)。
  終局後も「ログ」からログを開け、閉じると結果パネルへ戻る。**リプレイ再生モードでは結果パネルを出さない**(手を前後させる妨げになる)
- **QOL**: 残り15秒以下で時計周辺に緊迫感の演出(脈動・砂粒・警告色)/ **打点アシスト**(いま直接攻撃できる総攻撃力。守護がいればその旨、倒しきれるなら「決着可能」)を相手の情報帯のHPの器の右隣へ枠なしの「見出し + 数字」で表示(枠で囲うとボタンに見える) /
  卓のメダリオン等を押すと歯車が回る・砂埃が舞う軽い反応(相手の長考中の手持ち無沙汰)

### 対局以外の画面

- **起動して最初に出るのはタイトル画面**。ゲーム名「砂時計アリーナ」。どこか(またはEnter/Space)を押すとホームへ。
  置くのは開始の導線とアカウントへの入口だけ。ホームからタイトルへ戻る導線は設けない
- **タイトルロゴは王道クラシカル**(金の箔押し文字に濃紺の縁取り、上に砂時計の紋章、下に飾り罫)。**紋章・題字・罫はすべて同じ金箔(上が明るく下が琥珀の縦グラデーション)と濃紺の縁で描く**(部品ごとに色が違うと1つのロゴに見えない)。**英字のサブタイトルは置かない**。
  ロゴは作品の絵として画像アセット扱いだが、未配置の間もコード描画で同じ構図を出す。背景もタイトル専用が無ければホームを流用
- **タイトル→ホームだけは専用の演出**: 押すとロゴが光って伸び上がり、金色の砂が上から画面を満たし、覆いきったら差し替えて砂が下へ抜ける
- **ホーム画面**は画面下部5タブ(アイコン+ラベル)「たたかう / そろえる / きろく / おぼえる / つくる」。
  **タブは行いで分ける**(対局の入口を複数のタブへ散らさない)。**選択中はせり出させ文字を大きく、非選択は沈めて彩度と明るさを落とす**
- **入口の強弱は3段に固定**: 塗りつぶした真鍮の面(そのタブでいちばんやってほしいこと1つだけ)/ 暗く凹んだパネル(同格の選択肢)/ 文字だけ(補助情報)
- **ホームの札は「見出し + いまの状態を1行」**(デッキ編集=選択中のデッキ名・枚数・数、図鑑=収集数、ショップ=砂金)。
  中身そのものは見せず、右に紋章の透かしを額縁の内側に収めて敷く(上限あり)。砂時計の絵を大きく透かす案は採らない。
  札はタブの領域を使いきる高さにするが行は増やさない
- **ホームは「たたかう」を初期選択**(初めての人は誘導対局を経てからホームへ来るため。18章)
- 画面遷移は0.2秒未満のクロスフェード。通信待ちは文言の末尾に巡回するドット
- **たたかう**: 上の枠「だれかと」(ランダムマッチ / ルームマッチ / ランクマッチ)・下の枠「ひとりで」(CPU戦「好きなデッキで1局」/ ソロモード
  「決まった条件の関門に挑む」/ リーサルパズル「1手番で仕留める」)。固定の数を副題に書かない。
  **「前回の対局へ戻る」は最上段の帯**(戻れるときだけ・急ぐ用件を上へ)。対局前に**デッキ選択画面**を挟む(前回の選択が初期値。
  保存デッキが無ければプリセット「基本」で入る)。**ルームマッチだけは専用画面の中でデッキを選ぶ**
- **おぼえる**: 「遊んで覚える」(誘導対局)と「読んで覚える」(遊び方・画面の見かた・キーワード辞書)の2枠
- **そろえる**: 左に大きな「デッキ編集」、右に縦2列で「砂時計図鑑」「ショップ」。ショップをヘッダーの砂金チップへ移す案は採らない
- **きろく**: 上の枠「ミッション」(**今日の3つと進み具合を札に並べ、受け取れるものがあれば下部タブと札の両方に印**)、下の枠「戦績」「リプレイ」
- **砂金の残高は真鍮の小さなチップ**。文言は「砂金 1,500」に統一し3桁区切り。増えたときだけ脈打たせて数え上げる。
  ホームのヘッダーにアカウントボタン(表示名、未設定なら「ゲスト」)と並べて置き、対局から戻るたびに更新する

### 砂時計図鑑・デッキ編集

- **砂時計図鑑は机に開いた見開きの本**(左=一覧 / 右=選んだ1枚の解説)。全種を保有の有無に関わらず並べ、未保有は輪郭と「?」
  (砂時計と砂術で形を分ける)。**収集済みの印は置かない**(同じことを2度言うことになる)。全体の進捗は「収集 9 / 70」の1行
  - 1件ごとにコスト(左上の菱形)と総量(右下の丸。砂術は「術」)。砂術は絵の代わりに紋章
  - **右のページの砂時計は押すとひっくり返せる**(操作を促す表示は置かない。砂術は裏返らない)
  - 右ページ下部に「あなたの記録」(共に戦った対局数・勝率。19章の数字を引くだけ)
  - 戻ると並び替えは紙面の外へ。**並び順はコスト順(既定。同コストは砂時計が先・砂術が後 → 総量の小さい順 → id順)と追加順**
    をボタン1つで往復し、保存しない。**id順は並びとして使わない**(内部の識別子で追加順とも一致しない)
  - **能力の実演**: カード詳細に実演枠を設け、そのカードの能力が盤面で何を起こすかを数秒のループで見せる。
    **カードごとではなくキーワード / 効果の種類ごとに1本**(カードが増えても自動で付く)。バニラには「基本の砂の動き」。
    **紙に刷った図版(インクの線画)**で描き、部品(砂時計・HPバー・矢印・守護の輪・硝子の膜・砕けた印)の組み合わせで組む。
    基本の砂は1粒ずつ落とし、省略は「…」で。**文は「何が起きるか」だけを持ち、「いつ」はトリガーから組み立てる**。
    実演を出すのは図鑑と辞書だけ(対局中・デッキ編集の詳細は持たない)
- **デッキ編集は「左=全カードの一覧(グリッド)/ 右=編成中のデッキ」の2カラム**。一覧の探しやすさを最優先(横1行の横スクロールは23種で破綻した)
  - 左の操作行に**「絞り込み」ボタン**(コスト・キーワード・名前検索をモーダルへ集約。適用中は条件数バッジ、一括リセット)
  - 右は「デッキ名・枚数 / **30枠の棚(横6×縦5)**」。編成中のデッキは棚に並べた砂時計そのものとして見せる。
    枠の数はデッキ枚数と一致させ、**空き枠がそのまま「あと何枚」を示す**(帯もマナカーブの棒グラフも置かない。並びがコスト順固定のため)。
    空き枠は棚に彫った受け皿に薄い砂時計の影。**同名2枚は隣り合う2枠**(「×2」にまとめない)。駒にはコスト・総量・紋章・名前
  - 一覧の札を押すと1枚加わる(「2/2」なら暗くするが詳細確認のクリックは受ける)。**棚の枠を押すとその1枚が在庫へ戻る**(増減ボタンは持たない)
  - 一覧の札は**ホバーで掴めるカーソル**へ変わりドラッグで棚へ入れられる(他画面の `HourglassCard` は通常カーソル)
  - **詳細はホバーで出し、操作を要する要素を置かない**(対局画面と同じ規則・同じ置き場)
  - **保存は30枚ちょうどのときだけ通す**。名前は10文字程度まで。プリセットを読み込める(18章)
- **デッキ一覧**: 横長カード(デッキ名 + 代表的な砂時計のアイコン)の**横2列グリッド**、編集・削除ボタン、「使用中」バッジは出さない。
  並び替えはヘッダーの「デッキ入れ替え」から専用モードへ。対局前のデッキ選択も同じ一覧を流用(選ぶだけ)
- **共有**はデッキ編集のヘッダーから開く1パネルに**デッキ表(画像)とデッキコード**を並べる(渡す方法が2つあることに気づけるように)
  - **デッキコードは8桁の数字。中身はサーバーへ預けて番号だけを渡す**(30枚の組み合わせは8桁へ収まらない)。
    発行はボタンを押したときだけ、同じ構築には同じ番号、預けたデッキは消さない、カードのidと枚数で持つため増減しても読める
    (プールから消えたカードを含むものだけ読めない)。通信が要り、失敗はその旨を1行で
  - **デッキ表は1280×720の画像**。上から「デッキ名と枚数 / 30枠の棚(横10×縦3)」で、**編成中の棚と同じもの**を使う。
    隅に作品名とバージョン、コードを発行済みならその番号(画像のために発行しない)。共有パネルにはその画像をそのまま映す。
    **「画像をコピー」と「画像を保存」**。コピーはクリップボードAPIを試み、iframe等で拒否されたら画像をオーバーレイ表示して
    右クリックからコピーできるようにする。ブラウザ以外は保存のみ

### 共通のレイアウト規約

- 基準解像度1280x720・16:9。アスペクト比を維持し、縦横比の異なる端末では黒帯で16:9を崩さない。PCのホバー操作を最優先
- **対局画面を除く全画面**: 外周余白24px、上部に高さ88pxの共通ヘッダー(左=戻る / 中央=画面タイトル / 右=主アクション0〜3個)、
  その下24pxの余白、コンテンツは y=136 から。画面ごとに個別に決めない
- **一覧が空のときは領域中央に「砂時計の印 / 見出し / 次にすることの1行」**だけを出す(押せるものは置かない)。
  通信待ちも同じ形で見出しの末尾へ巡回ドット(見出しの位置は動かさない)
- **「戻る」はヘッダーを持たない画面(図鑑・工房)でも同じ形(左向きの五角形)**。位置と形だけ共通で大きさは画面に合わせてよい
- **一覧は横2列のグリッドを基本**とし、カードは横長・低背にする(縦1列は1画面に2〜3件しか入らない)
- **UIクローム(ボタン・パネル枠・入力欄・棚板・名札)はコード描画**。無地の図形では平坦でチープに見えるため、多段グラデーション・
  面取り・内側の落ち込み影・グレイン・金属の照り返しを伴わせる。描画は共通ライブラリへ集約し画面ごとに個別実装しない。
  **砂時計のイラストと背景イラストは画像のまま**(作品の絵そのもの)
- **背景イラストを持たない画面は「場所」として描く**: 書庫(ルール・辞書・画面の見かた)/ 記録室(戦績)/ 控えの間(デッキ一覧・
  ルーム・パズル選択)/ 帳場(ショップ)/ 無地(対局)。部品(板壁・棚・引き出し・作業灯・吊り看板)は共通に持ち、画面は組み合わせを選ぶだけ。
  壁は奥にあるものとして扱い、中身の乗る帯は「板目が見えていて文字も読める」ところまで落とす
- 全画面について、大手DCG/ソシャゲのUIを参考に、公開して恥ずかしくない見た目へ作り込む

## 対局画面の見た目

他の画面と同じく「場所として読める」画面にする。方向は**濃紺ベルベットの卓 + 吊りランプの
一点光源**。UIはコードで描く。

| 要素 | 決めたこと |
|---|---|
| 場所 | 暗い石の広間。卓の真上の真鍮の吊りランプ(相手の情報帯の中央の空きから見える)が唯一の光源で、卓・情報帯・手札・行動の列はすべて真下へ落ち影を持つ |
| 卓 | 額と面を台形に描き(手前が広く奥が狭い)、**相手の列の駒を0.92倍**にして奥行きを出す。フル3Dにはしない。面は濃紺のフェルト |
| 台座 | 平たい円ではなく、上面の楕円と側面の帯を持つ真鍮の器。守護の太い輪・選択の水色の輪は上面の縁に掛ける |
| 情報帯 | **1枚の板で囲わず、真鍮の器具を横に並べる**(板を囲う額を太くしても「UIの矩形」のままで卓に負けた)。**左の群**は 肖像のメダル / 名札(称号を上・表示名を下)/ HPの器(右端に赤い丸で現在HP)、**右の群**は帯の右端へ詰めて マナの計器(青い丸に現在値・右へ最大値ぶんの粒・コインは肩の金貨)/ 山札・墓地・手札の札。**中央は空けて吊りランプを見せる**。上下の帯で同じ位置に同じものを置く(自分側は手札の札の位置を空ける)。**色の語彙は盤面と揃える(青=コスト/マナ、赤=体力/HP)**。手番の側はメダルの外の琥珀の輪が脈打ち、攻撃の的の間はHPの器の縁が赤く脈打つ |
| 行動の列 | 右端の縦1列を1枚の濃紺のパネルとして描き、丸い真鍮のボタンを収める。**縦の間隔は群の中(狭い)と群の間(広い + 区切り線)の2種類だけ**。ターン終了は大きな丸。反転権は紋章を彫った一回り大きいメダル + 自分/相手の残り回数の粒の札。**持ち時間の時計はここ**(ターン終了の真上)に置き、いま手番の側の残りだけを懐中時計の面に出す。時計を持たない対局は「∞」で、時計そのものは消さない |
| 手札 | 革の面の上、札の上端を卓の額の下端へわずかに重ねる。札の面は「絵の窓 / 名前の帯 / キーワードの行」の3段。地は羊皮紙寄りの明るい紙、真鍮の額(砂術は青系)。**絵の窓の奥にそのカードの砂の色の光だまり**を敷いて色違いの1枚ずつを立たせる(色は色相表から求める)。四隅は 左上=コスト / 右下=総量 / 左下=封蝋 のまま、コストと総量は真鍮の縁で嵌めた宝石として描く |

| 直前の手 | 1件は濃紺の板に真鍮の縁(名札・山の札と同じ語彙)。左端の色(自分=琥珀 / 相手=赤)と「自分 / 相手」で誰の手か、手の種類とカードの紋章・名前でどのカードかを示す。新しい1件は左から滑り込み、古い件は1段下へ滑る |

見た目とは独立に保つもの: 画面の構成、数値の位置、砂時計の絵、演出、詳細のホバー、対象選択・ドラッグ。

## 操作への反応(手触り)

演出の派手さではなく、**押した・掴んだ・置いた・取り消したという操作のひとつひとつに画面が
返事をする**ことで手触りを作る。いずれも既存の要素の反応を細かくするもので、新しい画面要素は
増やさない。実装済み。細部の尺・振れ幅は実機で詰める(TODO.md)。

**対局画面**

- 手札: ホバー中の札の両隣が外へ避ける / ドラッグ中の札は動く方向と逆へ遅れて傾く(攻撃の
  「上端をつままれた駒」と同じ物理)/ 空き枠へ放したら指の位置から台座の中心へ滑ってから着地 /
  引いた札が入るとき他の札がスライドして場所を空ける / 相手の手番の間は手札を少し沈める
- マナと数字: 札にホバー中はそのコストぶんのピップが光る / 支払ったピップは札の方向へ吸われて
  消える / 駒の体力・攻撃力のバッジは値が変わった瞬間に小さく跳ねる
- 対象選択: 狙える相手にホバーすると駒がわずかに縮んで輪郭が脈打つ(身構え)/ 攻撃のドラッグ
  中は駒から指先へ矢印を引く / 右クリック・Escの取り消しで光っていた枠は短く縮んで「戻る」
- 音: ボタン・手札・駒にカーソルが乗ったとき、押下音を高く小さく鳴らす(音源は増やさない)。
  ターン終了の砂落ちの音はCC0素材が揃うまで保留

**メニュー画面群**(ホーム・デッキ編集・図鑑・ショップ・アカウント・各一覧)

- 全画面: ボタンの押し込みをもう一段深く(ハイライトが沈み影が薄くなる)/ クロスフェードに
  進む方向の横移動を足す(進むときは右から、戻るときは左へ)/ Esc・右クリックで戻る /
  共通ヘッダーのタイトルは着地でごく短く浮いてから止まる
- ホーム: タブ切り替えで中身が横へ滑る / `HomeTile` のホバーで紋章の透かしが浮く / 副題が
  外部要因(砂金・ミッション)で変わった瞬間に光る / 砂金チップへ獲得ぶんの粒が飛んでから数え上げる
- デッキ編集: 一覧の札を棚へ入れるとき札の位置から枠へ飛び、戻すときは逆向き / 2枚目で
  「2/2」バッジが跳ねる / 30枚ちょうどで棚全体が一度淡く光る / 絞り込みモーダルは押した
  ボタンの位置から膨らんで開く
