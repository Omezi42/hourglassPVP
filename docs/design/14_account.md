# 14. アカウント

対局の記録(リプレイ)と通貨(15章)をプレイヤー個人に紐づけて保存するための仕組み。

- **アカウントを作らなくても遊べる**。起動した時点で匿名のアカウントが自動的に用意され、
  そのまま全ての機能を利用できる(**掲示板〈ラボ〉への投稿・投票を除く**。29章)。
  ただし匿名のままだとブラウザのデータを消した時点で記録と通貨が失われるため、
  その旨をアカウント画面に明示する
- **IDとパスワードを自分で決めて登録できる**。登録するとその2つでログインでき、
  別の端末・別のブラウザからでも同じ記録の続きを遊べる。メールアドレスは取得しない
- **IDは他のプレイヤーと重複できない**。既に使われているIDで登録しようとした場合は
  その旨を表示して登録を拒否する
- **パスワードを忘れた場合、そのアカウントは復旧できない**。メールアドレスを取得しない以上、
  再設定の案内を送る手段が存在しないため。登録画面にこの注意を明記する
  (将来メールアドレスを任意項目として追加すれば解決できるが、現時点では扱わない)
- **匿名で遊んでいた記録は、登録した時点でそのまま引き継がれる**。登録は新しいアカウントを
  作る操作ではなく、いま遊んでいる匿名アカウントにIDとパスワードを結びつける操作として扱う
- **自動ログイン**:一度ログインすれば、次に起動したときは自動的に同じアカウントへ復帰する。
  匿名アカウントもこの対象とし、起動のたびに別人になることがないようにする
- **ログアウトできる**。ログアウトすると新しい匿名アカウントで遊ぶ状態に戻る。登録済みの
  アカウントの記録は消えず、同じIDとパスワードで再びログインすれば戻れる
- **表示名を持つ**(10文字程度まで)。対局中の「先手/後手」の表示と、リプレイ一覧の
  対戦相手の表示に使う。未設定の場合は従来どおり「あなた/相手」と表示する。表示名は
  いつでも変更でき、ID(ログインに使う文字列)とは別物として扱う
- **表示名に使えるのは、同梱フォントが字形を持つ文字だけとする**。絵文字・ハングル・
  アクセント付きのラテン文字・大半の記号は字形が無く、そのまま出すと豆腐(□)になる。
  **フォールバック用のフォントを同梱して対応する案は採らない**。絵文字だけで約10MBあり、
  pck全体(約4MB)の何倍にもなってブラウザでの起動待ちがそのぶん延びるため、
  日本語圏向けの作品として釣り合わない。入力欄では使えない文字を受け付けず、
  「この文字は使えません」と1行で示す。**相手から届いた表示名も同じ基準で通し**、
  使えない文字は「?」へ置き換えて表示する(自分が我慢しても、相手のクライアントが
  送ってきた名前で自分の画面が化けるため)
- **対局画面の名前欄は、自分側には常に自分の表示名を出す**(オンライン対戦・CPU戦のいずれも)。
  相手側は、オンライン対戦では相手の表示名、**CPU戦では「CPU」**とする。誰と戦っているのかが
  一目で分かる状態にするため
- **アカウント画面**を用意し、タイトル画面とホーム画面の両方から開けるようにする。
  画面には現在のアカウントの状態(匿名か登録済みか)・表示名・通貨の残高を表示し、
  未登録なら「登録」、登録済みなら「ログアウト」の導線を置く。ログイン導線も同じ画面に置く
- サーバー側での正当性検証を行わない方針(11章)はアカウントにも適用する。認証そのものは
  認証サービスに任せるが、通貨や記録の内容はクライアントの申告をそのまま信頼する

## アイコンと称号
プレイヤーの個性を表現するため、アイコンと称号を設定できる。

- **アイコン**:
  - アカウント画面で一覧から好きなアイコンを選択・変更できる。
  - 初期状態で選択可能なアイコンは砂時計の紋章(流砂、時計、王冠、大盾、宝剣、真眼、光輪、閃光)の8種とする。
  - **アイコン・エモート・プレイマット・カードスキン(31章)は「所有」を持つ**。初期から持っているのは上の8種と
    エモート4種、プレイマット「なし」(卓に何も敷かない既定の状態)で、それ以外は
    ショップ(21章)で砂金と引き換えに解放する。**すなえるアイコンもショップの品とする**。
    **ただしカードスキンの設定場所はアカウント画面ではなく砂時計図鑑**とする
    (カードの数だけ行が要り、アカウント画面には並べる場所が無いため。31章)。
  - **プレイマットもアカウント画面で設定する**(ショップは買う場所であって、設定する場所を
    兼ねない)。所有しているものだけを一覧に出すのはアイコンと同じ。
  - **所有しているものだけをアカウント画面の一覧に出す**。持っていないものを暗く並べて
    「買えばここに増える」と示す案は採らない。**その役目はショップの側が果たしており**、
    設定する場所に買えないものが混ざると、選ぶための一覧が品書きを兼ねてしまう。
  - 所有しているアイコンが増えても縦に伸びないよう、一覧はスクロールできるようにする。
  - 未設定時の既定値は「流砂(`sand`)」。
  - ホーム画面ヘッダー、アカウント画面、対局画面(PlayerInfoBar)に表示される。
  - CPU戦でのCPUのアイコンは専用アイコン(`cpu`)とする。
- **称号**:
  - アカウント画面で一覧から好きな称号を選択・変更できる。
  - 称号が増えても一覧しやすいスクロール可能なリスト形式で表示する。
  - 初期状態では「駆け出し決闘者(`novice`)」(ゲーム起動で自動獲得)と「称号なし(`none`)」から選べるようにする。
  - **これ以外の称号は、獲得した人だけが選べる**(例:掲示板〈ラボ〉で採用された投稿者だけが選べる「発案者」。29章)。
  - 未設定時の既定値は「駆け出し決闘者(`novice`)」。
  - 対局画面の名前プレート上部に小さく表示される。
- **アカウント画面のレイアウト**:
  - 画面の高さいっぱいに収まる**2カラム構成**(幅1060px)とする。
    - **左カラム(プロフィール設定)**: 名札見本(リアルタイムプレビュー)、表示名変更、アイコン一覧グリッド、スクロール対応の称号リスト、「プロフィールを保存」ボタン。
    - **右カラム(アカウント登録・ログイン)**: 登録・ログイン・ログアウトの操作および注意事項。
  - ボタンは全てゲーム世界観に統一された真鍮スタイルのボタン(`CodedButton`)を使用する。
- **保存と同期**:
  - 表示名と同様に `players/{uid}` に保存され、ログインした全端末で同期される。
  - オンライン対戦時、相手のアイコンと称号も取得して対局画面に表示する。
