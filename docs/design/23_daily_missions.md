# 23. デイリーミッション

毎日更新される課題を達成することで、通貨「砂金」を獲得できる継続プレイ用の仕組み。

- **仕様概要**:
  - 毎日午前0:00(JST)に**3つのミッション**が提示される。**選び方は日付から決める**
    (乱数で選ぶと、起動し直すたびに違う課題が並び、狙って進められない)。
  - 候補は次の7つで、ここから3つが出る。

| 課題 | 報酬 |
|---|---|
| 落砂を10回発動する | 50 |
| 反転を8回行う | 50 |
| 砂術を3回撃つ | 50 |
| 砂時計を20体場に出す | 50 |
| 15回攻撃する | 50 |
| 1勝する | 100 |
| 3回対局する | 50 |

  **3つすべてを達成しても1日150〜200**にあたる。砂金の使い道はショップ(21章)だけであり、
  日課で入る量を厚くすると、そこに並ぶ品が相対的に安くなって買う判断そのものが消える。
  **入手を増やすときは、ショップの価格の側も併せて見直す。**

  - **進捗の記録**: 対局終了時(CPU戦・オンライン問わず、10手以上)に対局中のアクションが集計され、自動的に進捗が進む。**数えるのは自分の行動だけ**で、相手の反転や砂術は進まない。「反転」には反転権で駒を反転させた回(相手の駒を含む)も入れる(反転権も反転の操作であり、別扱いにすると課題の文言と食い違うため)。10手に満たない対局を数えないのは、開始直後に投げ捨てて回すのを防ぐため(15章の砂金と同じ線)。
  - **ミッション画面**: きろくタブの「ミッション」から開くモーダルで、達成したものは「受取」ボタンで砂金を獲得する。**通信できないときは受け取れない**(残高はアカウントにあり、手元で受取済みにすると権利だけが消えるため。21章のショップと同じ扱い)。
  - **課題は日をまたぐと入れ替わり、進捗も消える**。貯めておくものではない。

## はじめの7日

**来た日の数が7日に達するまで、その日はじめてホームを開いたときに砂金を受け取れる。**
初日に遊び終えた人へ、次の日にまた開く理由を1つ渡すため。

| 来た日 | 受け取るもの |
|---|---|
| 1日目 | 100砂金 |
| 2日目 | カードセットを1つ選んで受け取る |
| 3〜6日目 | 100砂金 |
| 7日目 | 400砂金 + アイコン「すなえる」 |

- **数えるのは来た日の数で、連続していなくてよい。期限もない。**休んだ人を罰しないため
- 7日ぶんの砂金(900)はカードセット1つの値段にあたる。最初の買い物をはじめの1週間で体験させるため。
  はじめの1週間だけの入手なので、ショップの価格は据え置く
- **2日目は、ショップで売っていてまだ持っていないカードセット(段階公開中を含む)から1つを選んで受け取る。**
  100砂金(アイコン1つ)では次の日に開く理由として弱く、対局の中身が広がる品を初日から予告するため。
  受け取ったセットは買ったときと同じく、そのままデッキ編成に使える。持っていないセットが無ければ100砂金を渡す。
  アカウントごとに1回だけの配布で毎日の入手量は変わらないため、ショップの価格は据え置く。
  2日目を過ぎた人へ遡っては配らない
- 日付の境目はミッションと同じ日本時間の0時。受け取った日数と最後に受け取った日はアカウントに持つ
  (端末を替えても数え直さないため)。いま遊んでいる人も、受け取った日数が7に満たなければ対象になる
- **ホームを開いたとき、今日のぶんがまだなら暗幕の上に札を出す。**見出し「はじめの7日」、7つの日の粒(受け取った日は真鍮、
  今日は琥珀で脈打たせ、先の日は沈める)、粒の下に各日の報酬(「100」「セット」「400」)、今日受け取るもの、
  主ボタン「受け取る」。押すと受け取り、札を閉じる。粒の下の報酬は、初日から先の日に何があるかを見せるため
- **2日目の札は、持っていないカードセットをショップと同じタイル(絵・名前・価格)で並べ、1つ選ぶと「受け取る」と
  「収録カードを見る」(ショップと同じプレビュー)が押せる。**価格を出すのは、受け取る品の値打ちを伝えるため
- **通信できないときは札を出さない**(ミッションの受取と同じく、手元で受取済みにすると権利だけが消えるため)。次に通信できたときに出す
- 7日目の「すなえる」をすでに持っていれば、砂金だけを渡す
- **CPU戦の結果パネルに、明日受け取れるものを1行で出す**(「明日来ると カードセットを1つ選べる ・ はじめの7日 2/7」)。
  今日のぶんを受け取っていて、7日に達していないときだけ出す。CPU戦の結果パネルが、初日の遊びの終わりになることが多いため
