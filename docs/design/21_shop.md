# 21. ショップ

砂金(15章)を使う唯一の場所。ホーム画面の「ショップ」から入る。

- **売るのはアイコン・エモート・プレイマット・パック(8章)**とする(15章)。称号は
  売らない——名札の上に出る短い文字列であり、買ったことが見た目にほとんど現れないため、
  同じ額を払う品としてアイコン・エモートと並べられない
- **「砂の海」はプレイマットの標準的な1枚としてショップに並べる**(価格は下記の標準1500)。
  既定は「なし」であり、この砂紋の布も他のマットと同じく買って設定する対象とする
- **カードの見た目を替える品(カードスキン)は売らない**。砂時計の絵はカード1種ずつに固有の姿を持つ(9章)ため、
  別の姿を品にすると標準の絵と見た目の質が競合する。以前に買ったスキンは、1枚500砂金をプレゼント(33章)で補償し、
  #お知らせで案内する
- **「品揃えは固定」はアイコン・エモート・プレイマットに限る。**日替わりにも、ランダムにもしない。**欲しいものが今日並んで
  いるかどうかを運に任せると、貯めた砂金の使い道を自分で決められなくなる**。パックは中身が運で決まるが、
  天井と生成(15章)で欲しいカードへ確実に届く道がある
- **価格はアイコン100・エモート200・プレイマット1500(標準)/ 3000(豪華)**。
  プレイマットが桁違いに高いのは、**対局中ずっと目に入り、画面で最も面積が大きい**ため。
  同じ品種の中に価格の段を設け、模様と縁飾りの作り込みで段を分ける。
  **アイコンは後から足した品も一律100とする**(品種の中で段を作らない)。
  **エモートは最初の4種が200、後から足した品は品ごとに価格を持つ**(いまは300)。
  対局中ずっと使う定番の文言より、遊び心のある文言のほうを後から高く足していく
  **既に並んでいる品の価格は遡って上げない**——新しい品種の側で
  釣り合わせる(砂金の入手経路が増えるたび、既存の価格は相対的に安くなる)
- **一度買ったものは消えない**。同じものは2度買えず、購入済みの品は「所有済み」と示す
- **残高が足りない品は暗くし、購入ボタンだけを押せなくする**(手札のマナ不足と同じ扱い)。
  選んで詳細と見え方を確かめることはできる——手の届かない品も、見え方が分かれば貯める目標になる。
  **買えないことは品を暗くすることと「あと n 足りません」だけで示し、価格を赤で書かない**——残高が0のうちは
  品書きが一面の赤字になり、品が並んでいるというより不具合が並んでいるように見える
- **買う前に確認を挟む**。押し間違いで砂金が減ると、取り返す手段が対局しかない。
  **品を選ぶ → 詳細で価格と購入後の残高を見て「購入する」を押す、の2段階を確認とし、確認のダイアログは出さない**
  (ダイアログは詳細と同じことを繰り返すだけになる)。品とボタンは離れた位置に置き、品の連打で買わないようにする
- 買ったものは**アカウント画面**で設定する。ショップは買う場所であり、設定する場所を
  兼ねない(**パックは例外**。開けたカードはそのままデッキ編成に使えるようになり、
  アカウント画面での設定操作を挟まない)

## 画面

共通のレイアウト規約(9章)に従い、ヘッダーは **左=戻る / 中央=「ショップ」/ 右=砂金の残高**とする。
残高はここでの購入で必ず動くため、ヘッダーへ常時出す。

**左に品種のタブ、中央に品のタイル、右に選んだ品の詳細**を置く。品種をタブで分けるのは、品が増えても
1本のスクロールへ積み上がらず、目当ての品種へ1回で行けるようにするため。

- **タブ**は パック → プレイマット → エモート → アイコン の順(対局への効き目が大きい順)。
  各タブに「所持 n / m」を添える。**売り物が0件の品種のタブは出さない**
- **タイル**は「品の絵 / 名前 / 価格または『✓ 所持』」。絵は品種ごとに実物に近いものを出す:
  アイコンはその紋章、**エモートは実際に出る文言**(文言が品そのもの)、**プレイマットは実際に敷いた縮小見本**、
  **パックはその弾のパックの絵**(弾の名前と1パックの枚数を添える)。
  名前や色の名前だけでは何を買うのか分からない
- **所持済みの品は暗くしない**(暗くするのは買えない品だけ。2つを見分けられるようにする)
- **詳細**は 品種 / 名前 / 見本 / 説明 / 価格と購入後の残高 / 「購入する」。見本はアイコン・プレイマット・
  エモートなら**対局で実際にこう見える姿**(アカウント画面の見本と同じもの。14章)、
  パックは確率と天井までの残り(下記)。パック以外は、所持済みなら購入ボタンの代わりに「アカウント画面で設定できます」を出す
- 開いたときは先頭のタブの先頭の品を選んだ状態にする(詳細が空の画面を見せない)

**通信できないときは買えない**。残高はアカウント(14章)にあり、手元だけで減らすと
次に通信した時点で復活してしまう。その場合はその旨を1行で示す。

## パック

- **1パック = 5枚・100砂金。** 1パック単位と10パック単位で買える(10パックは単に10回ぶんで、値引きはしない)
- **1日1パックを無料で開けられる。**日付の境目はミッションと同じ日本時間の0時。毎日開く理由を1つ置くため
- 5枚のうち1枚は**レア以上が必ず出る**
- 出る確率(カード1枚あたり)

| 枠 | コモン | レア | エピック | レジェンド |
|---|---|---|---|---|
| 1〜4枚目 | 76% | 20% | 3.5% | 0.5% |
| 5枚目(レア以上確定) | — | 82% | 15% | 3% |

- **天井: レジェンドが出ないまま40パック開けると、40パック目の5枚目はレジェンドになる。**数えるのは弾ごとで、レジェンドが出たら0に戻る
- **パックの詳細に確率と天井までの残りを出す**(「レジェンド確定まで あと12パック」)。出る確率を見せずに引かせない
- 開けたカードはそのままデッキ編成に使える
- パックからは公開済みのカードだけが出る(8章の段階公開)。確率はレアリティごとに固定で、公開済みのカードで等分する
- **所持0枚のカードは、デッキ編集の一覧でロック表示にし、所持数(1/2)を札に添える。**押すとショップのパックへの導線を出す
- **砂時計一覧(図鑑)は、所持0枚のカードをシルエットで示す**(9章の「未収集はシルエットと『?』で示す」)。基本セット70枚は常に2枚持つ扱い
- **買う前に中身を確認できる場所は、ショップのパックの詳細が持つ。**「収録カードを見る」を置き、押すとその弾の
  公開済みカードをコスト・総量・キーワード・効果つきで見られるプレビューを開く(未公開の枠は「?」)。
  図鑑・デッキ編集のシルエット/ロックは収集要素としての演出のまま変えず、確認する手段だけをショップ側へ持たせる

目安(試算): 弾60枚を全部そろえるのに中央値で約115パック。日課と対局で1日約300砂金+無料1パックなら、約4週間。
レジェンドは平均20パックに1枚。

### 開封

- パックを開けると、5枚が裏向きに並ぶ。裏の縁の光でレアリティが分かり、押すと1枚ずつめくれる。
  レジェンドは専用の演出でめくれる(見た目はモックで決める)
- 上限を超えたカードは、めくった後に砂粒(15章)へ崩れて残高に飛ぶ
