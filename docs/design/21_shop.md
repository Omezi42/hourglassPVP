# 21. ショップ

砂金(15章)を使う唯一の場所。ホーム画面のそろえるタブの「ショップ」から入る。

- **売るのはアイコン・エモート・プレイマット・カードセット(8章)・カードスキン(31章)**とする(15章)。称号は
  売らない——名札の上に出る短い文字列であり、買ったことが見た目にほとんど現れないため、
  同じ額を払う品としてアイコン・エモートと並べられない
- **「砂の海」はプレイマットの標準的な1枚としてショップに並べる**(価格は下記の標準1500)。
  既定は「なし」であり、この砂紋の布も他のマットと同じく買って設定する対象とする
- **品揃えは固定とする**。日替わりにも、ランダムにもしない。**欲しいものが今日並んで
  いるかどうかを運に任せると、貯めた砂金の使い道を自分で決められなくなる**
- **価格はアイコン100・エモート200・プレイマット1500(標準)/ 3000(豪華)**。
  プレイマットが桁違いに高いのは、**対局中ずっと目に入り、画面で最も面積が大きい**ため。
  同じ品種の中に価格の段を設け、模様と縁飾りの作り込みで段を分ける。
  **既に並んでいるアイコン・エモートの価格は遡って上げない**——今後足す品の側で
  釣り合わせる(砂金の入手経路が増えるたび、既存の価格は相対的に安くなる)
- **一度買ったものは消えない**。同じものは2度買えず、購入済みの品は「所有済み」と示す
- **残高が足りない品は暗くし、押しても買えない**(手札のマナ不足と同じ扱い)。
  **買えないことは行を暗くすることだけで示し、価格を赤で書かない**——残高が0のうちは
  品書きが一面の赤字になり、品が並んでいるというより不具合が並んでいるように見える
- **買う前に確認を挟む**。押し間違いで砂金が減ると、取り返す手段が対局しかない
- 買ったものは**アカウント画面**で設定する。ショップは買う場所であり、設定する場所を
  兼ねない(**カードセットは例外**。買った時点でそのままデッキ編成に使えるようになり、
  アカウント画面での設定操作を挟まない)

## 画面

共通のレイアウト規約(9章)に従い、ヘッダーは **左=戻る / 中央=「ショップ」/ 右=砂金の残高**とする。
残高はここでの購入で必ず動くため、ヘッダーへ常時出す。

一覧は**横2列のグリッド**(9章)。1件は「品の絵 / 名前 / 価格または『所有済み』」で構成し、
アイコンはその絵を、エモートは実際に出る文言をそのまま出す。**エモートは文言が品そのもの**
であり、名前だけを並べると何を買うのか分からない。**プレイマットは実際に敷いた縮小見本**を
出す——色の名前だけでは何を買うのか分からず、これも文言と同じく品そのものにあたる。

**通信できないときは買えない**。残高はアカウント(14章)にあり、手元だけで減らすと
次に通信した時点で復活してしまう。その場合はその旨を1行で示す。

## カードセット

- **カードセットだけは、他の3種(アイコン・エモート・プレイマット)と価格の決め方が違う**。
  対局の中身に関わる以上、品種一律の価格では釣り合わない。**セットごとに個別に価格を決める**。
  **目安は「1枚100砂金 × 枚数」とする**が固定式ではなく、そのセットの強さに応じて
  個別に増減してよい(6章の効果の値段表と同じ、目安であって固定式ではない扱い)
- 品目には、そのセットの狙い(1行)とセット内のカード数を添える。ショップの一覧そのものには
  1枚ずつの詳細までは並べない
- **購入すると、そのセットのカードがデッキ編成へ入れられるようになる**。買い切りであり、
  ガチャ(確率による排出)は無い(15章)
- **未購入のカードセットのカードは、デッキ編集の一覧でロック表示にする**。押すと
  ショップの該当セットへの導線を出す
- **砂時計一覧(図鑑)は、保有していないカードをシルエットで示す**(9章に既にある
  「未収集はシルエットと『?』で示す」を、カードセットの導入をもってはじめて使う。
  基本セット70枚は常に保有済み扱いとする)
- **買う前に中身を確認できる場所は、ショップの品目そのものが持つ。**デッキ編集・砂時計一覧が
  未所有のカードをロック/シルエットで隠す(上記)以上、**それ以外のどこかで確認できることを
  前提にしてはいけない**。カードセットの品目に「内容を見る」を置き、押すとそのセットの
  全カードをコスト・総量・キーワード・効果つきで見られるプレビューを開く。**図鑑・デッキ編集の
  シルエット/ロックは収集要素としての演出のまま変えず、確認する手段だけをショップ側へ持たせる**
  (見た目を隠す場所と、買う判断のために中身を確認できる場所を分ける)
