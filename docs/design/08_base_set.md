# 8. 基本セット(現行のカード一覧)

砂時計58種 + 砂術12種 = **70枚を「基本セット」とし、ここで出そろったものとする**。
以後に追加するカードは基本セットへ混ぜず、**別のセットとして数える**。
レアリティ・クラス制・カードセットはいずれもこの70枚を土台として設計する。

**「出そろった」とは、追加を止めるという意味ではなく、値付けの基準をここで固定する
という意味である。**58種の時点までは1枚足すたびに基準そのものが動いていたが、
以後は基本セットの70枚を動かさずに、新しいセットの側をこれへ合わせて測る。

カードの個別データ(名前・コスト・総量・キーワード・効果)は `docs/Hourglasses.md` を参照。

## 基本セット以後の追加:カードセット

基本セット以後に追加するカードは、**「カードセット」**としてコンセプトごとに3〜15枚程度を
まとめ、ショップ(21章)で砂金と引き換えに**買い切り**で解放する形を主軸とする。
1セットの規模はコンセプトの大きさに応じて選ぶ——数枚の強化パッケージのこともあれば、
1つのプレイスタイルを一通り揃えられる15枚規模のこともある。

**ガチャ(確率による排出)は採らない。**欲しいセットをそのまま買う。重複という概念が
発生しないため、重複を別のカードへ変える「錬金」のような仕組みも持たない。

**基本セット70枚は、カードセットを1つも持たなくても通常に遊べる状態を維持する。**
カードセットは対局の土台ではなく、そこへ足す広がりとして位置づける。

**未購入のカードセットのカードは、デッキ編成へ入れられない。**カードセットの購入が
そのままカードの入手経路になる(21章)。

**買い切りのカードセット以外の追加手段も、状況に応じて別途検討してよい**
(記念・イベント等の無料追加など)。カードセットだけに追加手段を限定しない。

**1セットが単一のキーワードの使い回しだけで埋まることは避ける。**「語彙だけでカードを
作らない」方針(6章)はセット単位でも守る。

**セットは「足りない要素の詰め合わせ」ではなく、1つの枠(世界観・狙うデッキタイプ)で
まとめる**。プールに欠けている要素(墓地参照・反転への反応・
マナ操作など)は、それぞれが自然に収まる枠へ振り分けて、別々の回のセットとして出す。
**枠を選ぶときは、まずメタゲームでどのデッキタイプが組めていないかを見る。**

### 第2弾「静止の刻」

**枠は「時を止める・巻き戻す」。狙うのはコントロールデッキの成立。**

基本セットの時点で、アグロ(速落・貫通・本体火力・コスト1〜2が10枚)とミッドレンジ
(コスト3〜4が31枚)は組めるが、**コントロールは組めない**。カードが足りないからではなく、
**駒が毎ターン老いて必ず死ぬ**という骨格が受けを許していないためである。守護の壁を立てても
数ターンで自壊し、回復はフラスコ・バームの2枚しか無く、相手の駒の成長に触る手段が1枚も無く、
「耐えていれば勝つ」形になる勝ち筋も無い。

このセットは、そこへ**老いない駒(静止)**・**砂を上へ戻す**・**回復**・**条件付きの除去**・
**大型の時限爆弾**を足して、盤面を維持しながら長期戦へ持ち込む道を作る。
9枚・900砂金。個別のカードは `docs/Hourglasses.md`「カードセット: 静止の刻」を参照。

**値付けの物差し**(このセットの数値を詰める際にユーザーが示したもの。以後も使う):
**総量を増やす効果は「使いやすく強い」と高く見積もる**——攻撃力へ足しても反転すれば体力に
なるため、体力・攻撃力のどちらへ足しても実質は総量の増加である。
**総量を変えずに砂を動かすだけの効果(落とす・上へ戻す)は低く見積もる**——前借りか後払いで
あって、それ自体は得にならない。

**今後のセットの枠(案・未確定)**:反転が反転を呼ぶ「反響の刻」(反転コンボ・相手の反転や
反転権への反応・召喚酔い解除)/ 墓地を積もった砂として参照する「遺砂の刻」(墓地参照・回収・
余砂の連鎖)/ アグロを更新する砂嵐の枠(マナ操作・速落付与)。採用が決まった回にここへ足す。
