# 8. 基本セットと弾(現行のカード一覧)

砂時計58種 + 砂術12種 = **70枚を「基本セット」とし、ここで出そろったものとする**。
以後に追加するカードは基本セットへ混ぜず、**別に数える**(下記の「弾」)。
レアリティ・弾はいずれもこの70枚を土台として設計する(クラス制は採らない)。

**「出そろった」とは、追加を止めるという意味ではなく、値付けの基準をここで固定する
という意味である。**58種の時点までは1枚足すたびに基準そのものが動いていたが、
以後は基本セットの70枚を動かさずに、新しい弾の側をこれへ合わせて測る。

カードの個別データ(名前・コスト・総量・キーワード・効果)は `docs/Hourglasses.md` を参照。

## 基本セット以後の追加:弾

基本セット以後に追加するカードは、**60枚を1つの「弾」**としてまとめ、ショップ(21章)で砂金と引き換えに
**パック**を開けて集める。

- **弾の中は、セットくらいの規模(5〜10枚)のテーマに分ける。**1弾でテーマを1つに絞らない。
  1テーマ=1つの枠(世界観・狙うデッキタイプ)という決め方を、弾の中のテーマに引き継ぐ
- **基本セット70枚はガチャの外に置き、全員が最初から2枚ずつ持つ。**弾を1パックも開けなくても通常に遊べる状態を維持する
- **同名カードは2枚まで(2章)。弾のカードは1枚ずつ所持数を数え、2枚持って初めて2枚入れられる。**
  レジェンドだけは同名1枚まで(下記)なので、1枚で足りる
- 所持数の上限(通常2・レジェンド1)を超えて出たぶんは、自動で砂粒(15章)に変わる
- ソロモード限定のカード(27章)とプレゼントのカード(33章)はガチャに入れない。手に入れる道が別にあるため。
  手に入れた時点で上限の枚数(2枚)を持つ

**1テーマが単一のキーワードの使い回しだけで埋まることは避ける。**「語彙だけでカードを
作らない」方針(6章)はテーマ単位でも守る。

**テーマは「足りない要素の詰め合わせ」ではなく、1つの枠(世界観・狙うデッキタイプ)で
まとめる**。プールに欠けている要素(墓地参照・反転への反応・
マナ操作など)は、それぞれが自然に収まる枠へ振り分けて、別々のテーマとして出す。
**枠を選ぶときは、まずメタゲームでどのデッキタイプが組めていないかを見る。**

### 第1弾

これまでのカードセット7つ(五砂・静止・遺砂・反響・追砂・薙砂・詠砂、計52枚)を弾の中のテーマとし、
**各テーマにレジェンドを1枚ずつ(7枚)と、テーマに属さないレジェンドを1枚**足して60枚にする。

- **前にカードセットを買った人は、そのセットのカードを2枚ずつ持っている扱いにする。**払った砂金をそのまま形として残すため
- 新しいレジェンド8枚は第1弾の公開時にまとめてパックへ入れる

### レアリティ

**レアリティは、そのカードの独自性と、テーマの中で持つ意味合いの強さで決める。カードの強さも加味するが、主ではない。**

| レアリティ | 1弾の枚数 | 決め方 |
|---|---|---|
| コモン | 24 | テーマの語彙を素直に使う札。デッキの土台になる |
| レア | 18 | テーマの中で役割がはっきりした札。ひとひねりある |
| エピック | 10 | テーマの読み方を変える札。テーマの顔になる |
| レジェンド | 8 | テーマの頂点。他に無い効果と専用の演出を持つ |

- **レジェンドは同名1枚までしかデッキに入れられない。**
- 既存の52枚には、コモン24・レア18・エピック10を割り振る(割り振りは Hourglasses.md に1枚ずつ書く)
- レアリティはカードの枠の色・宝石で示す(見た目は9章「レアリティ」)

### 段階公開

- **弾は60枚がそろう前から出してよい。テーマごと、または1日1枚ずつパックの中身に足していく。**
- パックからはそのとき公開済みのカードだけが出る。レアリティごとの出る確率は変えず、そのレアリティの中の公開済みカードで等分する
- 弾の一覧(図鑑・ショップの詳細)では、未公開の枠を「?」のシルエットで並べる

### テーマ「静止の刻」

**枠は「時を止める・巻き戻す」。狙うのはコントロールデッキの成立。**

基本セットの時点で、アグロ(疾走・貫通・本体火力・コスト1〜2が10枚)とミッドレンジ
(コスト3〜4が31枚)は組めるが、**コントロールは組めない**。カードが足りないからではなく、
**駒が毎ターン老いて必ず死ぬ**という骨格が受けを許していないためである。守護の壁を立てても
数ターンで自壊し、回復はフラスコ・バームの2枚しか無く、相手の駒の成長に触る手段が1枚も無く、
「耐えていれば勝つ」形になる勝ち筋も無い。

このテーマは、そこへ**老いない駒(静止)**・**砂を上へ戻す**・**回復**・**条件付きの除去**・
**大型の時限爆弾**を足して、盤面を維持しながら長期戦へ持ち込む道を作る。
個別のカードは `docs/Hourglasses.md`「第1弾 テーマ: 静止の刻」を参照。

**値付けの物差し**(このテーマの数値を詰める際にユーザーが示したもの。以後も使う):
**総量を増やす効果は「使いやすく強い」と高く見積もる**——攻撃力へ足しても反転すれば体力に
なるため、体力・攻撃力のどちらへ足しても実質は総量の増加である。
**総量を変えずに砂を動かすだけの効果(落とす・上へ戻す)は低く見積もる**——前借りか後払いで
あって、それ自体は得にならない。

### テーマ「遺砂の刻」

**枠は「砕けた砂は消えず、墓地に積もって次の砂時計の糧になる」。狙うのは、自分の駒が死ぬことで得をするデッキの成立。**

余砂を持つカードは基本セットに9枚あるが、**味方が死んだことに反応する受け手も、任意に死なせる手段も、
墓地を読むカードも無い**ため、余砂は1枚ずつの小さなおまけに留まり、デッキの軸にならない。
静止の刻が「駒が必ず老いて死ぬ」骨格に逆らうテーマなら、このテーマはその骨格に乗る。
**老いて砕けること自体を資源にする**ため、捨て駒・味方の破壊への反応・自壊の手段・墓地の厚みで伸びる駒・
墓地からの回収と蘇生を足す。個別のカードは `docs/Hourglasses.md`「第1弾 テーマ: 遺砂の刻」を参照。

### テーマ「反響の刻」

**枠は「1つの反転が次の反転を呼ぶ」。狙うのは、反転を軸にしたデッキの成立。**

基本セットとソロモード・テーマ「五砂の刻」を合わせても、反転トリガーを持つカードは6枚しか無い。さらに反転は
1体につき1ターン1回のため、1手番に起こせる反転トリガーは駒の数で頭打ちになり、反転はデッキの軸にならない。
このテーマは、**反転が別の反転を起こす連鎖**・**毎ターン反転を起こす駒**・**反転の回数制限を外す手段**・
**相手の反転への反応**を足して、1手番に何度も返すデッキを作る。

個別のカードは `docs/Hourglasses.md`「第1弾 テーマ: 反響の刻」を参照。

**連鎖する効果の対象は「攻撃力が体力より多い味方」に絞り、その中からランダムに選ぶ(札に「ランダムな」と書く)。**
反転トリガーは相手の手番(相手の反転権)にも発動して持ち主が選べないため、選ばせずに済む形にする。この条件なら若い駒を返して
砕く事故が起きず、返した駒は条件から外れるため連鎖が必ず止まる。

### テーマ「追砂の刻」

**枠は「先に動いた相手へ追いつく」。狙うのは、後手が勝ちにくい理由を1つずつ見つけて、カードの方針で補うこと。**

手番の補正(2章のコイン・手札1枚・反転権)は効き幅が大きく、これ以上は重ねられない(7章)。そこでルールではなくカードの側で、
後手が苦しくなる場面そのものへ手当てをする。**カードに「後手」とは書かず、後手が多く出会う場面で働く効果にする**
(先手が持っても損にはならないが、得をするのは主に後手になる)。後手を直接強くする補正にはしない。

補う理由と方針(公開した枚数に合わせてここへ足す):

| 後手が勝ちにくい理由 | 補う方針 | カード |
|---|---|---|
| 先手が先に並べた小型の駒を処理しきれず、テンポを取られたまま押し切られる | **細かい除去**。軽いコストで小型の駒を払う(4枚) | スリング・砂つぶて・ボーラ・ニブル |
| 先に老いて攻撃力の伸びた先手の駒に、先に殴られる | **殴られて得をする受け**(3枚) | ブロック・ヴォールト・ハイヴ |
| 先にHPを削られ、本体の削り合いで負ける | **HPを取り戻す**(1枚) | リリーフ |
| 1手遅れるぶん、相手のほうが常に1段重いカードを出してくる | **重い駒にだけ効く除去**(1枚) | 崩落 |
| 先に盤面を埋められ、展開で追いつけない | **1枚で2体並ぶ展開**(1枚) | マーチ |

個別のカードは `docs/Hourglasses.md`「第1弾 テーマ: 追砂の刻」を参照。

### テーマ「薙砂(なぎさ)の刻」

**枠は「押し寄せる砂の群れを薙ぎ払う」。狙うのは、軽い駒を並べて引き続けるデッキに、ミッドレンジとコントロールが追いつける形を作ること。**

いまのプールの全体除去(スイープ・バースト・砂塵嵐)はどれも4コスト以上で、軽い駒を並べるデッキが展開を終えた後にしか撃てない。
さらに追砂の刻の守護と引く手段が加わり、軽いデッキは守りを固めながら手札を切らさずに押し切れる。このテーマは、
**2〜3コストで払える手段**と、**並べること・守護で固めること・引くことそのものを咎める手段**を足す。
どれも軽いデッキを相手にしたときだけ強く働き、そうでない相手には並の1枚に留まる形にする。

個別のカードは `docs/Hourglasses.md`「第1弾 テーマ: 薙砂の刻」を参照。

### テーマ「詠砂(えいさ)の刻」

**枠は「砂を詠むたびに力が積もる」。狙うのは、砂術を軸にしたデッキの成立。**

砂術は基本セットと各テーマを合わせて22枚あるが、**砂術を使うこと自体に報いるカードが1枚も無い**ため、
砂術は1枚ずつの小技に留まり、デッキの軸にならない(単体の勝率も44%前後に沈みやすい)。このテーマは、
**砂術を使うたびに働く駒**・**砂術を探す手段と墓地から取り戻す手段**・**砂術を軽くする手段**・**撃った砂術の数で決める締め**を足す。
燃料は既存の砂術にするため、新しい札は砂術に反応する駒を中心にし、砂術は2枚に絞る。

個別のカードは `docs/Hourglasses.md`「第1弾 テーマ: 詠砂の刻」を参照。

### 第2弾「前借りの弾」

**弾の軸は「明日の砂を今日使う」。**HP・次の手番のマナ・自分の山札・自分の砂の寿命を代償に、今の一手を大きくする。
世界は「刻が足りなくなった時代。人は明日のぶんの砂を今日の器へ注いで戦った」で、フレーバーは「借りた砂は必ず返す時が来る」に揃える。

狙うメタの穴は3つ。**アグロの更新**(疾走を与える・HPを払う)、プールに1枚も無い**マナ加速**、
逆転率(7章の目標25〜35%に対して14%台)を上げる**劣勢のときだけ強い札**。

| テーマ | 枠 | 狙うデッキ |
|---|---|---|
| 背水(はいすい)の刻 | 追い詰められた器ほど強く鳴る | 劣勢から返す |
| 烈砂(れっさ)の刻 | 燃え尽きる前に駆ける | アグロの更新 |
| 早鐘(はやがね)の刻 | 鐘を早く鳴らして刻を進める | マナ加速 |
| 導火(どうか)の刻 | 落ちきる時が決まった器 | 自壊する大型 |
| 先触(さきぶれ)の刻 | まだ来ない刻(山札)を先に見る | 墓地肥やし・踏み倒し |
| 注砂(ちゅうさ)の刻 | 残った砂を全部注ぐ | マナを余らせない中速 |

テーマ外のレジェンドは2枚(各テーマ1枚と合わせて8枚)。**特殊勝利(山札が0枚なら勝つ)はテーマ外のレジェンド1枚だけが持つ。**
**打ち消しと追加ターンは作らない**(相手の手番に割り込む操作窓が無いため / 相手を長く待たせ、逆転ではなく押し切りに使われるため)。

#### テーマ「背水の刻」

**枠は「追い詰められた器ほど強く鳴る」。狙うのは、劣勢から盤面を返すデッキの成立。**

人の対局で、劣勢のときに出して勝てていたのはスイープだけだった(軽く、出したその手番に盤面を返す)。
このテーマはその型を、**自分のHPが相手より少ないとき / 12以下(初期HPの半分)のときに強くなる札**として足す。
同じ読み方に寄らないよう、HPを比べる札・HPのしきい値を見る札をそれぞれ3枚までにし、残りは殴られたときに押し返す札・老いを巻き戻す札にする。
個別のカードは `docs/Hourglasses.md`「第2弾 テーマ: 背水の刻」を参照。

### プレゼントで配るカード

お知らせのプレゼント(33章)で配るカードは、ソロモード限定のカードと同じくガチャに入れない。**手に入れた時点で2枚を持つ。**
ショップには並べず、CPUのデッキにも入れない。個別のカードは `docs/Hourglasses.md`「プレゼントのカード」を参照。
