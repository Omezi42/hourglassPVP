# 33. お知らせとプレゼント

Discordの #お知らせ に出している更新のお知らせをゲームの中でも読めるようにし、運営から全員へ贈り物を配る。
Discordを見ていない人にも、何が変わったのかと受け取れるものを届けるため。

入口はホームのヘッダーの「お知らせ」(9章)。押すと暗幕の上にモーダルを出し、上に2つのタブ「お知らせ」「プレゼント」を置く。
開いたときは、受け取っていないプレゼントがあれば「プレゼント」、無ければ「お知らせ」を選んでおく。
**自動では開かない**(毎日更新する運用のため、開くたびに割り込むと邪魔になる)。

## お知らせ

- 左に回の一覧(新しい順。版の日付「2026.10.29」)、右に選んだ回の本文。開いたときは最新の回を選ぶ。一覧は直近20回まで
- 本文は #お知らせ に投稿したビルドの更新のお知らせと同じ文面。「あたらしいもの / なおしたもの / かわったもの」を見出しにし、項目は行頭の点で並べる
- 末尾の「遊ぶ →」のリンクの行は出さない(もうゲームの中にいるため)
- 読んでいない回は一覧で名前の左に小さな丸を付ける。モーダルを開いた時点で全部読んだことにする
- まだ読んでいない回があるとき、ヘッダーの「お知らせ」に赤い丸を付ける(9章)。はじめて起動した人には、いちばん新しい回だけを読んでいない回として扱う(何十回ぶんの丸を出さないため)

## プレゼント

- 運営から**全員へ**配る贈り物。1件ごとに 名前・中身・説明1行・受け取り期限(省略すると期限なし)を持つ
- 中身は**カードセット**か**砂金**
- 一覧は受け取れるもの → 受け取り済みの順。1件ごとに中身の絵(カードセットは収録カードの紋章、砂金は砂金のチップ)・名前・説明・期限(「11月30日まで」。期限なしは出さない)・「受け取る」ボタン
- 受け取ったものは「受け取り済み」を沈めた色で残す。**期限を過ぎた未受け取りの品は一覧から消す**
- 受け取った砂金はヘッダーの残高へ飛ばす(ミッションの受け取りと同じ演出)。カードセットは受け取った時点でデッキ編成に使える
- **ゲスト(匿名)のアカウントでも受け取れる**。通信できないときは「受け取る」を押せなくし、「通信できるときに受け取れます」を添える
- **期限のないプレゼントは、あとから始めた人も受け取れる**
- 1件は1つのアカウントにつき1回だけ。2つのタブで同時に押しても2回は受け取れない
- 受け取っていないプレゼントがあるとき、ヘッダーの「お知らせ」に赤い丸と件数を出す(9章)
