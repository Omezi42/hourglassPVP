# コンセプト

砂時計モチーフのターン制対戦カードゲーム。
**砂時計の上の部屋に残った砂が体力、下に落ちた砂が攻撃力**であり、時間が経つほど
強くなると同時に脆くなる。ひっくり返せば体力と攻撃力が入れ替わる——この一点を
ゲームの核に据える。

1戦は10分以内を目標とする(7章)。Godot + unityroom でのオンライン対戦を想定し、
毎日アプデで新しい砂時計を追加し続けられるデータ駆動な拡張性を前提とする。

## 世界

フレーバーテキスト(1章)はこの前提と食い違わないように書く。

- 砂は「刻(とき)」そのもの。落ちた砂は戻らず、刻が進むほど砂時計は強く、脆くなる
- 砂時計は刻を閉じ込めた器。ひっくり返すと、残りの刻と過ぎた刻が入れ替わる
- 砂術は器に閉じ込めずに砂をそのまま振るう術。一度きりで、跡は残らない
- 砕けた器の砂は消えず、底に積もる(墓地)
- 「〜の刻」は時代の名前。セットごとに、砂の扱い方が違う時代がひとつある
- 語り手は名乗らない。説明をせず、固有名詞は増やさない(既にあるカード名だけを使う)
