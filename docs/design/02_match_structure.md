# 2. 対局の構成

- デッキは **30枚**(同名カードは2枚まで)
- 場は各プレイヤー **6枠**
- プレイヤーの初期HPは **24**(時計の文字盤にちなむ数)
- マナは自分のターン開始時に**最大値+1・全回復**(上限10)
- **初期手札は先手3枚・後手4枚。後手は「コイン」を1枚持つ**
- 山札が尽きたら、以降は自分のターン終了ごとに1ダメージ(疲労)

先手・後手の補正は「**後手が1枚多い**」と「**後手はコインを持つ**」の2つだけとする。

**コイン**は、後手が**1対局に1度だけ、自分の手番でマナを+1できる**もの。手札の枚数には
数えず、使うタイミングだけを選ぶ。マナ上限(10)は超えない。

補正の効き幅はどちらも大きく、実測では**コイン単独で先手勝率が約22ポイント動く**。
そのため**複数の補正を重ねてはいけない**。先手も自分の1ターン目からドローする
(「先手の1ターン目はドローなし」も約22ポイントの補正で、コインと併用すると先手勝率が38%まで落ちる)。

マナ上限を恒久的に+1する形の補正は、粒度が粗すぎて使えない(先手勝率が64%から26%へ飛ぶ)。

## マリガン(初手の引き直し)

対局開始時、両プレイヤーは配られた初期手札を見て、**任意の枚数を選んで引き直せる**。
選んだカードを一度手札から外し、**同じ枚数を引いてから、外したカードを山札へ混ぜて切り直す**。
この順序により、**引き直したカードがその場で手札へ戻ってくることはない**。
マリガンは1対局に1度だけで、**先手・後手が同時に行う**。相手が何枚交換したかは互いに分からない。

30枚のデッキでコスト1〜2のカードを1枚も引けない事故が構造的に起きるため、
**事故がそのまま敗因になる状態を避けることを目的とする**。交換できる枚数に上限は設けない
(全交換もできる)。上限を設けても事故の型が変わるだけで、覚えることだけが増えるため。

**コインは後手の持ち物であり、マリガンの対象外とする**(手札の枚数に数えないため)。

## 反転権

**反転権**は、場に出ている砂時計を**敵味方問わず**反転させられる特殊な行動回数。
通常の反転(3章)とは別枠で管理し、**「1体につき1ターン1回まで」「出したターンは
反転できない」という制限を受けない**。マナは不要。

先手・後手ともに持つが、**対局中に使える総回数が異なる**(後手を多くすることで
手番差を補正する)。使わなかった回数はターンをまたいで持ち越せる。1度使うと、
場のどちらの陣営でもよいので1体を選んで反転させ、残り回数が1減る。

自分の砂時計を反転権で有利な状態(攻撃力が体力を上回ったとき)へ戻すのはもちろん、
**相手の砂時計を反転させることにも使える。**相手の駒(体力が攻撃力より多い、
まだ若い駒)を反転させると、体力と引き換えに攻撃力が跳ね上がる。**この一撃だけでは
相手を弱めたことにならず、むしろ次の相手の手番で使える攻撃力を渡すだけになる**ため、
同じ手番のうちに自分の攻撃でその駒を仕留めるか、確実に破壊できる(体力が0になる)
場合に限って使うのが定石になる。「反転」トリガー(6章)を持つ砂時計は、
誰が反転させても、**持ち主を利する形で**効果が発動する(グロウなら持ち主の総量が
増え、ホイールなら持ち主の相手がダメージを受ける)。

先手・後手それぞれの総回数は **先手2回・後手3回**とする。CPU自己対戦(800戦×2シード)で
5指標すべてが目標圏に収まることを確認済み(先手勝率51.0〜51.5%・決着手数20.1〜20.2手・
ユニットへの攻撃47.5〜47.9%・逆転率32.1〜33.3%・本体ダメージで決着100%。
`docs/BalanceReport_v5.md` 12章)。**コインとの併用も確認済みで、コインを外すと
先手勝率が60〜69%まで跳ね上がるため、コインは維持する**(7章「手番補正は複数重ねては
いけない」の例外ではなく、反転権はコインの代わりにはならないという結論)。

**反転権の値打ちは「弱めてから同じ手番で仕留める」使い方に集約される。**この使い方を
教えないと、単に強い駒への反撃としてしか見えず宝の持ち腐れになる(実際、この使い方を
知らないCPUで測ると反転権はほぼ使われず何も変えなかった。同12章)。ルール画面
(16章)・誘導対局(18章)のいずれかで、この使い方を伝える案内を用意すること
(現状は未着手)。
