# 25. 日曜イベントの告知

日曜イベント(15章)の開始を、Discordの #お知らせ へ自動で告知する継続的な仕組み。

- **22章の「(対局記録の分析は)自動投稿はしない」とはこれは別物である。**あちらは
  1局ごと・日次の集計を指すが、こちらは**週1回しか起きないイベント開始**の告知であり、
  自動化してもうるさくならない
- **自動投稿にはサーバー側の定期実行が要る。**この作品は10章のとおりバックエンドに
  自前サーバーを持たない方針だったが、**Firebaseのサーバーレス関数(Cloud Functions)と
  その定期実行(Cloud Scheduler)を導入する**。常時稼働するプロセスを持たないという
  骨格は変えていない(Cloud Functionsもサーバーレスの実行環境である)
- **告知は毎週日曜0:00(JST)に1度だけ行う。**曜日の判定と同じ基準(15章)に揃える
- **ホーム画面と対局結果パネルにも「日曜イベント中」の表示を添える。**Discordを
  見ていないプレイヤーにも伝わるようにするため。文言は1行に留め、通常時は何も出さない
- **将来、Discord Botのスラッシュコマンドを足す土台としても、同じFirebaseプロジェクトへ
  Cloud Functionsを1本追加する形にする。**常駐するBotプロセス(Gateway接続)は
  現時点では持たず、Discordの「Interactions Endpoint URL」(HTTPS方式)で受ける。
  リアルタイムなメッセージ監視・オンライン表示のようにGateway接続でしか実現できない
  要件が具体的に出た時点で、常駐サーバーの導入を改めて検討する
