# 13. CPU戦

- オンライン通信を必要としない、CPU(コンピューター)を相手にしたローカル対局。`たたかうタブ`の「ひとりで」の枠に「CPU戦」を置く(9章)。他の対局と同様、押すと先に使用デッキを選ぶ画面を挟んでから開始する
- CPUのデッキは、現在定義されている全砂時計を各2枚ずつ入れた山からランダムに30枚を引いて組む(CPU専用のカードは用意しない)。**この「全砂時計」には、プレイヤー本人が未購入のカードセット(21章)も含む**——CPUが使うカードをプレイヤーの所有状況で絞らないことで、対局中に「このカードが欲しい」と思わせる出会いの場にする(ユーザー判断)。**ただしソロモード限定のカードセット(価格0・ショップに並ばない。27章)は除く**——通貨で買えない以上、CPUに見せても購入へつながらないため
- 先手/後手は常に**プレイヤーが先手**に固定する
- CPUもマリガン(2章)を行う。相手が何枚引き直したかは、対人戦と同じく分からない
- CPUは1手番の中で「場に出す → 攻撃する → 反転する → 終える」の順に選ぶ。**攻撃してから反転する**のが要点で、逆にすると攻撃力の高い状態を捨ててしまう。価値の物差しは生涯ダメージ(1章)を使う。**1手ずつ間合いを置いて指す**(まとめて適用すると盤面が一瞬で書き換わり、何をされたのか追えないため)
- 5章の持ち時間は、**オンライン対戦の切断・放置対策を目的とした仕組み**であり、CPU戦はローカル対局でその懸念が存在しないため、持ち時間の消費・時間切れ判定を行わない(プレイヤー・CPUともに考慮時間は無制限)
- CPU戦の対局終了後、その対局の棋譜は12章の通り**ローカルにリプレイとして保存する**(Firestoreへは書き込まない)。観戦はオンライン対戦のルームコード対戦限定のまま、CPU戦は対象外とする

## CPU戦の思考レベル

CPU戦のデッキ選択のあとに、思考レベルを選ぶ画面を挟む。**初級 / 中級 / 上級**の3段階とし、
既定(選び直さなかった場合)は**中級**とする。

| レベル | 攻撃 | 反転・反転権 | 設置効果・砂術の対象 | 場に出す判断 |
|---|---|---|---|---|
| **初級** | 攻撃できる駒・狙える相手をランダムに選ぶ(守護がいれば無視できないのは通常のルールどおり) | 使わない | ランダムに選ぶ | 出せるカードがあれば出す(効率・組み合わせは見ない) |
| **中級** | 生涯ダメージ(1章)を物差しに、最も得な相手を狙う | 「攻撃してから反転する」「弱めてから同じ手番で仕留める」を使う(2章) | 最も効果が活きる1体を選ぶ | 生涯ダメージが最大になる1枚を優先して出す |
| **上級** | 中級の判断に加え、**次の相手の手番で受け返す被害**も見て無理に本体を削らず安全な順を選び、**相打ちで自分の守護持ちを失うと後続の被弾が増える**ことも割り引く | 中級と同じ(2章の判断はこの戦闘システム上すでに尽くされている) | 中級より対象を絞る。**ダメージを与える効果は硝子が残っている相手を避け、実際に通る中で最善を選ぶ**(確定破壊は硝子を無視して通るため対象外) | 中級の判断に加え、**その手番で使い切れないマナを残さない**出し方をわずかに優先し、**コインは使った場合に出せる組み合わせが実際に上回るときだけ**切る |

**マリガン(2章)も上級では引き直す枚数の判断を精密にする**。中級以下はコストの
上限だけで戻すが、上級は**手札に残るコスト1〜2のカードが少ないほど、重いカードを
より積極的に戻す**。事故を避けるという狙い(2章)そのものを、より丁寧に実現する。

**上級は評価軸を足すだけに留め、複数手先の探索は行わない。**貪欲法という
CPUの骨格(13章)そのものは変えない。

**誘導対局(18章)は中級固定とする。**教える操作の手順が難易度によって変わってはいけないため、
思考レベルの選択画面を挟まない。

**思考レベルは対局のたびに選び直せる**(前回選んだ値を初期値として引き継ぐ)。
