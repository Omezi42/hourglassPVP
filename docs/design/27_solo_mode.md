# 27. ソロモード(遠征)

一人用の、繰り返し遊べる本命のコンテンツ。**1回の遠征ごとに違う道を進み、15枚の山札を勝つたびに育てながら
作戦を持ったCPUと連戦する。**対戦の読み合いとデッキ構築を、同時に遊ぶ人がいなくても何度でも味わえるようにするため。
**チュートリアルではない。**案内役(すなえる)や操作の説明は出さない(初めての人への導線は誘導対局・18章が持つ)。

ホーム画面の**「たたかう」タブ**の上段、「対戦する」と並ぶ真鍮の札から入る(9章)。札には遠征の状態を出し、遠征が無いときは「毎回ちがう道で山札を育てる」。

## 遠征の流れ

1. **出発: 作戦を選ぶ。**CPUデッキ(13章)の8つからランダムに3つを示し、1つを選ぶ。その作戦の15種を
   **1枚ずつ、計15枚**を初期の山札にする。CPUデッキはどれも15種×2枚のため、半分がそのまま作戦を持った15枚になる
2. **道を進む: 全6段。**各段で示された行き先から1つを選ぶ(下記「道」)。6段目は最終戦だけが置かれる
3. **対局・関門に勝つたびに、候補から1枚を選んで山札に足す**(下記「山札を育てる」)
4. **HPは24から始まり、対局をまたいで持ち越す。**対局でHPが0になったら遠征は終わる。最終戦に勝てば**踏破**

遠征は同時に1つだけ持てる。途中で抜けても、次に開いたときに道の上から続けられる(下記「中断と再開」)。
遠征を諦めて最初からやり直す操作も置く(確認を挟む)。

## 画面

ヘッダーは「ソロモード」+戻る。背景は他の画面と同じ広間。

- **出発**(遠征が無いとき): 見出し「作戦を選んで出発」。作戦の札を3枚横に大きく並べる(真鍮の縁の凹んだ札に、作戦名・狙い1行・
  15種の小さな砂時計の絵)。札を押すと出発する。下に記録「いちばん多く勝った数 N ・ 踏破 N回」を沈めた色で出す
- **道**(遠征中): 左の約6割に**左から右へ進む6段の道**。段ごとに縦の列で行き先の駒を並べ、駒の中の絵は種類(対局・関門・泉)で変え、
  下に2行のラベル(「対局」+「CPU ・ 重厚」/「関門」+関門名/「泉」+「HP +8」)を置く。CPUが上級になる段(3段目以降)の対局・関門は
  1行目を「対局 ・ 上級」「関門 ・ 上級」とする。選び終えた段は選んだ駒だけを真鍮で明るくし、
  選ばなかった駒は沈んだ石の色にする。選び終えた駒どうしは砂を敷いた道でつなぐ。いま選ぶ段の駒は明滅する光で押せることを示し、
  先の段は暗くする。最終戦の駒は一回り大きくする。右の約4割に状態のパネル(作戦名・HPのバー・勝った数・山札の一覧をコスト順に
  コストの宝石+名前+枚数で。スクロールする)。右下に凹んだ小さなボタン「遠征をやめる」(確認を挟む)
- **行き先の詳細**(道の駒を押したとき): **駒を押しただけでは対局を始めない。**押した駒に真鍮の輪を付け、右のパネルを行き先の詳細に
  切り替える。取り消せない選択の前に、相手と特殊ルールを見て決められるようにするため。
  - 対局・関門: 見出し(「3段目 ・ 関門」。最終戦は「6段目 ・ 最終戦」)、相手「CPU ・ 速攻」、作戦の狙い1行、CPUの強さ(「中級」/「上級」)、
    相手の作戦の15種の小さな砂時計の絵。関門は関門名と特殊ルールの説明、「勝つと候補が4枚に」を添える
  - 泉: 見出し「N段目 ・ 泉」と回復後のHP(「HP 16 → 24」)
  - 下に主ボタン「挑む」(泉は「休む」)と凹んだボタン「戻る」。「戻る」または同じ駒をもう一度押すと状態のパネルへ戻る。別の駒を押すとその駒の詳細へ替わる
- **候補**(勝った直後。道の画面へ戻ったときに出す): 道を暗幕で覆い、見出し「山札に1枚足す」、小見出し「N戦目の勝利 ・ 山札 N枚」、
  カードを大きく横に並べる。作戦のデッキから出した1枚には肩に小さな札「作戦」を付ける。押すと山札へ足す。下中央に凹んだボタン「見送る」。
  右端に**いまの山札の一覧**(状態のパネルと同じ行の形。見出し「いまの山札 N枚」)を置く。何を足すかを山札の中身を見て決められるようにするため
- **遠征の記録**(遠征が終わったあと、次に遠征の画面を開いたとき1度だけ): 暗幕の上に見出し(踏破は「踏破」、それ以外は「遠征の終わり」)、
  作戦名・勝った数(「4勝 / 6段」)・残りHP、**通った道**(道の画面と同じ描き方で、選んだ駒を真鍮で。負けた駒には×を重ねる。押せない)、
  **最後の山札の一覧**を並べる。対局の途中で抜けて終わったときは「対局の途中で抜けたため、遠征は終わりました」を1行添える。
  主ボタン「出発へ」で出発の画面へ進む。「遠征をやめる」でやめたときは出さない(自分で終えたため)

## 道

1段目〜5段目は、それぞれ**2〜3個の行き先**から1つを選ぶ。行き先の並びは遠征のたびに作り直す。

| 行き先 | 内容 |
|---|---|
| **対局** | 作戦を持ったCPUデッキと通常ルールで1局 |
| **関門** | 特殊ルール(下記)を1つ付けた対局。勝つと候補が1枚増える(4枚から1枚) |
| **泉** | 対局なし。HPを8回復する(上限24)。1段目には出さない |

- 各段には対局か関門が必ず1つ以上あり、泉は1段に1つまで
- **6段目は最終戦**(通常ルールの対局)だけを置く
- 対局・関門の行き先には、**相手の作戦名を選ぶ前から出す**(「CPU ・ 速攻」)。相手の作戦を見て道を選ぶこと自体を読み合いにするため。
  1回の遠征の中で同じCPUデッキとは2度当たらない
- **CPUの思考レベルは段で決める**: 1〜2段目は中級、3段目以降は上級(13章)。思考レベルを選ぶ画面は挟まない
- 先手は常にプレイヤー(13章)。マリガン・コイン・反転権は通常の対局と同じ

## 山札を育てる

- 対局・関門に勝つと**3枚の候補から1枚**(関門は4枚から1枚)を選んで山札に足す。**足さずに見送ってもよい**
  (山札が薄いほど強いカードを引きやすいため、足さない判断にも意味がある)
- 候補のうち**1枚は、選んだ作戦のCPUデッキの15種から**出す(作戦の方向へ育てやすくするため)。残りは下記の範囲から出す
- 候補に出る範囲: 基本セットと**ショップで売っているカードセットのカード(未購入も含む)**。遠征の中だけで使える。
  13章のCPUデッキと同じく、手に入れる前のカードに触れる場にするため。**ソロモード限定の3枚とトークンは出さない**
- 同名カードは山札に2枚までで、既に2枚あるカードは候補に出さない。候補は同名を重ねない
- 候補は勝った時点で決まり、中断して開き直しても変わらない
- **ソロモードの遠征に限り、30枚未満の山札で対局する。**山札が尽きたときの疲労(2章)はそのまま効く

## 関門(特殊ルール)

関門は、次の特殊ルールから1つを付けた対局。**いずれもソロモードの対局にだけ適用し、**オンライン対戦・通常のCPU戦・
リーサルパズル(24章)・誘導対局(18章)には一切影響しない。関門は1つずつデータとして持ち、コードを変えずに足せる。

| 関門 | 特殊ルール |
|---|---|
| **先を越された盤** | 相手の場に守護の砂時計が1体いる状態から始まる |
| **守りの壁** | 相手は3体を展開済み。こちらには攻撃できない守護の壁が1体ある |
| **返せない砂** | 3章の通常の反転を使えない。**反転権(2章)は使える** |
| **早すぎる落下** | 毎ターン砂が2粒落ちる |
| **倍の傷** | 4章の相打ちで受けるダメージが2倍になる(双方) |
| **生き延びる** | 相手が2体を展開済みの盤から、5回目の自分の手番まで生き延びれば勝ち |
| **空にする** | 相手の場の砂時計をすべて破壊すれば勝ち(相手のHPを0にしても勝ち) |

## 中断と再開

- 道の上(対局と対局の合間)で抜けたときは、そのまま続きから再開する
- **対局の途中で抜けた(アプリを閉じた)ときは、その対局を負けとして扱い、遠征を終える。**対局をやり直して
  結果を選び直せないようにするため

## 遠征をまたいで残るもの

| もの | 内容 |
|---|---|
| **砂金** | 対局・関門に勝つたびに20、踏破で100 |
| **到達記録** | いちばん多く勝った数(最高6)と踏破回数 |
| **限定カード** | 初めて2勝したとき「チャイム」、初めて4勝したとき「ウォード」、初めて踏破したとき「揺さぶりの一手」とアイコン「glow」 |

ソロモードの対局は戦績(19章)・対局の記録(22章)へ入れない(自分で組んだデッキの対局ではないため)。

## ソロモード限定カード(カードセットとして解放)

**8章の「カードセット」の仕組みをそのまま使う。**ソロモードのためだけに別の所有の仕組みを作らない
——8章は「買い切りのカードセット以外の追加手段」を許しており、遠征での到達はその1つに当たる。

- 3枚は**1枚ずつを別々のカードセットとして**登録する。到達する地点ごとに違う1枚を解放するため
- **ショップでは売らない。**到達した時点でその1枚ぶんのセットが所有済みになる(砂金は減らない)
- 所有・未所有の扱いは8章・21章のカードセットの規則に従う。未所有の間はデッキ編集でロック表示、図鑑ではシルエット表示
- **基本セット70枚には影響しない。**所有後は通常のデッキ構築に使える
- **ソロモード限定カードは、CPUデッキ(13章)にも遠征の候補にも混ぜない**。未所有の可能性があり、通貨でも買えないため

| 名前 | 種別 | コスト | 総量 | 効果 |
|---|---|---|---|---|
| **チャイム** | 砂時計 | 2 | 4 | 反転:カードを1枚引く |
| **ウォード** | 砂時計 | 3 | 4 | 守護 + 設置:自分の他の砂時計1体の総量+1 |
| **揺さぶりの一手** | 砂術 | 2 | ─ | 相手の砂時計1体を反転させる |

数値は他の新規カードと同じく実測で調整することがある(`docs/Hourglasses.md`)。

## 結果パネル

**リーサルパズルの結果パネル(24章)と同じ形を使う。**違いは次のとおり。

- 所属は「ソロモード ・ N段目 ・ 対局/関門/最終戦」、結果の下の行は相手(「CPU ・ 速攻」。関門は関門の名前を前に添える)
- 勝ちのひとことは「自分のHP N を残して勝利」(生き延びる・空にするは「最後まで生き延びた」「相手の場を空にした」)。
  負けは**勝利条件までの残りを数字で出す**(「相手のHP あと N」「生き延びるまで あと N 手番」「相手の場に あと N 体」)
- 負けたときは下に**遠征の結果**(何段目まで進み、何勝したか)を出す。関門で負けたときは関門の説明も出す
- 報酬の札は、この対局で得た砂金に加え、この勝ちで解放した限定カード・アイコンを絵ごと並べる
- パネルの右上に小さく「ログ」を置く(終局後は盤面が暗幕に覆われ、他にログを開く手段が無いため)
- ボタンは、勝ったとき「道へ戻る」(主)、負けたとき・踏破したときは「遠征を終える」(主)だけ。やり直しは置かない
