# 27. ソロモード(遠征)

一人用の、繰り返し遊べる本命のコンテンツ。**1回の遠征ごとに違う道を進み、15枚の山札を勝つたびに育てながら
作戦を持ったCPUと連戦する。**対戦の読み合いとデッキ構築を、同時に遊ぶ人がいなくても何度でも味わえるようにするため。
**チュートリアルではない。**案内役(すなえる)や操作の説明は出さない(初めての人への導線は誘導対局・18章が持つ)。

ホーム画面の**「たたかう」タブ**の上段、「対戦する」と並ぶ真鍮の札から入る(9章)。札には遠征の状態を出し、遠征が無いときは「毎回ちがう道で山札を育てる」。

## 遠征の流れ

1. **出発: 作戦を選ぶ。**CPUデッキ(13章)の8つからランダムに3つを示し、1つを選ぶ。その作戦の15種を
   **1枚ずつ、計15枚**を初期の山札にする。CPUデッキはどれも15種×2枚のため、半分がそのまま作戦を持った15枚になる
2. **道を進む: 全6段。**各段で示された行き先から1つを選ぶ(下記「道」)。6段目は最終戦(主との対局)だけが置かれる
3. **対局・関門に勝つたびに、3枚の束を1つ選んで山札に足す**(下記「山札を育てる」)。関門に勝つと、加えて**恩恵**を1つ選ぶ(下記「恩恵」)
4. **HPは24から始まり、対局をまたいで持ち越す。**対局でHPが0になったら遠征は終わる。最終戦に勝てば**踏破**

遠征は同時に1つだけ持てる。途中で抜けても、次に開いたときに道の上から続けられる(下記「中断と再開」)。
遠征を諦めて最初からやり直す操作も置く(確認を挟む)。

## 画面

ヘッダーは「ソロモード」+戻る。背景は他の画面と同じ広間。

- **出発**(遠征が無いとき): 見出し「作戦を選んで出発」。その下に**砂の深さの選択**(「◀ 砂の深さ N ▶」と、その深さで加わる条件を
  「・」で区切って1行に小さく。深さ0は「条件なし」)。選べる深さまでしか進めず、選べない側の矢印は沈める。前回選んだ深さを覚えておく。
  その下に**この遠征の主**を1行で(「最終戦の主 ・ 流砂の主 ─ 毎ターン砂が2粒落ちる」)。
  作戦の札を3枚横に大きく並べる(真鍮の縁の凹んだ札に、作戦名・狙い1行・15種の小さな砂時計の絵)。**その作戦で踏破したことがあれば、
  札の右上に真鍮の封蝋の印**を押し、中に踏破した最も深い深さの数字を入れる。札を押すと出発する。下に記録
  「いちばん多く勝った数 N ・ 踏破 N回 ・ 踏破した作戦 N / 8」を沈めた色で出す
- **道**(遠征中): 左の約6割に**左から右へ進む6段の道**。段ごとに縦の列で行き先の駒を並べ、駒の中の絵は種類(対局・関門・泉・工房)で変え、
  下に2行のラベル(「対局」+「CPU ・ 重厚」/「関門」+関門名/「泉」+「HP +8」/「工房」+「抜く・複製」/「最終戦」+主の名前)を置く。CPUが上級になる段(3段目以降)の対局・関門は
  1行目を「対局 ・ 上級」「関門 ・ 上級」とする。選び終えた段は選んだ駒だけを真鍮で明るくし、
  選ばなかった駒は沈んだ石の色にする。選び終えた駒どうしは砂を敷いた道でつなぐ。いま選ぶ段の駒は明滅する光で押せることを示し、
  先の段は暗くする。最終戦の駒は一回り大きくする。右の約4割に状態のパネル(作戦名・HPのバー・勝った数・山札の一覧をコスト順に
  コストの宝石+名前+枚数で。スクロールする)。右下に凹んだ小さなボタン「遠征をやめる」(確認を挟む)
- **行き先の詳細**(道の駒を押したとき): **駒を押しただけでは対局を始めない。**押した駒に真鍮の輪を付け、右のパネルを行き先の詳細に
  切り替える。取り消せない選択の前に、相手と特殊ルールを見て決められるようにするため。
  - 対局・関門: 見出し(「3段目 ・ 関門」。最終戦は「6段目 ・ 最終戦」)、相手「CPU ・ 速攻」、作戦の狙い1行、CPUの強さ(「中級」/「上級」)、
    相手の作戦の15種の小さな砂時計の絵(8列2段。読むのは作戦の傾向なので、1枚ずつは小さくてよい)。関門は関門名と特殊ルールの説明、「勝つと恩恵を1つ」を添える。
    最終戦は主の名前と特殊ルールの説明、「倒せば踏破」を添える。相手が自分の山札の写しを使う関門・主では、相手を「CPU ・ あなたの山札」とし、
    狙いの行を出さず、絵は自分の山札の種類を並べる
  - 泉: 見出し「N段目 ・ 泉」と回復後のHP(「HP 16 → 24」)
  - 工房: 見出し「N段目 ・ 工房」と「山札から1枚を抜くか、1枚を複製する」
  - 下に主ボタン「挑む」(泉は「休む」、工房は「入る」)と凹んだボタン「戻る」。「戻る」または同じ駒をもう一度押すと状態のパネルへ戻る。別の駒を押すとその駒の詳細へ替わる
- **束**(勝った直後。道の画面へ戻ったときに出す。関門なら恩恵を選んだあと): 道を暗幕で覆い、上端に見出し「束を1つ選んで山札に足す」と
  小見出し「N戦目の勝利」。左に束を**横長の札として縦に**並べる。札の左に束の名前(「反転の束」)と作戦の狙い1行、選んだ作戦の束には
  「◆ 作戦」を添える。札の右にその3枚を**手札と同じ大きさで欠けずに**並べる(4つのときは札ごと縮める。カードの中身は切り取らず全体を縮小する)。
  **札を押すと選ぶだけで、まだ足さない。**選んだ札は真鍮で明るくする。右のパネルに見出し「山札 N枚 → N枚」と**足したあとの山札の一覧**を出し、
  増える行を琥珀で光らせる。その下に主ボタン「この束を足す」(選ぶまで押せない)と凹んだボタン「見送る」。
  3枚が一度に入る取り消せない選択なので、足したあとの山札を見てから決められるようにするため
- **恩恵**(関門に勝った直後): 暗幕の上に見出し「恩恵を1つ選ぶ」、小見出し「関門『名前』を越えた ・ 遠征のあいだずっと効く」。
  恩恵の札を3枚横に大きく並べる(真鍮の縁の凹んだ札に、恩恵ごとの絵のメダル・名前・効果1〜2行)。押すと得る。見送りは置かない。
  下に沈めた色で「持っている恩恵: …」
- **工房**(工房の行き先を選んだとき): 暗幕の上に見出し「工房」。左に山札の種類ごとに1枚ずつ、**コスト順の格子**でカードを並べる
  (全体を縮小して欠けずに見せる。2枚あるカードは右下に「×2」)。右に**作業台のパネル**(行き先の詳細と同じ額縁)。
  カードを選ぶ前は「カードを1枚選ぶ」と山札の枚数だけを出す。カードを押すと真鍮の輪で囲み、作業台にそのカードを大きく出し、
  「山札に N枚」と2つの操作を**結果つき**で並べる: 凹んだ「抜く」+「山札 21 → 20枚」/ 主ボタン「複製する」+「山札 21 → 22枚」
  (2枚あるカードは「複製する」を押せず「同名は2枚まで」)。作業台の下に凹んだ「何もしない」。
  束・行き先と同じ「左で選び、右で結果を見て決める」形にそろえるため
- 状態のパネルと遠征の記録には、作戦名の下に**持っている恩恵の名前**を並べる

- **遠征の記録**(遠征が終わったあと、次に遠征の画面を開いたとき1度だけ): 暗幕の上に見出し(踏破は「踏破」、それ以外は「遠征の終わり」)、
  作戦名・勝った数(「4勝 / 6段」)・残りHP、**通った道**(道の画面と同じ描き方で、選んだ駒を真鍮で。負けた駒には×を重ねる。押せない)、
  **最後の山札の一覧**を並べる。対局の途中で抜けて終わったときは「対局の途中で抜けたため、遠征は終わりました」を1行添える。
  主ボタン「出発へ」で出発の画面へ進む。「遠征をやめる」でやめたときは出さない(自分で終えたため)

- **遠征の札**(遠征の対局の最中): 卓の左、直前の手の列の下に、直前の手の1件と同じ幅・同じ語彙(濃紺の板に真鍮の縁)の札を常に置く。
  上から「遠征 ・ N段目」(小さく沈めた色)/「対局」「主『流砂の主』」「関門『生き延びる』」/ 特殊な勝利条件の関門だけ残りの数(「あと 2 手番」
  「相手の場に あと 3 体」)。残りの数が変わった瞬間に札を小さく跳ねさせる。カーソルを乗せると関門の説明を詳細パネルと同じ形で出す
  (札は押す操作を持たないため)。対局に入ると道で読んだ特殊ルールが見えなくなり、忘れたまま戦うことになるため

## 道

1段目〜5段目は、それぞれ**2〜3個の行き先**から1つを選ぶ。行き先の並びは遠征のたびに作り直す。

| 行き先 | 内容 |
|---|---|
| **対局** | 作戦を持ったCPUデッキと通常ルールで1局 |
| **関門** | 特殊ルール(下記)を1つ付けた対局。勝つと束に加えて恩恵を1つ選ぶ(難しい道を選ぶほど得をするようにするため) |
| **泉** | 対局なし。HPを8回復する(上限はいまの最大HP)。1段目には出さない |
| **工房** | 対局なし。山札から1枚を抜くか、1枚を複製する(何もしなくてもよい)。1段目には出さない |

- 各段には対局か関門が必ず1つ以上あり、泉と工房は合わせて1段に1つまで
- **6段目は最終戦**(主との対局。下記「主」)だけを置く
- 対局・関門の行き先には、**相手の作戦名を選ぶ前から出す**(「CPU ・ 速攻」)。相手の作戦を見て道を選ぶこと自体を読み合いにするため。
  1回の遠征の中で同じCPUデッキとは2度当たらない
- **CPUの思考レベルは段で決める**: 1〜2段目は中級、3段目以降は上級(13章)。思考レベルを選ぶ画面は挟まない
- 先手は常にプレイヤー(13章)。マリガン・コイン・反転権は通常の対局と同じ

## 山札を育てる

- 対局・関門に勝つと**3つの束から1つ**を選び、その3枚をまとめて山札に足す。**足さずに見送ってもよい**
  (山札が薄いほど強いカードを引きやすいため、足さない判断にも意味がある)。見送らなければ5勝でちょうど30枚になる
- 束は**作戦(13章のCPUデッキ)ごと**に作り、その作戦の15種から3枚を出す。1つの束の中のカードが噛み合うようにするため。
  3つのうち**1つは選んだ作戦の束**、残りは他の作戦から重ならないように選ぶ
- 同名カードは山札に2枚までで、既に2枚あるカードは束に入れない。束の中で同名を重ねない。3枚そろわない作戦は束にしない
- 束は勝った時点で決まり、中断して開き直しても変わらない
- **ソロモードの遠征に限り、30枚でない山札で対局する。**山札が尽きたときの疲労(2章)はそのまま効く

## 恩恵

関門に勝つたびに**3つから1つ**を選ぶ。遠征のあいだずっと効き、同じ恩恵は1回の遠征で1度しか出ない。
恩恵は1つずつデータとして持ち、コードを変えずに足せる。**ソロモードの遠征にだけ効く。**

| 恩恵 | 効果 |
|---|---|
| **丈夫な体** | 最大HP+4。得たときにHPも4回復する |
| **深い泉** | 泉の回復+4 |
| **目利き** | 束の候補が4つになる |
| **先制の砂** | 対局の開始時、相手のHPが3少ない |
| **用意周到** | 対局の最初の手札を1枚多く引く |
| **勝ち癖** | 対局に勝つとHPが3回復する(上限はいまの最大HP) |
| **身軽** ◆ | 山札が20枚以下なら、対局の最初の手札を2枚多く引く |
| **小さな軍勢** ◆ | 山札のコスト2以下の砂時計は総量+1 |
| **重い砂** ◆ | 山札のコスト5以上の砂時計はコスト-1 |
| **返し上手** ◆ | 自分の砂時計を反転するたび(反転権を含む)、相手に1ダメージ |
| **置き土産** ◆ | 自分の砂時計が破壊されるたび、相手に1ダメージ |
| **砂袋** ◆ | 対局の反転権が1回多い |
| **早起き** ◆ | 対局の最初の自分の手番だけ、マナ+1 |
| **硝子の心臓** ◆ | 最大HP-6(HPも最大HPを超えないよう減る)。束の候補が2つ増える |

**◆は戦い方を変える恩恵。**恩恵の候補3つには、◆を必ず1つ以上含める(残っていれば)。数字が少し増えるだけの3択にせず、
恩恵を見て山札の組み方を変える判断を毎回作るため。山札の中身を変える恩恵(小さな軍勢・重い砂)は、手札・詳細パネルに変えたあとの値で出す。

## 関門(特殊ルール)

関門は、次の特殊ルールから1つを付けた対局。**いずれもソロモードの対局にだけ適用し、**オンライン対戦・通常のCPU戦・
リーサルパズル(24章)・誘導対局(18章)には一切影響しない。関門は1つずつデータとして持ち、コードを変えずに足せる。

| 関門 | 特殊ルール |
|---|---|
| **先を越された盤** | 相手の場に守護の砂時計が1体いる状態から始まる |
| **守りの壁** | 相手は3体を展開済み。こちらには攻撃できない守護の壁が1体ある |
| **返せない砂** | 3章の通常の反転を使えない。**反転権(2章)は使える** |
| **早すぎる落下** | 毎ターン砂が2粒落ちる |
| **倍の傷** | 4章の相打ちで受けるダメージが2倍になる(双方) |
| **生き延びる** | 相手が2体を展開済みの盤から、5回目の自分の手番まで生き延びれば勝ち |
| **空にする** | 相手の場の砂時計をすべて破壊すれば勝ち(相手のHPを0にしても勝ち) |
| **鏡写し** | 相手はこの対局だけ、自分の山札の写しを使う |
| **速攻勝負** | 自分の8回目の手番が終わるまでに相手のHPを0にしなければ負け |
| **小さな大軍** | 相手の場にグレイン(総量3)が5体いる状態から始まる |
| **反転の応酬** | 反転権(2章)が双方3回ずつになる |

## 主(最終戦)

最終戦の相手は**主**。CPUデッキに固有の特殊ルールを1つ重ね、**相手のHPが8多い**。遠征ごとに1体で、**出発の画面で示し、道の6段目にも出す。**
最後の相手を最初から見せ、束・恩恵・道を主を倒すために選ばせるため。主の特殊ルールは関門と同じ仕組みで、1つずつデータとして持ち、コードを変えずに足せる。
主の作戦(CPUデッキ)は1〜5段目の相手と重ならない。勝っても恩恵は出ない(遠征が終わるため)。

| 主 | 作戦 | 特殊ルール |
|---|---|---|
| **流砂の主** | 速攻 | 毎ターン砂が2粒落ちる |
| **城塞の主** | 重厚 | 相手の場に守護の砂時計が3体いる状態から始まる |
| **鏡の主** | (自分の山札の写し) | 相手は自分の山札の写しを使う |
| **急ぎの主** | 基本 | 相手の山札の砂時計はすべて速落を持つ(6章) |

## 中断と再開

- 道の上(対局と対局の合間)で抜けたときは、そのまま続きから再開する
- **対局の途中で抜けた(アプリを閉じた)ときは、その対局を負けとして扱い、遠征を終える。**対局をやり直して
  結果を選び直せないようにするため

## 砂の深さ(難度)

踏破したあとも、条件を重ねて挑み直せるようにする。**深さは0〜5。**深さNで踏破すると深さN+1を選べるようになる(作戦を問わない)。
条件は**積み重なる**(深さ3なら深さ1〜3の条件がすべて付く)。深さは遠征の間変わらない。

| 深さ | 加わる条件 |
|---|---|
| 1 | CPUが1段目から上級 |
| 2 | 泉の回復が5になる |
| 3 | 相手のHPが4多い状態で対局を始める |
| 4 | 束の候補が1つ減る |
| 5 | 遠征の開始時の最大HPが20 |

- 道の状態のパネル・遠征の札・遠征の記録・結果パネルの所属に「深さN」を添える(深さ0では出さない)
- 踏破の砂金は深さに応じて増える(下記)

## 遠征をまたいで残るもの

| もの | 内容 |
|---|---|
| **砂金** | 対局・関門に勝つたびに20、踏破で100 + 深さ×50 |
| **到達記録** | いちばん多く勝った数(最高6)・踏破回数・選べる最も深い深さ・**作戦ごとに踏破した最も深い深さ**(出発の札の封蝋の印) |
| **限定カード** | 初めて2勝したとき「チャイム」、初めて4勝したとき「ウォード」、初めて踏破したとき「揺さぶりの一手」とアイコン「glow」 |

ソロモードの対局は戦績(19章)・対局の記録(22章)へ入れない(自分で組んだデッキの対局ではないため)。

## ソロモード限定カード(カードセットとして解放)

**8章の「カードセット」の仕組みをそのまま使う。**ソロモードのためだけに別の所有の仕組みを作らない
——8章は「買い切りのカードセット以外の追加手段」を許しており、遠征での到達はその1つに当たる。

- 3枚は**1枚ずつを別々のカードセットとして**登録する。到達する地点ごとに違う1枚を解放するため
- **ショップでは売らない。**到達した時点でその1枚ぶんのセットが所有済みになる(砂金は減らない)
- 所有・未所有の扱いは8章・21章のカードセットの規則に従う。未所有の間はデッキ編集でロック表示、図鑑ではシルエット表示
- **基本セット70枚には影響しない。**所有後は通常のデッキ構築に使える
- **ソロモード限定カードは、CPUデッキ(13章)にも遠征の束にも混ぜない**。未所有の可能性があり、通貨でも買えないため

| 名前 | 種別 | コスト | 総量 | 効果 |
|---|---|---|---|---|

## 結果パネル

**リーサルパズルの結果パネル(24章)と同じ形を使う。**違いは次のとおり。

- 所属は「ソロモード ・ N段目 ・ 対局/関門/最終戦」、結果の下の行は相手(「CPU ・ 速攻」。関門は関門の名前、最終戦は主の名前を前に添える)
- 勝ちのひとことは「自分のHP N を残して勝利」(生き延びる・空にするは「最後まで生き延びた」「相手の場を空にした」)。
  負けは**勝利条件までの残りを数字で出す**(「相手のHP あと N」「生き延びるまで あと N 手番」「相手の場に あと N 体」)
- 負けたときは下に**遠征の結果**(何段目まで進み、何勝したか)を出す。関門で負けたときは関門の説明も出す
- 報酬の札は、この対局で得た砂金に加え、この勝ちで解放した限定カード・アイコンを絵ごと並べる
- パネルの右上に小さく「ログ」を置く(終局後は盤面が暗幕に覆われ、他にログを開く手段が無いため)
- ボタンは、勝ったとき「道へ戻る」(主)、負けたとき・踏破したときは「遠征を終える」(主)だけ。やり直しは置かない
