# 29. 掲示板(ラボ)

**開発側が出す「お題」に沿って、プレイヤーからカード案を募る仕組み。**お題は次の
カードセット(8章)の枠そのものであり、投票で支持された案をそのセットへ入れるかを
開発側が検討する。カードセットは「世界観の枠+メタの穴」で1つのコンセプトにまとめるため、
テーマの無い案を常時集めても入れる先が無い。お題で枠を先に示して、案がそのまま
セットへ入れられる形にする。

ホーム画面5つ目のタブ**「つくる」**(9章)から開く。

## 募集回

**1つのお題につき1回の募集回を開く。**同時に開いている回は1つだけ。

| 項目 | 内容 |
|---|---|
| お題 | 20字以内。例「長く場に残る砂時計」 |
| 補足 | 80字以内。お題の狙いを1〜2文で |
| 期間 | 開始と締切の日時(JST)。目安は2週間で、お題ごとに開発側が決める |

- **募集中**:投稿と投票を受け付ける。**得票数は伏せる**(早く出した案・すでに票を
  集めた案へ票が偏るのを防ぐため)
- **締切後**:投稿・投票を締め、得票数を公開して得票の多い順に並べる。
  開発側が上位から採用する案を決め(0件でもよい)、**結果を確定した時点で
  採用した案に印を付ける**。確定するまでは「検討中」と出す
- 回が開いていない間は、次のお題を準備中である旨を出し、過去の回は見られる

## 投稿

**1回の募集につき1人1件まで、無料。**件数を絞る役目は件数の上限が担う。

| 項目 | 内容 |
|---|---|
| カード名(案) | 20字以内。**そのまま採用されるとは限らない** |
| モチーフ・効果の説明 | 200字以内の自由記述(複数行) |
| 砂時計 / 砂術のどちらか | 6章の分類にそのまま従う |

- **コスト・総量・キーワードの数値は投稿者が決めない。**採用後に6章の値段表・
  実測(`docs/BalanceReport_v5.md`)に従って開発側が値付けし、通常のカード追加フロー
  (`.claude/skills/add-hourglass/SKILL.md`)に乗せる。掲示板が担うのはモチーフと
  アイデアだけであり、値付けの厳密さを緩めない
- **投稿後は書き直せない。**送信の前に確認を1回挟む
- **自動のNGワードチェックを通れば、すぐ一覧へ載る。**開発側が後から目を通し、
  問題のある投稿は下記の管理ツールで非表示にする(登録済みアカウント限定・1回1件のため
  荒れにくく、事前審査で掲載を待たせるより掲示板が空に見えないことを優先する)
- 非表示にされた投稿は、投稿者本人にだけ「非表示」と表示する。その回には出し直せない

## 投票

- **1回の募集につき1人3票。**1件に入れられるのは1票まで。自分の投稿には入れられない
- **取り消しはできない。**反対票・コメント機能は持たない
- 募集中の一覧は**見る人ごとに決まった順で混ぜて並べる**(開き直しても同じ順。
  人によって順が違うため、上に出る案が固定されない)

## 画面

ヘッダーの下に「**募集中 / 自分の投稿 / 過去の回**」の3つを切り替えるタブを置く。
一覧は横2列(9章の一覧レイアウト規約)、1件も無いときは`EmptyState`(9章)を使う。

- **募集中**:上部の帯にお題・補足・締切までの残り時間・残りの票数と、主ボタン
  「案を出す」(投稿済みなら「投稿済み」で押せない)を置く。一覧の1件には
  カード名・種別・説明の冒頭と、自分が投票した案には「投票済み」の印を出す
- **1件を押すと詳細パネルを開き**、全文と「この案に投票する」を出す
  (一覧の札は操作させるため、ホバーでは詳細を出さない)
- **自分の投稿**:これまでの投稿を新しい順に、お題・状態(掲載中/非表示/検討中/
  採用/締切後の得票数)とともに並べる
- **過去の回**:締め切った回をお題と期間で並べ、押すとその回の案を得票順に得票数つきで出す。
  採用した案には印を付ける

## 登録済みアカウント限定(14章の例外)

**投稿・投票は登録済みアカウント(14章)に限る。**匿名アカウントは閲覧だけできる。
匿名アカウントはブラウザのデータを消せば何度でも作り直せるため、1回1件・1人3票の
上限が意味を持たなくなる。未登録の間は「案を出す」と投票ボタンを暗くして無反応にし、
理由を1行添える。

## 管理ツール

**お題の作成・非表示・採用の確定はゲーム内では行わず、開発側だけが開くHTMLの
管理ツールから行う**(実装方針は`Architecture.md`)。1画面で、回の一覧・お題の作成・
回ごとの案の得票順(非表示を含む)・非表示の切り替え・採用の印・結果の確定を行える。

## 採用された投稿者への報酬

**採用されたら、投稿者に称号「発案者」を付与する。**14章の称号システムに1件追加する
形とし、専用の報酬の仕組みを新設しない。
