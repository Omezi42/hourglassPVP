# 22. 対局の記録と分析

いまバランスの数値は**すべて自己対戦シミュレーションで測っている**(7章)。CPUは1手ごとの
貪欲法であり、**砂術を持て余す**ことが実測で分かっている(`docs/BalanceReport_v5.md` 10.6節)
ように、機械の数字は人の対局とずれる。**人が指した対局を残し、シミュレーションの値と
突き合わせられるようにする。**

## 記録する対象

- **オンライン対戦(ランクマッチ・ルームマッチ)だけを記録する**。CPU戦は記録しない。
  CPUの癖がそのまま混ざり、「人の対局を測る」という目的と食い違うため。観戦者と
  リプレイの再生も記録しない
- **ルームマッチも記録するが、ランクマッチとは区別して持つ**。友達対戦は真剣勝負とは
  限らないため、分析のときに外せるようにする

## リプレイとは別に持ち、消さない

対局そのもの(デッキ・種・手順)は既にオンライン対戦の仕組みが持っているが、**それは
リプレイのための置き場であり、アカウントごとに直近30件で消える**(12章)。同じ場所に
「消える」と「消さない」という相反する要件を負わせられないため、**分析用の記録は別に
1件だけ書き、消さない**。中身が重複するが、消えるものと残るものを分けることのほうを採る。

## 記録する中身(要約 + 棋譜)

| 内容 | 理由 |
|---|---|
| ビルドID・バージョン | **カードが変われば混ぜて数えられない**。版をまたいだ集計を防ぐ唯一の手段 |
| 対局の種別(ランクマッチ / ルームマッチ) | 上記のとおり分けて数えるため |
| 勝者・決着の要因・総手数・両者の最終HP | 7章の5指標をそのまま出せる |
| 対局が始まった時刻・終わった時刻 | 1局の時間(7章の目標10〜15分)を人の対局で測るため |
| 両者のデッキ30枚のid | カード別・デッキ別の勝率 |
| 山札の種・指した手の並び | **後から再生できる**。「人がどう指したか」はここにしか無い |
| 両者のプレイヤーID | 同じ人どうしの連戦を除いて数えるため。**表示名は記録しない** |

## 誰が書くか

**両者が書きにいき、先着1件だけが通る**。片方が切断していても記録が残り、
二重には数えられない。観戦者は書かない。

**書き込みに失敗しても対局には何も起こさない。**分析のための記録であり、落ちて失われるのは
サンプル1件だけである。**画面にも何も出さない**(裏方の処理の成否をプレイヤーへ見せない。
11章の募集通知と同じ扱い)。

## ゲーム内で見る

全件をクライアントが読むのは重すぎるため、**集計を1つだけ持ち、終局のたびに増分で
更新する**。持つのは総対局数・先手の勝利数・手数の合計・決着の要因ごとの数と、
カードごとの「採用した局数 / そのうち勝った数」。**更新するのは記録を書けた側だけ**とし、
二重に数えないようにする。

戦績画面(19章)へ**「みんなの戦績」**を足し、自分の戦績と切り替えて見られるようにする。
**カード別の勝率はカードの強さそのものではない**という但し書きは、自分の戦績と同じものを
出す(強さの測り方は7章の方式による)。

**集計は版で分けず、通算として貯める。**カードは毎日増えるため版ごとに分けると
画面に出る数字が毎日0に戻る。版ごとの分析は下記の道具が記録そのものを読んで行う。

## Discordで見る

**自動投稿はしない。**1局ごとに流せばうるさく、日次でまとめるにはサーバー側の定期実行が
要るが、この作品はサーバーを持たない(10章)。代わりに**求めたときに記録を読んで集計し、
Discordへ投稿する道具**を用意する。集計の範囲(ビルドID・期間・対局の種別)を指定できる。

## 来た人がどこまで進んだか(通過数)

対局の記録はオンライン対戦しか見ない。**来た人がどの段階でやめているか**は、別に数える。
次に何を直すべきか(入口か、1人で続ける理由か、対人戦か)をこの数で決めるため。

**段階ごとに「その端末で初めて通った」ときだけ1を足す。**同じ人が何度通っても1回。

| 段階 | 数える時点 |
|---|---|
| 起動 | ゲームを初めて起動した |
| ホーム | ホームを開いた(誘導対局を終えて初めて来た場合を含む) |
| 誘導対局を始めた | 誘導対局(18章)を始めた |
| 誘導対局を終えた | 誘導対局の段階をすべて終えた(スキップした場合は数えない) |
| 誘導対局を飛ばした | 誘導対局の途中で「スキップ」した(18章) |
| 対局を終えた | CPU戦(誘導対局を含む)を最後まで指した |
| オンラインの入口 | ランダム・ランク・ルームのいずれかの入口を押した |
| オンライン対戦を終えた | オンライン対戦を最後まで指した |
| 今日の1問を始めた | 今日の1問(24章)を始めた |
| 遠征を始めた | ソロモード(27章)で作戦を選んで出発した |
| 遠征の1戦目に挑んだ | 最初の遠征で、1段目の対局・関門を始めた |
| 遠征の1戦目に勝った | 最初の遠征の1段目に勝った |
| 遠征の1戦目に負けた | 最初の遠征の1段目で、投了以外で負けた |
| 遠征の1戦目の途中で抜けた | 最初の遠征の1段目で投了した、または対局の途中で閉じたことが次に開いたときに分かった |
| 遠征で1勝した | 遠征の対局・関門に初めて勝った |
| 遠征の3段目に着いた | 遠征の3段目の行き先を選んだ |
| 遠征を踏破した | 遠征の最終戦に勝った |
| 2回目の遠征を始めた | 2回目以降の遠征に出発した(1回で離れたか、繰り返し遊ばれているかを見るため) |
| 別の日に来た | 初めて起動した日とは別の日に起動した |

**遠征の1戦目は最初の遠征だけを数える。**負けと離脱を分け、遠征の入口の難しさを直すか、続ける動機を直すかを決めるため。
閉じたまま戻らない人は「挑んだ − 勝った − 負けた − 抜けた」で拾う。関門の特殊勝利条件による決着は投了に数えない。

**誘導対局の手順ごと。**台本(18章)の各手順に入ったところで数える。どの手順で抜けるかを見るため。
手順は台本の番号で持つため、台本を書き換えた日をまたいで比べない。

**ランクマッチの待機。**その端末の**最初の待機だけ**を、始めてから対局が決まるかやめるまで追う。
待っている間のCPU戦(11章)を出す秒数を変えたときに、その効果を見るため。

| 段階 | 数える時点 |
|---|---|
| 待機を始めた | 初めてランクマッチの待機に入った |
| 5秒 / 15秒 / 30秒 / 60秒待った | 相手が決まらないまま、その秒数まで待機を続けた(CPU戦の最中も含む) |
| CPU戦へ切り替えた | 待っている間のCPU戦を始めた(5秒たって自動で始まった場合と、ボタンを押した場合の両方) |
| 人と対戦が成立した | 相手が見つかった |
| 自分でやめた | 対局が決まる前にキャンセル・戻るを押した |

タブを閉じて抜けた人は「やめた」を送れないため、何秒まで残っていたかで拾う。

**配信先ごと。**すべての段階を、合計とは別に配信先(unityroom / itch.io / PLiCy / その他)ごとにも持つ。
どの窓口から来た人が残るかを比べるため。見分けられない配信先は「その他」に入れる。

- **数え始める前から遊んでいた端末は、どの段階も数えない**(初めて来た人の歩みを測るため。数え始めた日の起動を「初めての起動」と取り違えないように)
- **日ごとに分けて持つ**(通った日の日付で数える)。ゲームを直した前後で比べるため
- **個人を特定できるものは持たない。**段階ごとの人数だけを持つ。端末ごとの「通った済み」は端末の中にだけ残す
- 送れなかった段階は通っていない扱いにし、次に起動したときに送り直す
- 失敗しても画面には何も出さない(上の対局の記録と同じ扱い)
- 見るのは下の道具。ゲーム内には出さない

## 1局の時間(CPU戦・遠征)

人どうしの対局は数が少ないため、**人がCPUと指した対局の長さを別の数として持つ**。CPUの手は人より速く、
人どうしの対局の長さそのものではない。7章の目標に対して長すぎないか・短すぎないかの目安に使う。

- **対象はCPU戦と遠征の対局・関門。**誘導対局(台本で決まっている)・今日の1問・観戦・リプレイ再生は数えない
- **棋譜もデッキも送らない。**1局ごとに所要時間の帯・手数・勝敗だけを足す
- **所要時間は対局が始まった時点(マリガンを含む)から決着まで。**オンライン対戦の開始時刻(対局が決まった時点)と揃えるため
- 帯は **〜5分 / 〜10分 / 〜15分 / それより長い** の4つ。席を離れた局が平均を壊さないよう、時間そのものではなく帯で持つ
- 種別(CPU戦 / 遠征)に分け、**日ごとに持つ**(ゲームを直した前後で比べるため)
- **対局ごとに数える。**通過数と違い、同じ端末から何局送られても数える。個人を特定できるものは持たない
- 送れなかった1局は送り直さない(落ちて失われるのはサンプル1件だけ)。失敗しても画面には何も出さない
- 見るのは下の道具。ゲーム内には出さない
