# 17. キーワード辞書

ルール画面(16章)が「順に読ませる紙芝居」であるのに対し、こちらは**語を1つだけ
引きに来るためのリファレンス**とする。ホーム画面の「ルール」タブから、ルール画面と
並べて入口を置く。

- 収録するのは**現在定義されている語すべて**。常在の能力7種(守護 / 硝子 / 貫通 /
  速落 / 毒砂 / 吸命 / 連撃)とトリガー5種(設置 / 反転 / 余砂 / 落砂 / 被弾)。
  **6章で「語にしない」と決めた毒砂・吸命・連撃も辞書には載せる。**カードの面へ語を
  出さないことと、用語を引けることは別の話であり、盤面で「破壊」とだけ書かれた能力の
  正確な挙動を確かめる場所が無いと困るため
- 1件は「語 / 一文の説明 / 実演 / その語を持つ砂時計の一覧」の4つで構成する
- **語にしない能力(毒砂・吸命・連撃)は、カードの面と同じ短い言い換え**(「破壊」
  「回復」「2回攻撃」)**を見出しに出す。**盤面に出ていない語を辞書だけで見せると、
  同じ能力の呼び名が2つになるため(6章)
- **実演は9章のカード詳細と同じものを使う**。辞書専用の絵は作らない。実演はキーワード /
  効果の種類ごとに1本用意する方針(9章)であり、辞書はその単位とそのまま一致する
- **その語を持つ砂時計を並べることを、説明文と同じだけ重要な要素として扱う。**
  「守護はどの砂時計にあるのか」を引けることが辞書の価値の半分を占める。一覧は
  全砂時計から実行時に集めるため、砂時計を追加したときに辞書側へ書き足す作業は発生しない
- **該当する砂時計が1枚も無い語も項目を消さない。**「まだこの能力を持つ
  砂時計はありません」と示し、語彙として定義済みであることを隠さない
- 左に語の一覧、右に選んだ語の詳細、の2カラムとする。共通のレイアウト規約(9章)に従う

## 詳細パネルからの用語ポップ

- **砂時計の詳細に出ている語(「守護」など)を押すと、その語の説明と実演を小さな
  パネルとして重ねる。**辞書画面と同じ内容を出す
- **押せるのは効果欄に並ぶ語のボタン**(語にしない能力は短い言い換え、設置などの
  トリガーはその語)。効果の文そのものは押させない。押せるものと読むものを見た目で
  分けるため
- **用語ポップと実演を持つのは砂時計一覧の詳細だけとする。**デッキ編集と対局画面の詳細は
  ホバーで出して外れたら消えるため(9章)、**パネルの中の語を押しに行った時点で消えてしまう**。
  操作を要する要素は、パネルが留まる画面にしか置けない
- ポップは押した語1件だけを出す。ここから辞書の全一覧へ移る導線は置かない
