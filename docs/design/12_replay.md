# 12. リプレイ

- **ゲームの中にリプレイの一覧は置かず、観戦は持たない。**リプレイは攻略サイト(32章)から開く。
  ホームで一度に目に入る入口を減らすため(遊ぶ人の多くは見返さない)
- 対象は**オンライン対戦**とする。CPU戦の棋譜は残さない
- リプレイを再生できるのは、その対局を実際にプレイした本人のみとする
- 対局そのもの(`matches`)は**アカウントごとに直近30件**を残し、超えたら古いものから自動的に削除する(アプリ全体で数えるとプレイヤー同士が互いの記録を消し合う)。
  攻略サイトが全件を再生できるのは、22章の消えない記録を読むため
- リプレイは1手ずつコマ送りで再生できる形式とする
- パスは棋譜に1手(`pass`)として記録され、リプレイでも1手として数える
- **リプレイ再生画面**:対局画面の盤面・情報帯をそのまま流用し、盤面のクリック操作を無効化した「再生モード」として動作させる。画面右の行動の列には、対局中のボタンの代わりに、先頭へ/1手戻る/再生・一時停止/1手進む/最後へ、の5つの再生コントロールと「n / 全手数」の手数表示を置く。**再生モードには結果パネルを出さない**。「再生」中は一定間隔(0.8秒/手を目安)で自動的にコマを進める
