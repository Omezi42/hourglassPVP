# 12. リプレイ・観戦

- 対局終了後、その対局の手順(棋譜)をリプレイとして保存する。**オンライン対戦・CPU戦の両方が対象**とする
- リプレイを閲覧できるのは、その対局を実際にプレイした本人(CPU戦の場合は自分)のみとする
- 保存件数は、オンライン対戦・CPU戦それぞれ直近30件とし、それを超えたら古いものから自動的に削除する。**この30件はアカウントごとに数える**(アプリ全体で数えるとプレイヤー同士が互いの記録を消し合う)
- **リプレイはアカウントに紐づく**(14章)。別の端末からログインしても同じ記録を続けて閲覧できる。CPU戦のリプレイは通信を必要としない利点を保つためローカル保存のままとし、レコードに所有者を記録して一覧では自分のものだけを表示する
- リプレイは1手ずつコマ送りで再生できる形式とする
- パスは棋譜に1手(`pass`)として記録され、リプレイでも1手として数える
- **リプレイ一覧画面**:`きろくタブ`の「リプレイ」から遷移する。オンライン対戦・CPU戦を問わず、保存済みリプレイを横長カードの一覧として新しい順に縦スクロール表示する(両者は保存先が異なるため、一覧表示の時点でマージして日時順に並べる)。各カードには対局日時・勝敗・先手/後手・対戦種別(オンライン/CPU戦)に加えて、**両者のデッキを代表する数枚のアイコン**を表示する(デッキは30枚あり、そのまま並べるとカードに収まらないため)。対局履歴が無い場合は「まだ対局履歴がありません」等の案内を表示する。カードをタップすると再生画面へ遷移する
- **リプレイ再生画面**:対局画面の盤面・情報帯をそのまま流用し、盤面のクリック操作を無効化した「再生モード」として動作させる。画面右の行動の列には、対局中のボタンの代わりに、先頭へ/1手戻る/再生・一時停止/1手進む/最後へ、の5つの再生コントロールと「n / 全手数」の手数表示を置く。**再生モードには結果パネルを出さない**ため、一覧へ戻る導線もこの列に置く。「再生」中は一定間隔(0.8秒/手を目安)で自動的にコマを進める
- **観戦機能**:進行中の対局を第三者がリアルタイムで見られる機能。**ルームコード対戦限定**とし、ランダムマッチには観戦導線を用意しない(共有できるコードが存在しないため)。ルームマッチ画面(11章)のコード入力欄から「観戦する」を押し、対局中の2人が使ったものと同じコードを入力すると観戦できる。観戦中は盤面・HPが対局の進行に合わせてリアルタイムに更新されるが、一切操作はできない。対局が終了した場合は通常の勝敗演出をそのまま表示する
