# 3. ターンの流れ

1. **マナ回復** — 最大マナ+1、全回復
2. **ドロー** — 1枚引く
3. **メインフェイズ** — 以下を好きな順で、何度でも
   - **場に出す**:手札から1枚、マナを支払って空き枠へ置く。
     **空き枠が無い場合は出せない**(既存の砂時計への上書き設置は行わない)
   - **コインを使う**(後手のみ・1対局に1度):マナを+1する
   - **反転する**:自分の砂時計の体力と攻撃力を入れ替える。**マナは不要**。
     ただし**1体につき1ターンに1回まで**、**出したターンは反転できない**
   - **反転権を使う**(残り回数があるとき):敵味方問わず場の砂時計1体を選んで
     反転させる。マナは不要。**通常の反転の制限(1体1ターン1回・出したターンは不可)を
     受けない**ため、すでに反転済みの駒や出したばかりの駒にも使える(2章)
   - **攻撃する**:攻撃力が1以上の砂時計で、相手の砂時計か相手プレイヤーを攻撃する。
     **1体につき1ターンに1回まで**、**出したターンは攻撃できない**
4. **ターン終了** — 自分の砂時計の砂が1粒ずつ落ちる(体力-1 / 攻撃力+1)。
   体力が0になったものは破壊される
