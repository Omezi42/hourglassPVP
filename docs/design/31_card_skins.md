# 31. カードスキン

**特定のカード1枚の見た目(砂時計の姿)を、自分だけ別の姿へ差し替えられる品。**
ショップ(21章)で砂金と引き換えに買い切りで解放する。売らずに全員へ配るもの(配布のスキン)も置ける。

9章のとおり、砂時計の絵は全種が共通の1枚の色違いであり、固有の絵を1枚ずつ描き起こす
運用は量産に向かないため採らなかった。**スキンはその裏返しで、「量産しない代わりに
1枚ずつ固有の見た目を用意する」ための置き場**とする。カードを見分ける役目は引き続き
紋章が担う(9章)ため、スキンで変わるのは砂時計の姿だけで、**紋章・名前・数値・
キーワードの表示は一切変えない**。

## スキンが持つもの

- 対象のカード1枚のid、表示名、そのカードだけの見た目(**枠と飾り・砂の色と質感・動き**)。
  **トークンと砂術は対象にしない**(砂時計の姿を持たないため)
- **本体のガラス玉は基本の絵と同じ大きさ・位置にする**。スキンだけ砂時計が大きく・小さく
  見えると、盤面で駒の大きさが揃わない
- 砂の量は基本の絵と同じく、体力と攻撃力の比で3状態(上の砂が多い / 落下中 / 下の砂が多い)に描き分ける。
  見た目を差し替えても、**砂の量というこの作品で最も重要な情報チャネル(9章)を潰さない**
- **砂の色と質感(9章の6種)もスキンが持つ。**枠だけを替えるより1枚ごとの違いがはっきりするため。砂の量の読み方は変えない
- **手札の絵の窓の光だまりの色(9章「手札」)は、スキンごとに1色持つ**(スキンの砂の色)。共通の絵の
  色相表から求められないため
- **飾りはゆっくり動いてよい**(刃を光が昇る・目が瞬く・波紋が広がるなど)。動きが見た目の品の値打ちになるため。
  動くのは**場の駒・ショップの見本・図鑑の右のページ**だけで、手札・一覧・棚・墓地・デッキ表では止めた姿を出す
  (並べる画面で全部が動くと散らかり、重くなる)
- **動きは駒の状態に応じて変えてよいが、読み取りを3状態の外へ広げない。**落下中だけ動く飾り(波紋・鈴)、
  上の砂が減るほど弱まる光(聖剣)のように、3状態で既に読める情報の言い換えにとどめる。
  目のある飾りはカーソルのほうを見る

## 売り方と価格

- **1品=カード1枚のスキン**とする。コンセプトで揃えた数枚を1つの品(スキンセット)に
  まとめて売ってもよいが、その場合も中身は1枚ずつ独立したスキンとして扱う(ON/OFFは
  1枚ずつ切り替えられる)
- **価格はスキン1枚500砂金を目安とする。**アイコン(100)・エモート(200)より高く、
  プレイマット(1500)より安い。対局中に目に入るのはそのカードを引いて出したときだけ
  であり、常に画面の大半を占めるマットほどは見えないため。**セットは合計より少し
  安くしてよい。**いずれも初期案であり、砂金の入手経路が増えたら見直す
  (「今後足す品ほど高くする」という21章の方針は同じ)
- 品揃えは固定(21章)。**買う前にショップの品目で3状態の絵をそのまま見られる**
  ようにする(見た目が品そのものであり、名前だけでは何を買うのか分からない。
  プレイマットの縮小見本と同じ考え方)
- 一度買ったものは消えない。同じものは2度買えない
- **配布のスキン**は全員が最初から所有している扱いで、ショップには並ばない。
  **最初はOFF**とし、図鑑でONにした人だけに効く(全員の盤面から元の絵が一斉に消えないように)。
  配ったことは#お知らせで案内する
- いまのスキンは配布の「聖剣」(ソード)と、売り物の8枚:「天翼」(ダッシュ)・「波紋」(エコー)・
  「千里眼」(アイ)・「戴冠」(クラウン)・「裁きの槌」(ハンマー)・「宝玉」(ミラー)・
  「鉄の大盾」(シールド)・「石積み」(ウォール)。いずれも500砂金

## ON/OFF

- **買った時点でONになる。**買ったのに何も変わらない、という状態を作らない(配布のスキンは最初OFF。上記)
- **切り替えは砂時計図鑑(9章)の右のページで、カード1枚ずつ行う。**そのカードの
  スキンを所有しているときだけ、絵の下に「スキン:ON / OFF」の切り替えを出す。
  所有していないカードには何も出さない(ショップの役目を図鑑が兼ねない。14章の
  「設定する場所に買えないものを混ぜない」と同じ)
- 図鑑の右のページの絵は、**ONのときスキンの絵で表示し、押して裏返す操作もそのまま
  効く**(3状態を持つため)
- **デッキ単位でまとめて切り替える仕組みは持たない。**構築ごとに見た目を変えたい
  場面はあるが、デッキごとにスキンの状態を持つとデッキの保存形式・共有(デッキ表・
  デッキコード)・対局前の受け渡しのすべてへ手を入れることになり、見た目の品1種の
  ために釣り合わない。**アカウントに対して1枚ずつ、が唯一の設定単位**
- 設定はアカウント(14章)に紐づき、別の端末からログインしても引き継がれる

## どこで見えるか

- **ONのスキンは、そのカードの絵を出すすべての場所で使う**:手札・場の駒・
  ドラッグ中のプレビュー・図鑑・デッキ編集の一覧と棚・墓地の中身・デッキ表(9章)・
  デッキ一覧の代表アイコン。**画面ごとに出す/出さないを分けない**
  (分けると「買ったのにここでは元の絵」という不揃いになる)
- **対局では相手にも見える。**表示名・アイコン・称号・プレイマットと同じ経路で
  相手の設定を受け取り、相手の場と手札から出た駒をその絵で描く。見た目の品は
  相手に見えて初めて値打ちになる(プレイマットと同じ)
- **CPUの駒にはスキンを当てない。リプレイは元の絵で再生する**(棋譜はスキンを
  記録しない。マットと同じ扱い)
- ルール画面(16章)・画面の見かた(20章)・キーワード辞書(17章)の実演と教材の
  盤面は**常に元の絵**を使う。教材の絵がプレイヤーごとに変わると説明と食い違う

## 見た目の作り方

- スキンは**画像ではなくコード描画(1種につきシェーダー1本)で作る**。ガラス玉と砂の描き方は全スキンで共通の部品を使い、
  スキンが持つのは枠・飾り・砂の色と質感・動きだけにする。ガラス玉の大きさ・位置と3状態の砂の量が全スキンで揃い、
  状態が変わっても枠が揺れない。画像生成と合成は使わない
- 1種ずつ、いまの絵と場の駒・手札・図鑑の大きさで並べたスクリーンショットで質を詰め、人の判定を経てから出す。
  **1度に多くを足す運用にはしない**(数枚ずつ)
- **配布物(pck)はほぼ増えない**(1種がシェーダー1本)ため、枚数の上限は持たない。重さは場に並ぶ数で決まるため、
  場の駒の大きさで測って確かめる
- 既に売ったスキンを作り直すときは**同じidのまま見た目だけを替える**(所有とON/OFFはそのまま)
- 新しいスキンを足したら、Discordの#お知らせへ紹介する(新カードと同じ扱い)
