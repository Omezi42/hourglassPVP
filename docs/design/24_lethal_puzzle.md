# 24. リーサルパズル(詰将棋モード)

あらかじめ配置された固定の盤面・手札・マナから、**「そのターン中に相手HPを0にする」**手順を見つけ出す一人用パズルモード。

- **仕様概要**:
  - ホーム画面の**「たたかう」タブ**の「ひとりで」の枠から「リーサルパズル」を選んで入場する(9章)。
  - 各問題はステージ形式(Stage 1〜10など難易度順)で構成。
  - **パズルのルール**:
    - ターン開始時のマナ、手札、自陣・敵陣の砂時計の状態(残り砂・攻撃力・キーワード)が固定されている。
    - プレイヤーが「ターン終了」を押すか、マナ・行動権を使い切った時点で相手HPが0にならなければ「失敗(リトライ)」。
    - 相手HPを0にできれば「正解(クリア)」となり、**初回クリアのときだけ50砂金**を得る。
      解き直しはできるが報酬は出ない(「この問題は解決済み」と示す)。
    - **手が尽きたことをゲーム側から宣告しない。**マナも行動権も残っている限り何も言わず、
      失敗になるのは「ターン終了を押した」ときだけとする。詰みかどうかを機械が決めると、
      プレイヤーがまだ気づいていない手順まで断じてしまうため。
  - **相手は指してこない。**パズルは自分の1手番だけで完結するため、CPUも持ち時間も置かない。
    エモートも出さない(送る相手がいないため)。
  - **一覧の札の高さは全問そろえる**。ヒントが2行になる問題だけ背が高いと、横2列の
    グリッドで行ごとに段差が出て並びが落ち着かない。2行が収まる高さを最初から取り、
    1行の問題は下が空くに任せる
  - **目的**: 砂の反転タイミング、相打ちによる砂の消滅、速落や貫通・毒砂の挙動など、対局で勝つための基本〜高度なテクニックを楽しく学べる。

## エンドレスモード

Stage1〜10は「決まった手順を覚えて卒業する」導入教材として固定のまま残す。
これとは別に、**無限に出題され続ける「エンドレス」**を用意する。

- **問題選択画面に「エンドレス」の入口を1つ追加する。**Stage1〜10の一覧とは別枠で、
  押すたびにその場で新しい問題が1つ生成されて始まる。**同じ問題が保存されることはなく、
  一覧にも並ばない**(そもそも一覧に並べる「1件」という概念を持たない)
- **出題する問題は、必ず解答手順が存在することを機械が確かめてから出す。**
  存在しない詰みを出してしまうことがそのまま「壊れたパズル」になるため、
  出題前に**その場でシミュレーションを行い、実際にその手順で相手のHPが0になることを
  確認できたものだけ**を見せる
- **択が多く、正解の手順はごくわずかになるよう作る。**盤面には「攻撃しても得にならない
  駒」「使うとマナが足りなくなるだけの砂術」のような、**一見有効に見えるが実際には
  たどり着けない選択肢**を混ぜる。1手・2手で偶然クリアできてしまう問題は出さない
  (最低でも3手前後の組み立てを要する規模で作る)
- **エンドレスに初回クリア報酬(50砂金)は無い。**同じ問題が二度と出ない以上
  「初回」という区切りが成立せず、際限なく遊べる対局に報酬を出すと他の対局種別
  (15章)に対して際限なく稼げてしまう。**エンドレスは純粋な腕試しとして扱う**
- **クリア記録も残さない。**Stage1〜10の「★」のような達成の印は、二度と出ない問題には
  意味を持たないため付けない
- 結果パネルでは、失敗したときも「次の問題へ」を押せば別の問題へ移れる
  (1問に詰まって遊べなくなる状態を避けるため。下記「結果パネル」)

## 結果パネル

ソロモード(27章)と共通の形で、対局の結果パネル(9章)とは別に持つ。パズルに要るのは
勝敗の内訳ではなく「解けたか」「次に何をするか」のため。

- **上から「所属 → 結果 → 問題名 → ひとこと → 受け皿 → ボタン」の順に置く。**
  - 所属は小さく「リーサルパズル ・ 第N問」(エンドレスは「リーサルパズル ・ エンドレス」で、問題名の行は出さない)
  - 結果は正解なら「クリア!」、失敗なら「とどかなかった」
  - ひとことは、正解なら「相手のHP N を削りきった」、失敗なら「相手のHP あと N」とし、**数字だけを大きく出す**
    (あとどれだけ足りなかったかが一目で読めるように)
  - 受け皿(凹んだ面)には、**正解なら初回クリアの報酬を札で並べ、失敗ならヒントを出す**。
    正解時にヒントは出さない(解けた後には用が無いため)
  - 解き直しで報酬が無いときは受け皿を出さず、「クリア済み(報酬は初回のみ)」と小さく添える。
    通信できずに砂金を控えたときは「次に接続できたときに反映」と小さく添える
- **正解は琥珀、失敗は冷えた石の色**で、対局の結果パネル(9章)と同じ質感・入場の動きを使う
- **ボタンは、次にいちばん押されるものを真鍮の主ボタンにする。**

  | 場面 | 主ボタン | 副ボタン |
  |---|---|---|
  | 正解(次の問題がある) | 次の問題へ | もう一度・一覧へ |
  | 正解(最後の問題) | 一覧へ | もう一度 |
  | 失敗 | もう一度 | 一覧へ |
  | エンドレスで正解 | 次の問題へ | もう一度・一覧へ |
  | エンドレスで失敗 | もう一度 | 次の問題へ・一覧へ |

  Stage1〜10の「次の問題へ」は並び順で次の問題を始める(正解の後だけ出す。解けていない問題を飛ばして
  先へ進む道はエンドレスだけが持つ)
