# 未検証・今後の検討事項

- **個々のカードの数値調整はいったん打ち切る。**勝率の幅は測定誤差(±3.5〜5pt)とほぼ同じで、
  これ以上は誤差を追いかけるだけになる。次に測り直すのはプールを触ってメタが動いたとき
  (残っている測り直しの項目は `docs/TODO.md` 5章)
- 実際のプレイテストによる決着手数・時間の確認(自己対戦では平均20〜22手)
- **手番補正をヒーローパワーで行う案(未検討・提案段階、仕様ではない)。**コイン・手札1枚差は
  効き幅が大きく1つしか選べないが、「後手だけ使える弱いドロー」のような固有の小効果なら細かく
  刻める可能性がある。ただしヒーローパワーはロードマップのクラスシステムとセットの概念であり、
  クラス制を採らないなら保留。進めるなら「手番補正だけを目的にした単独のヒーローパワー」か
  クラス制の一部かを先に決める
