# 18. はじめてのプレイ

ルール画面(16章)と辞書(17章)は**読みに行く**ものであり、読まずに対局へ入った
プレイヤーには何も届かない。ここでは**遊びながら覚える**導線と、**構築せずに遊べる**
状態を用意する。ブラウザゲームである以上、最初の数分で離脱されることが最大の損失にあたる。

## 誘導対局(チュートリアル)

- **実際の対局画面で、実際に手を指させる**。読み物や紙芝居ではなく、CPU戦をそのまま使う
- 進行は**段階ごとの短い指示**として画面上部に出す。「手札のカードを空き枠へ出してみましょう」
  のように**1度に1つだけ**を求め、その操作が行われたら次へ進む
- 段階は次の8つとする。**いずれもこの作品でしか通用しない部分**であり、
  他のカードゲームの経験だけでは埋まらない

| 段階 | 求める操作 | 覚えること |
|---|---|---|
| 0 | マリガンを確定する | 初手は引き直せる。引き直さなくてよい |
| 1 | 手札のカードを空き枠へ出す | 札のコストぶんマナを払って出す。マナは毎ターン1つずつ増える |
| 2 | ─(読んで「つぎへ」) | **上に残った砂が体力、下に落ちた砂が攻撃力**。出した直後は攻撃力0で動けない |
| 3 | ターンを終える | ターン終了時に砂が1粒落ちる(体力-1 / 攻撃力+1) |
| 4 | 相手の駒を攻撃する | 攻撃は相打ちで、**受けたダメージのぶん砂そのものが消える** |
| 5 | 相手の本体を攻撃する | 相手のHP帯を押せば本体を殴れる。**相手のHPを0にしたら勝ち** |
| 6 | 自分の駒を反転する | 体力と攻撃力が入れ替わる。**攻撃力が体力を上回ったら返す** |
| 7 | 反転権を使う | **相手の駒にも使える**。攻撃力の高い相手を返して弱めてから殴る |
| 8 | ─ | 以降は自由に続ける(最後まで遊べる) |

- **誘導対局は台本つきの1局とする**。山札を切らず決まった順で引き、プレイヤーが先手、CPUは初級で固定する。
  **どの段階の操作も必ず巡ってきて、初めての1局はまず勝てる**ようにするため。
  ルールは通常のCPU戦のまま使い、固定するのは山札の並び・手番・CPUの強さだけとする。
  台本(両者の山札の順)はデータとして持ち、プールを変えても段階が成立することを自動テストで確かめる
- **誘導対局はマリガン画面から始まる**(2章)。ここに案内が無いと、初めて遊ぶ人は最初の画面で
  何を求められているのか分からないまま止まる。**すなえるの指示はマリガンの暗幕より手前へ出し**、
  引き直しの意味と「選ばなくてよい」ことを伝える。**マリガンを誘導対局だけ省く案は採らない**。
  実際の対局では必ず通る画面であり、省くと初回の壁が後ろへ移るだけのため
- **段階を1つ終えたときの説明は、時間で消さず「つぎへ」を押すまで残す**。読む速さは人により、
  1秒足らずでは読み切れない。**指示の文が自動で切り替わることが、案内が1度しか出なかったように
  見せていた**。手を塞がない方針は変えないため、押さずに指し続けることもでき、
  次の操作を行った時点で先へ進む
- **段階をすべて終えたら、締めのひと言を出してから帯を閉じる**。勝利条件と、
  困ったら駒を押せば効果を読めることだけを伝える。何の区切りも無く案内が消えると、
  続きを投げ出されたように読める。**それ以上は喋らせない**。対局中ずっと話しかけるのは、
  長い語りがルールの読解を妨げるという本節の方針に反する
- **例外として、次の2つだけは初めて起きた瞬間に1度だけ短く補足する**(段階の途中でも締めの後でも)。
  自分の駒が砂の落ちきりで割れたとき(「体力が0になると割れちゃう。返せば長生きするよ」)と、
  相手が守護を持つ駒を出したとき(「守護がいる間は、先にその子を倒さないと本体を殴れないよ」)。
  どちらも**初めて遊ぶ人が「なぜ?」と止まる場面**であり、起きる前に説明しても入らないため。
  出し方は段階を終えたときの説明と同じ(「つぎへ」まで残す)。段階の説明を読んでいる間に起きたら、
  それを閉じた後に出す
- **いま触るものを盤面の上で光らせる**。「空いている台座へ出してみてね」と言われても、
  初見のプレイヤーには**どれが空き枠なのかが分からない**。段階ごとに対象(手札 / 空き枠 /
  ターン終了ボタン / 攻撃できる駒 / 相手のHP帯 / 反転できる駒・反転権の対象)を脈打つ輪郭で囲む。**手は塞がないまま
  視線だけを誘導する**ため、下記の「従わない操作も禁止しない」と両立する
- **求めた操作が今できない場合は、そのための手を代わりに示す**。1ターン目はマナが1しか
  無いため、手札によっては**「出してみてね」と言われても1枚も出せない**。この状態を放置
  すると、初めて遊ぶ人には指示に従えない理由が分からない。出せる札が1枚も無い間は
  「ターン終了を押すとマナが増える」ことを伝え、そちらを光らせる
- **何段階のうちのどこにいるかを出す**。すなえるの下へ段の数だけ点を並べ、済んだものを
  塗る。**終わりが見えないと、いつまで案内が続くのか分からない**。閉じる導線を置かない
  (下記)以上、残りが読めることは必要になる
- **段階を終えたときの一言には、いま自分の盤面で起きた実際の数値を差し込む**。
  「砂が1粒落ちたよ」ではなく「サンドの体力が5から4に、攻撃力が0から1になったよ」と書く。
  **一般論の説明より、目の前の駒と結びついた説明のほうが速く入る**
- **説明を読んでいる間は、話題にしている数字そのものを光らせる**(コストとマナ / 駒の体力と攻撃力 /
  相手のHP / 反転権の残り)。「上の砂が体力」と書いても、画面のどの数字かが結びつかなければ入らない。
  操作を求める輪郭とは色を分け、押す場所と読む場所を取り違えさせない
- **指示に従わない操作も禁止しない**。手を塞ぐと「言われた通りにしか動かせない」体験になり、
  自分で考える余地が消える。指示は**次に何をすれば良いか分からない状態を埋めるためだけ**に置く
- **途中で閉じる導線は置かない**。一度閉じると以降の段階の案内が二度と読めなくなり、
  誤って押した人は残りを教われないまま対局だけが続く。指示は手を塞がない(上記)ため、
  邪魔なら無視してそのまま指してよく、締めのひと言まで進めば自分で閉じられる
- 誘導対局は**何度でも遊べる**が、一度終えたら入口の扱いを控えめにする(下記)
- 誘導対局のデッキは**プリセットの「基本」と同じ30枚を台本の順に並べたもの**を使う。保存済みのデッキがあっても、
  そちらを使わない。覚えてほしい動きが出ないデッキで始まると成立しないため。
  結果パネルの「CPUともう1局」は同じ30枚を通常どおり切って使う

## 案内役「すなえる」

誘導対局の指示は、**マスコットの「すなえる」が話しかける形にする**。指示だけが
帯に出ている状態には話者がおらず、画面が一方的に命令しているように読めるため。

- **すなえるは、砂時計に天使の輪と羽と目を足したもの**とする。**新しく絵を起こさず、
  ゲーム内の砂時計そのものへ描き足す**。盤面に立っている駒と見た目が必ず一致し、
  「この子はこのゲームの砂時計なんだ」と分かる状態を保つため
- **口は描かない。**表情が固定されず、砂時計という物体のままでいられる
- 一人称は「ぼく」、語尾は「〜だよ」「〜してみてね」程度。**指示の文は短く保つ**。
  このゲームは覚えることが多く、長い語りはルールの読解を妨げる
- 立ち絵は**指示の帯の左端に小さく置く**だけとし、盤面を新たに隠さない。
  すなえるのために画面の場所を作らない
- **出るのは誘導対局の間だけ**とする。ルール画面(16章)・タイトル・ホームには
  出さない。**常時いると案内役ではなく飾りになる**ため、
  「初めて遊ぶ人に付き添う」という役割が薄れる

## プリセットデッキ

- **30枚を自分で組まずに遊べる状態を用意する**。デッキ構築は面白さの中心だが、
  **始める前に30枚を選ばせるのは最初の壁として重すぎる**
- プリセットは**3つ**とし、それぞれ狙いを1行で示す

| 名前 | 狙い |
|---|---|
| **基本** | 軽いカードを中心に、砂の進み方と相打ちを素直に体験する |
| **速攻** | 速落・貫通で早く殴りきる |
| **重厚** | 守護と大型で受け止め、盤面を残して勝つ |

- デッキ編集画面から**プリセットを選んで読み込める**。読み込んだ後は普通に編集でき、
  保存すれば自分のデッキになる(プリセット自体は上書きされない)
- **デッキを保存していないプレイヤーは、プリセットの「基本」で対局へ入れる**
  (これまでも既定のデッキで入れていたが、その中身が画面に出ていなかった)

## 初回の導線

- **初めて起動した人(ホームを一度も開いていない人)は、タイトルを押すとホームを経ずに誘導対局へ入る**。
  最初の数十秒に、タブと札が並んだ選択の画面を見せないため
- **ホームを初めて開くのは誘導対局から戻ったとき**。途中で抜けてもホームへ戻る(閉じ込めない)。
  ホームを開く前にブラウザを閉じた人は、次の起動でも誘導対局から始まる
- **誘導対局の結果パネルは、真鍮のボタンを「CPUともう1局」にする**(デッキは「基本」のまま、案内は出さない)。
  「ホームへ」は凹んだパネルへ下げる。1局を終えた直後が、続けて遊んでもらえるいちばんの機会のため
- 「1局遊んで覚える」は「おぼえる」タブの先頭に置く。**誘導対局を終えた(締めのひと言まで進んだ)ら、
  その入口は他の項目と同じ大きさへ下げる**。終えた人に毎回いちばん目立つ位置で勧め続けない
