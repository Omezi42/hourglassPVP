# 18. はじめてのプレイ

ルール画面(16章)と辞書(17章)は**読みに行く**ものであり、読まずに対局へ入った
プレイヤーには何も届かない。ここでは**遊びながら覚える**導線と、**構築せずに遊べる**
状態を用意する。ブラウザゲームである以上、最初の数分で離脱されることが最大の損失にあたる。

## 誘導対局(チュートリアル)

- **実際の対局画面で、実際に手を指させる**。読み物や紙芝居ではなく、通常の対局のルールをそのまま使う
- **両者の手をすべて決めた台本で進める**。何ターン目に何を出し、どこを殴り、次に何を引くかまで決まっている。
  **選べる余地は、初めての人にはかえって「何をすればいいのか」という迷いになる**ため
- **プレイヤーは指示された1か所しか押せない**。ほかを押しても反応しない。CPUもAIではなく台本どおりに指す。
  メニューからの投了・ホームへ戻る導線だけは残す(閉じ込めない)
- 進行は**1度に1つだけの短い指示**として出す。指示は「グレインを出してみてね」「そのグレインで、相手のグレインを
  殴ってみてね」のように**どのカードをどこへ、まで具体的に言い**、押す1か所だけを脈打つ輪郭で囲む。
  駒を選んで相手を押す操作は、選ぶ前は自分の駒、選んだ後は押す相手を囲む。反転権も、押す前は反転権のボタン、押した後は対象の駒を囲む
- **相手のHPは4から始め、4手番で勝って終わる**。最後の一撃で勝ったら結果パネルへ進む(自由に続ける段は無い)。
  結果パネルの上でもすなえるが締めの一言(勝ったこと、次はCPUと1局遊ぶこと)を話す。案内役が黙って消えると、対局の終わりが素っ気なくなるため
- 台本は次のとおり(自分が先手。数字は体力/攻撃力)。**いずれもこの作品でしか通用しない部分**を1つずつ体験させる

| 手番 | 自分の手(=指示) | CPUの手 | 教えること |
|---|---|---|---|
| 準備 | 「このままで開始」を押す(札は選べない) | 同じ | 初手は引き直せる。引き直さなくてよい |
| 自分1(マナ1) | グレイン(3/0)を出す → 読むだけ → ターン終了 | | 使ったマナ / **上の砂が体力、下の砂が攻撃力** / 砂が1粒落ちる(2/1へ) |
| CPU1 | | グレインを出す | |
| 自分2(マナ2) | グレインで相手のグレインを攻撃 → サンド(5/0)を出す → ターン終了 | | 相打ちで**双方1/1へ、受けたぶん砂そのものが消える** / 自分のグレインは砂が落ちきって割れる |
| CPU2 | | グレインで自分のサンドを攻撃(相打ちで割れる)→ サンドを出す | 相手からも殴られる |
| 自分3(マナ3) | サンドで相手の本体を攻撃(4→3)→ 2枚目のサンドを出す → ターン終了 | | **HP帯を押せば本体を殴れる。0にしたら勝ち** |
| CPU3 | | サンドで自分のサンドを攻撃 → シールド(守護・4/0)を出す | |
| 自分4(マナ4) | 反転権でシールド(3/1)を1/3へ返す → サンド(1/2)でシールドを倒す(相打ち)→ 2枚目のサンド(4/1)を反転して1/4へ → そのサンドで本体を攻撃(3→0) | | **守護がいる間は本体を殴れない** / **反転権は相手にも使える。弱めてから仕留める** / **反転で攻撃力を上げて勝ち切る**(ふだんは追い越したら返して長生きさせる、も説明文で添える)/ 勝利 |

- 台本(両者の山札の順と、両者の手の並び)はデータとして持つ。カードの数値を変えても台本どおりに進んで勝つことを
  自動テストで確かめる
- **マリガン画面から始める**(2章)。実際の対局では必ず通る画面のため省かない。すなえるの指示は暗幕より手前へ出し、
  引き直しがあることと、今回はこのままでよいことを伝える
- **説明は時間で消さず「つぎへ」を押すまで残す**。読む速さは人によるため。説明を読んでいる間は、
  **話題にしている数字そのもの**(使ったマナ / 駒の体力と攻撃力 / 相手のHP / 反転権の残り)を、
  押す場所を囲む輪郭とは違う色で光らせる。**実際に盤面で起きた数値を文へ差し込む**
  (「グレインの体力が3から2に、攻撃力が0から1になったよ」)
- **一度説明したことは繰り返さない**。2回目からの同じ操作には説明を付けず、終えたらすぐ次の指示へ進む。同じ説明が毎回挟まるとテンポが悪いため
- 説明は1行目に実際に起きたこと(数値)、2行目にその意味を書く。帯は1行およそ34字×2行に収める
- CPUの手は1手ずつ間を置いて指し、何が起きたか追えるようにする。間は帯に出したCPUの手の予告(「おなじグレインを出すみたい」)を読み切れる長さ(文の長さに比例)とする。自分の駒が砂の落ちきりで割れたときは、
  その場で1度だけ「体力が0になると割れちゃうよ。反転すれば長生きできるんだ」と補足する
- **何手番のうちどこにいるかを点で出す**(準備+4手番の5つ)。終わりが見えないと、いつまで続くのか分からない
- 誘導対局は**何度でも遊べる**が、一度終えたら入口の扱いを控えめにする(下記)
- 誘導対局のデッキは**プリセットの「基本」と同じ30枚を台本の順に並べたもの**を使う。保存済みのデッキがあっても、
  そちらを使わない。覚えてほしい動きが出ないデッキで始まると成立しないため。
  結果パネルの「CPUともう1局」は同じ30枚を通常どおり切って使う

## 案内役「すなえる」

誘導対局の指示は、**マスコットの「すなえる」が話しかける形にする**。指示だけが
帯に出ている状態には話者がおらず、画面が一方的に命令しているように読めるため。

- **すなえるは、砂時計に天使の輪と羽と目を足したもの**とする。**新しく絵を起こさず、
  ゲーム内の砂時計そのものへ描き足す**。盤面に立っている駒と見た目が必ず一致し、
  「この子はこのゲームの砂時計なんだ」と分かる状態を保つため
- **口は描かない。**表情が固定されず、砂時計という物体のままでいられる
- 一人称は「ぼく」、語尾は「〜だよ」「〜してみてね」程度。**指示の文は短く保つ**。
  このゲームは覚えることが多く、長い語りはルールの読解を妨げる
- 立ち絵は**指示の帯の左端に小さく置く**だけとし、盤面を新たに隠さない。
  すなえるのために画面の場所を作らない
- **出るのは誘導対局の間だけ**とする。ルール画面(16章)・タイトル・ホームには
  出さない。**常時いると案内役ではなく飾りになる**ため、
  「初めて遊ぶ人に付き添う」という役割が薄れる

## プリセットデッキ

- **30枚を自分で組まずに遊べる状態を用意する**。デッキ構築は面白さの中心だが、
  **始める前に30枚を選ばせるのは最初の壁として重すぎる**
- プリセットは**3つ**とし、それぞれ狙いを1行で示す

| 名前 | 狙い |
|---|---|
| **基本** | 軽いカードを中心に、砂の進み方と相打ちを素直に体験する |
| **速攻** | 速落・貫通で早く殴りきる |
| **重厚** | 守護と大型で受け止め、盤面を残して勝つ |

- デッキ編集画面から**プリセットを選んで読み込める**。読み込んだ後は普通に編集でき、
  保存すれば自分のデッキになる(プリセット自体は上書きされない)
- **デッキを保存していないプレイヤーは、プリセットの「基本」で対局へ入れる**
  (これまでも既定のデッキで入れていたが、その中身が画面に出ていなかった)

## 初回の導線

- **初めて起動した人(ホームを一度も開いていない人)は、タイトルを押すとホームを経ずに誘導対局へ入る**。
  最初の数十秒に、タブと札が並んだ選択の画面を見せないため
- **ホームを初めて開くのは誘導対局から戻ったとき**。途中で抜けてもホームへ戻る(閉じ込めない)。
  ホームを開く前にブラウザを閉じた人は、次の起動でも誘導対局から始まる
- **誘導対局の結果パネルは、真鍮のボタンを「CPUともう1局」にする**(デッキは「基本」のまま、案内は出さない)。
  「ホームへ」は凹んだパネルへ下げる。1局を終えた直後が、続けて遊んでもらえるいちばんの機会のため
- 「1局遊んで覚える」は「おぼえる」タブの先頭に置く。**誘導対局を終えた(台本の最後まで進めて勝った)ら、
  その入口は他の項目と同じ大きさへ下げる**。終えた人に毎回いちばん目立つ位置で勧め続けない
